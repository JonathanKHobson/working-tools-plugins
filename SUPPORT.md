# Support

Use this repository's Issues for reproducible package or documentation problems. Include package/version, client/version, expected behavior and a small synthetic example. Provider account, app availability and billing issues belong to that provider. Avoid posting private projects, credentials or personal machine logs.

Kyle Hobson maintains this collection on a best-effort basis. There is no response-time or ongoing compatibility guarantee. For a security issue, use SECURITY.md instead of a public issue. For old Compass artifacts, follow the original product repository's guidance.
