# Security

Do not post secrets, private documents or exploitable details in public issues. Use GitHub's private vulnerability reporting on this repository when enabled; if unavailable, contact jonathankylehobson@gmail.com with a minimal description and request a private reporting route before sending sensitive material.

Reports are handled on a best-effort basis with no response-time guarantee. Local MCP gateways can access the files and apps available to their process. Review requested operations and use a disposable project for initial tests. Provider tools and dependencies have their own security policies. No hosted service or data collection backend is operated by this repository.
