# Working Tools plugins

Practical AI workflows and local tools by Kyle Hobson. Choose an individual package for design, video, teaching, game creation or solo-service operations. Each public edition includes its operative skill instructions, requirements, source and notices.

**Start with the [installation guide](docs/install.md)**, or [browse Working Tools](https://working-tools.jkylehobson.chatgpt.site/). You do not need to install the whole collection.

| Your task | Package | What you bring |
| --- | --- | --- |
| Plan, render and inspect a video | [Video Production Workflow](plugins/video-production-workflow/) | Python, FFmpeg and your source media |
| Refine a screen or export in Google Stitch | [Stitch Design Toolkit](plugins/stitch-design-studio/) | Stitch account and browser tools |
| Work safely in DaVinci Resolve | [DaVinci Resolve Toolkit](plugins/davinci-resolve-toolkit/) | Resolve and a verified control route |
| Operate an ArtCraft creative app | [ArtCraft Design Toolkit](plugins/artcraft-design-toolkit/) | Python and separately installed ArtCraft CLI |
| Create or inspect a Figma design | [Figma Design Workflow](plugins/figma-design-workflow/) | Figma access and a supported host tool |
| Design a lesson or assessment | [Instructional Design Studio](plugins/instructional-design-studio/) | Learner context and objectives |
| Plan an accessible workshop | [Workshop Facilitator](plugins/workshop-facilitator/) | Purpose, participants and constraints |
| Scope and playtest a game | [Game Creation Studio](plugins/game-creation-studio/) | A game idea and your chosen engine |
| Prepare invoices or reconcile payments | [Solo Service Operations](plugins/solo-service-operations/) | Your own records; Python for the helper |

Check [tested compatibility](docs/compatibility.md) before choosing a host. A workflow can help an agent use an app; it does not supply that app, a paid account or a remotely hosted service. The [release registry](catalog/packages.json) owns versions and availability. Provider-owned tools and restricted local Studios are not silently bundled.
