# AI Literacy Education

Teach transferable judgment through a familiar task. Use [teaching context](../instructional-design/references/personal-grounding.md) only when the supplied instructor context matters; it does not require social-media content or a historical model. For adapting course extracts, simulated perspectives, or reusable workflows, read only the relevant [adaptation pattern](references/course-adaptation.md).

## Learner practice
Match activities to the requested capability. When task framing or prompt construction is an outcome, have learners name the goal, audience, constraints, evidence, and desired output; compare a vague request and an improved request and inspect the differences. When the outcome is checking outputs, begin with a supplied draft and its sources without adding a prompt-writing lesson. Use a safe fictional scenario, an approved public source, or an offline set of labeled example outputs.

For output-verification lessons, include at least one attractive but unsupported output and require evidence-linked corrections. For tool-choice lessons, include a case in which AI is unnecessary or inappropriate. Include privacy decisions when the task involves potentially sensitive information. Separate generated fluency from factual correctness. Do not teach a framework acronym as a guarantee of quality.

An AI persona can suggest a concern to investigate; it is not testimony from an actual stakeholder. Ask learners to connect an acceptance, correction, or rejection to evidence. A requested citation or confident explanation is not itself verification.

Require an independent attempt and an explanation of one meaningful revision. A different domain can test transfer. Score the learner's decisions and evidence checks, not a proprietary model's output quality alone. If model results differ between attempts, use a common supplied output for fair comparison.

## Current tools and boundaries
Verify the current product interface, access requirements, and available capabilities before writing click instructions. Old 2024 model names, prices, interfaces, and course performance statistics are not current facts. Credentials are not lesson content. Do not require sharing private learner work with a public proxy.

Return a ready-to-teach activity with the example inputs/outputs, learner practice, assessment, feedback, and offline fallback needed for the stated outcome. Add comparison, verification, tool-choice, and privacy exercises where they serve that outcome; do not crowd out independent practice to cover every AI topic. Keep publishing and student-data transfer separate from design authorization.
