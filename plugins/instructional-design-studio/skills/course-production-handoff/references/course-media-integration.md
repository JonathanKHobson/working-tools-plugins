# Course media integration

Use when lesson scripts, learner resources, recordings, and course pages need to become one coherent learner task. Extend the existing production register; do not create another project-management system. Video Production Workflow owns recording/editing/render QA, while this skill owns instructional alignment and learner launch verification.

## Reconcile source, script, and supporting material

Identify the current approved lesson source and version before using a historical recommendation. Separate confirmed facts, source-reported claims, unresolved questions, and production requirements. An old filename, folder plan, or suggested script edit does not override a newer learner handout or course decision.

Preserve continuity with prior tasks. Confirm the starting workspace and files, then provide a short recovery cue if they are missing. Keep a one-time attachment or a later-task resource at its intended point in the sequence; do not introduce a second scaffold or supply withheld data just because it is mentioned in the scenario.

Use `learning-content-storyboarding` for revisions: align each spoken explanation with a visible action, a source to check, and a recognizable result. Keep narration separate from screen actions, exact prompts, optional branches, and production/editor notes. Before saying a file is available, verify the learner download and actual filename. Keep full copyable prompts in the guide so narration can explain their purpose without reading every item aloud. Use Writing Quality Studio's `natural-prose-editor` for a pass against authentic prior delivery when requested.

## Map exported clips to the lesson

Add only fields needed by the existing register:

`lesson/part → canonical source/version → source clip and reviewed export → sequence/chapter start → transcript/captions → guide/practice file → course revision → evidence/status`.

- Preserve original exports and use separate delivery copies. Group clips by task, then verify their contents and order. Similar names can be consecutive parts, alternate takes, or duplicates; the name alone cannot decide.
- Keep standalone tips/bonuses distinct from the required sequence unless the current plan says otherwise. Clip counts and runtime are derived from this course, never inherited from the example history.
- Ask Video Production Workflow to probe duration/streams and inspect embedded timed captions before regenerating them. Preserve original chapter boundaries if joining consecutive clips; adjust offsets for every trim and spot-check both sides of joins.
- Reuse the canonical guide and existing lesson-page pattern. Check agreement among title, objective, visible action, practice file, success criteria, and next step. Avoid maintaining a divergent guide copied into an integration folder without source/version traceability.
- Check recordings for unrelated private screen details. Use reviewed delivery masks/crops that leave the demonstrated actions legible. Never silently replace source media with a redacted export.

## Verify the learner-facing result

Inspect the actual target course revision in its intended learner role. An author view, private draft preview, or already-published older revision is a different state. A saved draft is not publication; publication is not launch verification.

Exercise the learner path rather than only inspecting file presence: open the lesson, start/pause/seek the video, select chapters, follow transcript cues where supported, open the guide, copy required prompts, download/open practice files, and continue to the expected task. Check the relevant narrow-screen layout and captions/text alternative. Test notes or other persistence only when that feature is part of the intended flow. Do not turn optional UX ideas into required feature work.

For rendered review, map 3–8 anchors with ID, page/viewport, approximate region, selector/node if available, observed fact, and intended action. Useful anchors are player controls, a chapter boundary, a transcript cue, guide/prompt, resource download, and next-step control. Recheck changed anchors after fixes. Text extraction and a successful upload cannot substitute for this review.

Return the exact asset/course revision, what was exercised, observed results, and remaining gaps. Keep separate evidence for local media QA, draft attachment/save, learner playback, and public release. Follow existing user authorization for publication; this checklist does not create a new approval gate or grant publication permission.
