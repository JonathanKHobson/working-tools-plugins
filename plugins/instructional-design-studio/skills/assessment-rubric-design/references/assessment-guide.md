# Assessment construction and moderation

## Validity begins with an inference
State what a score will mean, then check what evidence the task actually provides. A rubric can make judgment more consistent without making the assessment valid for every purpose. A practice rubric is not a credentialing instrument.

Specify claim → evidence → task → conditions/allowed aids → scoring → inference limit. For example, scoring one unfamiliar interview response can evidence use of rating criteria, not competence in conducting a whole interview. Keep purpose, formality, and stakes separate: a graded draft can receive formative feedback and revision. [CMU formative and summative assessment](https://www.cmu.edu/teaching/assessment/basics/formative-summative.html).

## Multiple-choice items
Use a self-contained problem and one defensibly best answer. Distractors should represent plausible errors. Avoid grammatical cues, unnecessary negatives, trick wording, all/none options used as shortcuts, and extraneous reading demand. Use the number of options that the task and required platform justify, not an assumed universal four-option rule.

Explain why the correct option works and what the distractor reveals. A platform may require incorrect-option feedback to link to a review task without immediately revealing the answer; verify that requirement for the actual course/version. Do not universalize a historical Coursera checklist.

## Analytic rubric example
Task: revise a fictional AI event notice against its source.
Each dimension scores 0, 1, or 2; maximum 6. This is an illustrative formative rubric, with revision required for any unsupported factual claim regardless of total.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Factual support | Retains all original unsupported claims, or adds any new unsupported claim | Corrects/removes at least one original unsupported claim but retains at least one other; adds none | Corrects/removes all original unsupported claims; adds none; unknowns omitted or explicitly flagged |
| Task fit | Wrong purpose or audience | Mostly suitable with a material omission | Meets audience and requested output constraints |
| Revision rationale | No observable rationale | Names an edit without evidence | Connects an edit to a specific source discrepancy |

Do not score “confidence,” personality, or eloquence. If evidence is missing because the recording failed, mark unobserved rather than 0.

For this example, compare the original draft and revision against the same source. An unknown presented as an established fact is unsupported; an explicitly marked question awaiting confirmation is not a factual assertion. The factual-support anchors assume the original draft contains multiple unsupported claims. Use different anchors for a task with only one claim, and score missing required content under task fit.

## Three calibration samples
Strong: corrects day/time/registration, omits unknown price, cites the schedule → support 2; evaluate fit/rationale from the submitted text.
Partial: corrects day/time but retains “free” → support 1 with a factual retry requirement.
Flawed: keeps original unsupported details and provides no checking → support 0.
These anchors do not justify scoring dimensions for which no sample evidence is supplied.

## Moderation
Have raters score the same small set independently. Compare evidence and descriptors, not just total scores. Revise the rubric when disagreements reflect ambiguity; retain substantive disagreement when the artifact is genuinely borderline. Record accepted alternative solutions.

For a row combining multiple criteria, test crossed cases as well as uniformly strong/partial/flawed work: accurate evidence with unsupported certainty, or weak evidence with well-stated uncertainty. Every scorable combination needs one band. Separate dimensions when practical; otherwise define ordered rules, such as critical error first, all requirements met next, remaining scorable work in the middle. A rule to choose a fully matching band cannot resolve a case that matches none. Mark absence of assessable evidence separately.

## Fairness and AI
Keep allowed assistance explicit. If an AI can complete the final task, inspect the learner's process or an appropriate independent performance when that matters to the construct. Do not infer cheating from style alone. Use AI as draft feedback with evidence references and human review appropriate to stakes.

## Assessment package checklist
Objective IDs; task; conditions and allowed aids; answer key or anchors; rubric maximum; threshold rationale if any; feedback; retry; access options; moderation note; source/version. Ask for missing policy rather than inventing it.
