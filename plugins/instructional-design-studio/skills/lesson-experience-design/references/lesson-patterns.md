# Lesson patterns and a worked example

These are design templates to adapt. They are not fixed schedules mandated by research.

## Pattern A: Worked → supported → independent
Show a complete example and make the decision criteria visible. In the next case remove one scaffold, such as the suggested evidence location. In the final case ask the learner to choose a method and justify it independently. If errors reveal a missing prerequisite, restore that particular support.

## Pattern B: Predict → compare → explain → revise
Ask for a prediction, run or show the example, compare what happened, and revise the explanation. Useful for misconceptions. Avoid publicly ranking wrong predictions or rewarding confident guessing.

## Pattern C: Retrieve → check → apply later
Ask learners to recall a principle without notes, inspect feedback, then use the principle in a later task. Retrieval can be spoken, written, or embedded in an action. Decide whether the objective requires unaided recall or whether tool use is part of competent performance.

## Worked 25-minute lesson: checking an AI event announcement
Fictional source: a community library event is Saturday at 2 pm; registration is required; no admission price is stated. Fictional AI draft says Sunday at 3 pm, free admission, and no registration.

**Outcome:** identify unsupported or contradictory claims, correct the announcement, and support edits with the source.

| Minutes | Learner task | Feedback |
|---|---|---|
| 0–3 | Mark one claim needing a check | Ask which source would resolve it |
| 3–7 | Study correction of the wrong day | Model the source-to-edit link |
| 7–13 | Repair time and registration claims | Check against source; explain discrepancy |
| 13–18 | Decide what to do with “free admission” | Unknown price should be omitted or flagged, not invented |
| 18–23 | Independently inspect a new fictional workshop notice | Same rubric, different details |
| 23–25 | Save a verification checklist and identify a next use | Make one actionable transfer statement |

Learner prompt: “Mark each claim you can support. Revise the others. Show the source for one change.”
Criteria: correct known facts, preserves unknowns, fits audience, explains evidence. Let the learner retry. A correct revised paragraph generated entirely by the assistant is not evidence of learner performance.

## Instructor coaching
Use one question at a time: “Which claim needs evidence?” Wait for an answer. Offer a hint that narrows the search, then an example if still stuck. Do not keep withholding help to manufacture struggle. Once the learner can act, fade the support.

## Adaptations
For novices, reduce domain complexity and provide a source comparison table. For experienced learners, introduce conflicting sources and require a version decision. For younger learners, use age-appropriate language and a fictional school notice. For limited connectivity, print both sources and outputs. These adaptations need review for the actual group.

## Online discussion and game mechanics
These are proposed design patterns, not validated guarantees. Design discussion around a decision, evidence comparison, or revision: make a claim, examine a contrasting case, then revise with reasons. Explain how contributions receive useful feedback and set a response interval compatible with time zones and facilitator capacity. Avoid treating a quota of posts or instructor replies as learning evidence. Provide an individual route when peers are unavailable; a public social account need not be the participation gate.

For badges, points, branching, or competition, name the learner action the mechanic supports and inspect its tradeoffs. Completion badges represent completion; mastery claims need performance evidence. Do not reward speed when careful reasoning is the objective. Compare with a simpler practice-and-feedback activity before adding production effort. Enjoyment, click counts, and a dopamine explanation do not demonstrate durable learning.

## Shared-board lesson pattern

Use this when learners practice on a shared visual canvas. At each stage, make one active task prominent: the literal prompt, the input or evidence learners should inspect, where and how they can respond, what counts as complete, and how that output will be used next. Keep the agenda, prerequisites, rules, and required context available from arrival. Stage later work, while keeping evidence and options needed for the current judgment together; show related candidates against the same criteria side by side. Preserve source and response IDs when moving from observation to interpretation, candidate, choice, and later use. Do not replace a participant's wording with a polished synthesis without retaining the source contribution.

Choose a brief arrival interaction only if it rehearses a useful contribution or navigation move. Make play optional, allow passing, and offer text or scribe participation when drawing or precise movement is incidental. Provide facilitator instructions separately from learner prompts and keep any companion text synchronized with the actual board and its outputs. A rehearsal can reveal navigation, comprehension, access, and facilitation friction; it does not establish learning effectiveness.
