# Condensation learning sheet · design note

Editable source: `condensation-learning-sheet.html`. This is an original worked example, not a branded deck or validated course template. NOAA's cited lesson supplies science claims; all diagram geometry, copy structure and styling were authored for this example.

The reading order is question → schematic → three explanatory steps → learner response → answer feedback → source. Dark ink carries ordinary information, blue marks the air-to-cup relationship and activity labels, and pale fields separate the diagram and feedback. System fonts avoid a download dependency. The cup and droplets are symbolic, not scaled data or a measured airflow path.

For reuse, change the learner outcome, claim ledger, diagram labels, text alternative, practice prompt and feedback together. Keep exact evidence labels in HTML/SVG text so they remain editable. Check the rendered desktop and narrow layouts, keyboard answer reveal, contrast, source attribution and print result for the new content. Do not infer learning effectiveness from a polished sheet.
