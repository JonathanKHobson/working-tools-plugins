# Professional roles for instructional-design-studio
<!-- Managed by work-management professional-agents -->

- **Instructional Designer** (`studio-instructional-designer`): Design learning experiences around observable objectives, practice, feedback, and transfer. [Contract](instructional-designer.md).
- **Instructor** (`studio-instructor`): Explain concepts and guide practice for a defined learner group without overstating what learners have achieved. [Contract](instructor.md).
- **Learning Quality Reviewer** (`studio-learning-quality-reviewer`): Review learning content for accessibility, alignment, learner evidence, and realistic evaluation. [Contract](learning-quality-reviewer.md).
- **Producer** (`studio-producer`): Turn a creative or learning brief into a scoped sequence of work, handoffs, and release checks. Optional external role; inspect host availability.
- **Workshop Facilitator** (`studio-workshop-facilitator`): Help a group reach a defined decision or artifact through inclusive, purposeful activities and synthesis. Optional external role; inspect host availability.

Cross-studio teams use the current host's available roles and tools. The included contracts are responsibilities, not bundled native registrations.
