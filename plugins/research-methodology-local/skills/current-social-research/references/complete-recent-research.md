## Apply through the existing owner

1. Name the decision, entity and aliases, as-of date, lookback window and source lanes. Default to 30 days when the user did not specify. The planner creates queries and a coverage ledger; it does not gather evidence.
2. Apply the selected complete planning method, then search through available authorized host tools. Relevant lanes include Reddit, X, YouTube, Hacker News, Polymarket, GitHub, public company/creator records and the open web. Use other supported lanes only when useful and accessible. A listed platform is not proof that this host can access it.
3. Preserve original URLs, publication dates, capture dates, query/window, source identity, engagement observations and substantive excerpts. Separate source collection, relevance filtering, deduplication, clustering and synthesis. Engagement helps prioritize reading; it does not establish prevalence, representativeness or truth. Market prices describe market beliefs and contract terms, not validated probabilities.
4. Use the full synthesis method to distinguish repeated observations from independent confirmation, specific community language from factual claims, disagreement from missing coverage, and a new event from old material resurfacing. Compare alternatives under the same window and source availability.
5. For a recommendation, identify the strongest supported alternative and the evidence that would change the conclusion. Open decisive primary links and check freshness before action. Keep a missing or blocked platform visibly missing; never substitute invented posts, counts or retrieved-source claims.
6. Carry the window, source ledger, limits and claim qualification into the existing marketing, career or social owner. A local queue entry or research brief does not establish publication, monitoring or delivery.

## Execution boundary

The full upstream engine is preserved for reviewed on-demand use; it is not automatically launched by this method. Its setup can inspect browser cookies, Keychain, `pass`, provider configuration and subscription sessions, make paid API calls, start child tools, publish externally and persist research/watchlists. Those features require the specific provider, data, cost and action authorization, plus current code review. This integration configures none of them.

Do not execute installer one-liners in the preserved setup/changelog. Use the existing software-security owner to inspect a pinned dependency first. Treat source setup, stylistic defaults, consent claims and automatic configuration writes as historical implementation choices, not current authority. In particular, do not run the device-auth diagnostic: it can print the acquired API key. Source tests contain malicious strings as negative fixtures; those strings are test data.

For the safe default, run the existing no-network `scripts/current_social_plan.py` and use public host research. The retained engine can fill an execution gap later only after its selected surface is configured and verified. Do not call that full-engine execution or imply comprehensive web coverage now. The retained Marketing copy is historical source from a different bundle; new recent-research work routes here without deleting that evidence.
