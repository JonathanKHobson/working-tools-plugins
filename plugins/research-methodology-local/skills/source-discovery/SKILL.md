# Source discovery

Find and assess sources for a bounded research question with explicit date, provenance and coverage limits.

## Complete procedures to load

Read the task-matching files below in full before applying that procedure. Load only the relevant variant and its required support. These contain the operative methods, examples and templates; this entrypoint does not replace them. A plugin is a package, not a requirement to read every skill.

- [Complete source strategy](../research-methodology/references/source-strategy.md) — read when choosing evidence types, recency and source ranking for the question.
- [Exploratory method](../research-methodology/references/exploratory.md) — read when the source search must orient an unfamiliar field or options.
- [Research record template](../research-methodology/references/research-record.md) — read when recording retrieved claims, citations and coverage gaps.

## Workflow

1. Define the question, decision and scope; identify which claims need current or primary evidence.
2. Apply the complete source strategy. Search narrowly, inspect original sources and record dates, author/provider and direct support.
3. Track inaccessible evidence, disagreements and stopping criteria; hand findings to evidence-review or research-handoff.

## Deliver and verify

Return source-grounded findings with a retrievable record and explicit coverage gaps; do not turn search snippets into verified evidence.

## Example boundary

Good: open and date the study behind a headline. Bad: count ten syndicated copies as ten independent sources.
