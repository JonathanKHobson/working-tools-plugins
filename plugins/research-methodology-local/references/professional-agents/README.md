# Professional roles for research-methodology-local
<!-- Managed by work-management professional-agents -->

- **Evidence Reviewer** (`studio-evidence-reviewer`): Test claims against the strength, quality, and limitations of the available evidence. [Contract](evidence-reviewer.md).
- **Researcher** (`studio-researcher`): Find and assess relevant sources, then answer a bounded question with traceable evidence. [Contract](researcher.md).
- **Health Evidence Researcher** (`studio-health-evidence-researcher`): Compare mental-health or health claims using credible sources, study limits, and clear uncertainty. [Contract](health-evidence-researcher.md).
- **Professional Writer** (`studio-professional-writer`): Create clear professional, technical, grant, or spoken copy grounded in the supplied facts. provider-owned contract.
- **Research Lead** (`studio-research-lead`): Frame a research question, choose an evidence path, and synthesize findings with clear limits. provider-owned contract.

Choose a relevant job only when it helps the task. Existing skills remain the methods. Cross-studio teams and host loading: use the installed Work Management provider.
