# Research Toolkit procedure selection

Academic writing, scientific argument review, study planning, qualitative analysis and document-to-method conversion use complete bundled Studio procedures. Read the selected method and its actual support; no separate research-writing, prose or UI method plugin is needed.

| Task | Complete method |
| --- | --- |
| Manuscript structure, academic prose, essay or reviewer response | [Academic writing](../../skills/academic-writing/SKILL.md) and [manuscript craft](../../skills/academic-writing/references/manuscript-craft.md), preserving exact assignment/journal requirements |
| Mechanism, attribution, evidence and claim scope | [Evidence/tool audit](../../skills/academic-writing/references/evidence-and-tools.md) and [evidence review](../../skills/evidence-review/SKILL.md) |
| Decision-linked interview or usability plan | [Research methodology](../../skills/research-methodology/SKILL.md), full [study planning](../../skills/research-methodology/references/study-planning.md), [guides](../../skills/research-methodology/references/study-planning-guides.md) and [records/example](../../skills/research-methodology/references/study-planning-records-and-example.md) |
| Supplied qualitative evidence | [Qualitative analysis](../../skills/research-methodology/references/qualitative-analysis.md), with excerpt lineage, competing interpretations and coverage limits |
| Research to a decision, specification or artifact brief | [Research handoff](../../skills/research-handoff/SKILL.md) and [document-to-method](../../skills/research-handoff/references/document-to-method.md) |
| Source-grounded personas, empathy maps or journey maps | [Full evidence-artifact method](../../skills/research-handoff/references/evidence-artifacts.md): source/case inventory, evidence grouping, complete profile/empathy/journey construction, contradictions, verification and a worked example. Produce the textual artifact directly; `ux-design-toolkit:design-studio` is optional visual production. |

External source retrieval, the Academic Writing Toolkit tool connector and artifact production retain their own actual capabilities. Supplied-evidence work can continue without those optional tools; state an inaccessible source or unperformed tool/format check precisely. A study plan is not participant evidence.
