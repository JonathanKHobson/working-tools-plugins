# Provenance and rights

This package preserves the existing reviewed Brand Library edition associated with `brand-library-foundations-2026-10-07-v2`: 104 authored fictional identities linked to 106 local design templates. `source-files.json` identifies copied bytes and hashes. Source kits and preview images were copied unchanged. They include exact asset registers, logo provenance, native typography evidence and portable font notices.

No blanket license is introduced. Original identity/guide/logo rights and public redistribution authorization remain separate from the font licenses. The fictional names are not trademark-cleared. Source-family dependencies are not bundled when their licenses do not permit it; portable substitutions are explicitly identified in each kit. No official Documents, Presentations or Spreadsheets plugin asset was copied into this package.

The MCP runtime and adapter were authored for this consolidation. Shared chooser files are a byte-identical projection of the maintained local chooser, now owned by Design Templates. Private original host locations, task logs and approval evidence are retained outside this package. Existing external download links are source references, not a new upload or a promise of current availability.


Collection-dependent history and commands describe the maintained source-owner collection. Its bodies and private integrity pins are excluded from public distribution. Bind your own authorized collection before running those commands; the fresh public runtime uses its documented fixture or included eligible kits.
