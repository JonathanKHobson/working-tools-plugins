# Three Small Investigations · layout

## Composition rules

- Use Trebuchet route headings with plain Arial instructions.
- Make the route choice visible before the activities.
- Keep each investigation to a looking prompt, an action and a response.
- Separate optional extensions from the core visit.
- Use blue response boundaries and pale amber guide-dialogue strips; keep route drawings and black instructions distinct.

## Exact originating-format geometry

The following source extracts retain measured units and actual component positions. EMUs, points, cell units and CSS pixels are not interchangeable. They describe the originating template; adapt by relationships when changing format, and retain exact values when reproducing the original.
