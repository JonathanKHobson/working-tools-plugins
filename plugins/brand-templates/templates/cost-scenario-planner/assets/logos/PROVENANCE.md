# Case & Cost logo provenance

Prepared 2026-10-07.

## Source

Derived from the fictional template identity `cost-scenario-planner`. Source typography, palette roles and recognition rules inform the construction. This is an authored reusable identity, not an official identity of an external organization.

Authored logo direction: Use CASE & COST as an Arial wordmark above two unequal parallel ledger rules. No standalone symbol is needed. The paired rules echo inputs and results without suggesting certified financial advice.

## Production

The wordmark is outlined from licensed type and the supporting geometry is drawn as native SVG paths according to this identity’s source direction. No image generation was used for this typographic or geometric construction.

Type decision: Arial → Arimo. licensed metric-compatible production substitute

- arimo, Bold: Arimo-Bold.ttf; license OFL.txt.

The SVG masters are self-contained outlined paths. Text remains scalable artwork rather than live editable text. PNG files are transparent 2× exports of the corresponding SVG, rendered with MuPDF.
