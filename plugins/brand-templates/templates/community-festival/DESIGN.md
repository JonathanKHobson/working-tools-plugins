## Source boundary

Originating template: `community-festival`; visual source fingerprint `cb5010cfd624a765cd538f866fbefa13edf9910d82c15dbeaa9cb065fd3b0f35`. The source is a responsive festival-programme site. Its installed template DESIGN.md and native files contain implementation detail beyond this compact brand kit. They are distinct resources; this kit does not claim to include the full template.

Observed source values and type roles are separated from proposed Common Sun decisions. Semantic role assignments, lockups, recognition rules, and sample copy are proposals. No organization, trademark, or universal design standard is represented as approved. Read the linked format guidance and inspect the actual rendered result; this text is not a substitute for visual QA.

## Application checks

1. Confirm content order, event dates, venues, access information, and primary action against the task source.
2. Use the [layout](LAYOUT.md), [color](COLORS.md), [type](TYPOGRAPHY.md), and [logo](LOGO.md) guidance for the target format.
3. Render the complete deliverable at its intended size and inspect a dense schedule and the smallest expected viewport/page. For print, inspect a grayscale/reverse case and ensure no content depends on color alone.
4. Check font loading/substitution, text wrapping, contrast, clipping, and mark legibility. Compare against source values in tokens and source evidence, not against a single preview alone.
5. Record intentional differences and any unresolved asset/right or rendering issue with the deliverable.
