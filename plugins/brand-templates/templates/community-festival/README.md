# Common Sun brand kit

Open [guide.pdf](guide.pdf) for the visual identity and applications. Use the scalable logos in [assets/logos](assets/logos), with matching transparent PNGs for apps that need them. Fonts and their license notices are in [assets/fonts](assets/fonts).

For an AI assistant, begin with [SKILL.md](SKILL.md), then [DESIGN.md](DESIGN.md). It links the logo, color, typography and layout specifications. The guide can be edited and rerendered from [guide-source](guide-source/README.md).

This is a fictional reusable identity derived from the Community Festival template. Brand version 0.2.0 is a review candidate. SVG logo geometry and outlined type are production artwork; the separately labeled imagegen concept is retained only as source evidence.
