# Common Sun brand application

Start with [DESIGN.md](DESIGN.md), then use its linked guides for the task: [logo](LOGO.md), [color](COLORS.md), [type](TYPOGRAPHY.md), and [layout](LAYOUT.md). The [brand guide](guide.md) gives the complete rationale and status. Exact source observations and rights are in [tokens.json](tokens.json), [evidence.json](evidence.json), and [assets/manifest.json](assets/manifest.json).

Choose content and format before styling. Keep event name, schedule, venue, access details, and actions easy to scan. Use the source template's native structure when working in its site format; for another format, adapt the hierarchy to native components and units rather than copying CSS literally. Preserve facts, functionality, and accessibility. Use only packaged assets or separately cleared user assets.

This is a proposed, source-derived style, not an approved organization identity or trademark clearance. After adapting, render at the actual delivery size. Check a dense schedule, narrow/mobile view where relevant, monochrome/reverse mark, and print/export output where relevant. Verify legibility, contrast, font substitution and line wrapping; record material departures. See the specific checks in [DESIGN.md](DESIGN.md).
