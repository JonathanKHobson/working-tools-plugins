# Print Studio Notes · design specification

A portfolio identity that uses the visual language of a print studio to explain a newcomer’s first visit and the design decisions behind it.

## Identity-defining relationships

- Use Futura display titles with clear Arial case narration.
- Keep primary blue, red and yellow accents against warm paper.
- Give the prototype artifact a prominent place rather than replacing it with abstract diagrams.
