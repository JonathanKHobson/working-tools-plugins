# Print Studio Notes · brand guide

A portfolio identity that uses the visual language of a print studio to explain a newcomer’s first visit and the design decisions behind it.

[View the two-page visual guide](guide.pdf). Version 0.2.1.

## Recognize the identity

- Use Futura display titles with clear Arial case narration.
- Keep primary blue, red and yellow accents against warm paper.
- Give the prototype artifact a prominent place rather than replacing it with abstract diagrams.
- Keep the brief, constraint and proposed response in a readable sequence.

## Use the system

Start with [the logo family](LOGO.md), [colors](COLORS.md), [type](TYPOGRAPHY.md) and [layout](LAYOUT.md). [Components](COMPONENTS.md) and [adaptation rules](ADAPTATIONS.md) retain the originating design's functional relationships. [Writing style](STYLE.md) gives the voice and its factual limits.
