## Font decisions

- display: Portable variant selected. Arial is a separately licensed Microsoft/system font; not bundled. Arimo is available from verified open-font sources; for Arial roles it provides a metrics-compatible portable choice. License: [OFL.txt](assets/fonts/arimo/OFL.txt).
- body: Portable variant selected. Arial is a separately licensed Microsoft/system font; not bundled. Arimo is available from verified open-font sources; for Arial roles it provides a metrics-compatible portable choice. License: [OFL.txt](assets/fonts/arimo/OFL.txt).
- index: Portable variant selected. Courier New is a separately licensed Microsoft/system font; not bundled. Open Courier-compatible monospaced substitute for proprietary Courier New. License: [OFL.txt](assets/fonts/cousine/OFL.txt).

The source family column describes the originating artifact. An included substitute is an intentional portable alternative, not an exact reproduction or a font-name alias. If a user supplies the licensed source family, retain the source family and recheck line wrapping. Outlined logo masters do not require the font to display.

Preserve display/body/support hierarchy and the source sizing relationships below. Do not shrink body copy merely to fit a specimen box. Test long headings, numerals, punctuation and language coverage with the final font; add a line or page when needed. Retain font license and attribution files with any redistributed binary.
