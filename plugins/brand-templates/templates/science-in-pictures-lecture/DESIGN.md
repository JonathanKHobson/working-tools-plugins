# Light and Viewpoint · design specification

A scientific learning identity that uses a small number of well-captioned images to connect a visible phenomenon with a model.

## Identity-defining relationships

- Use Charter for explanatory reading and Helvetica for navigation.
- Give each scientific plate a number, source and useful caption.
- Use restrained green only to guide attention within an otherwise neutral field.
