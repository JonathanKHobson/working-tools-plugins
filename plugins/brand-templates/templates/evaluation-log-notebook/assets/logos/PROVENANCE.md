# Trial Ledger logo provenance

Prepared 2026-10-07.

## Source

Derived from the fictional template identity `evaluation-log-notebook`. Source typography, palette roles and recognition rules inform the construction. This is an authored reusable identity, not an official identity of an external organization.

Authored logo direction: Use TRIAL LEDGER in Menlo with a small open square followed by a record number. Do not use a checkmark as the default symbol.

## Production

The wordmark is outlined from licensed type and the supporting geometry is drawn as native SVG paths according to this identity’s source direction. No image generation was used for this typographic or geometric construction.

Type decision: Menlo → IBM Plex Mono. licensed monospaced adaptation, not exact Menlo

- ibm-plex-mono, Bold: IBMPlexMono-Bold.ttf; license OFL.txt.
- ibm-plex-mono, Regular: IBMPlexMono-Regular.ttf; license OFL.txt.

The SVG masters are self-contained outlined paths. Text remains scalable artwork rather than live editable text. PNG files are transparent 2× exports of the corresponding SVG, rendered with MuPDF.
