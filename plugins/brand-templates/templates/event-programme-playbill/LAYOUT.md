# The Night Window · layout

## Composition rules

- Use Impact for the performance title and Georgia for programme reading.
- Keep cast, sequence and contextual notes in distinct text sections.
- Give credits a clear hierarchy rather than shrinking them into a decorative footer.
- Retain monochrome print legibility in folded formats.
- Use burgundy programme labels with the black condensed title; retain the warm-paper supporting panels.

## Exact originating-format geometry

The following source extracts retain measured units and actual component positions. EMUs, points, cell units and CSS pixels are not interchangeable. They describe the originating template; adapt by relationships when changing format, and retain exact values when reproducing the original.

- [Event Programme Playbill: native layouts](references/event-programme-playbill/LAYOUTS.md)
