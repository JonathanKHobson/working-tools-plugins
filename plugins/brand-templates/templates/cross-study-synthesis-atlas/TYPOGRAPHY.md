## Font decisions

- display: Portable variant selected. Palatino is a system or separately licensed font; not bundled. Open book serif substitute for proprietary Palatino or Charter source dependencies. License: [OFL.txt](assets/fonts/literata/OFL.txt).
- body: Portable variant selected. Palatino is a system or separately licensed font; not bundled. Open book serif substitute for proprietary Palatino or Charter source dependencies. License: [OFL.txt](assets/fonts/literata/OFL.txt).
- navigation: Portable variant selected. Futura is an Apple/system or separately licensed font; not bundled. Open geometric sans substitute for proprietary Futura source dependencies. License: [OFL.txt](assets/fonts/jost/OFL.txt).

The source family column describes the originating artifact. An included substitute is an intentional portable alternative, not an exact reproduction or a font-name alias. If a user supplies the licensed source family, retain the source family and recheck line wrapping. Outlined logo masters do not require the font to display.

Preserve display/body/support hierarchy and the source sizing relationships below. Do not shrink body copy merely to fit a specimen box. Test long headings, numerals, punctuation and language coverage with the final font; add a line or page when needed. Retain font license and attribution files with any redistributed binary.
