# Ready for Review · brand guide

A working identity that helps a maker distinguish completed preparation from evidence still needed before review.

[View the two-page visual guide](guide.pdf). Version 0.2.1.

## Recognize the identity

- Use a blue-gray workspace with clear task labels and evidence notes.
- Keep the summary count separate from individual task details.
- Use rust for unresolved attention points, with text labels beside it.
- Give each task a visible action and a place for supporting evidence.
