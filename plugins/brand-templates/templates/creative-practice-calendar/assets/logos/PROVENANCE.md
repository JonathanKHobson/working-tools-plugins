# Make Room to Try logo provenance

Prepared 2026-10-07.

## Source

Derived from the fictional template identity `creative-practice-calendar`. Source typography, palette roles and recognition rules inform the construction. This is an authored reusable identity, not an official identity of an external organization.

Authored logo direction: Use MAKE ROOM TO TRY as a rounded typographic stack with one deliberately open square beneath it. The square is writing space, not a checkbox.

## Production

The wordmark is outlined from licensed type and the supporting geometry is drawn as native SVG paths according to this identity’s source direction. No image generation was used for this typographic or geometric construction.

Type decision: Arial Rounded MT Bold → Nunito. Portable variant selected. Arial Rounded MT Bold is a separately licensed system font; not bundled. Open rounded sans substitute for proprietary Arial Rounded MT Bold.

- nunito, Bold: Nunito-Bold.ttf; license OFL.txt.

The SVG masters are self-contained outlined paths. Text remains scalable artwork rather than live editable text. PNG files are transparent 2× exports of the corresponding SVG, rendered with MuPDF.
