# The Evidence Shelf · brand guide

An editorial evidence identity that invites browsing while preserving the path back to each source.

[View the two-page visual guide](guide.pdf). Version 0.2.1.

## Recognize the identity

- Use warm paper and brown-rust links with serif reading text.
- Keep record titles, metadata and source details in a stable hierarchy.
- Let filters narrow the shelf without rewriting the evidence.
- Use rules and pale inset fields to distinguish navigation from source content.
