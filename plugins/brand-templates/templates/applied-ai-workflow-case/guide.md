# Trace Practice · brand guide

A technical case identity built around inspectable before-and-after work, explicit boundaries and an authored trace register.

[View the two-page visual guide](guide.pdf). Version 0.2.1.

## Recognize the identity

- Use numbered sections to move from decision to inputs, comparison and complete trace.
- Pair IBM Plex Sans explanations with mono labels for prompts, IDs and limits.
- Keep the proposed output beside the baseline, giving qualifications equal prominence.
- Use pale mint reading areas and gold as a bounded emphasis, never a success signal.
