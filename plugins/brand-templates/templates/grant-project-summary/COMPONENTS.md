# Print Stories Together · components

## Recognition mechanisms

- Use Verdana body text and Trebuchet headings for comfortable document reading.
- Open with the proposed case before budget and delivery detail.
- Separate intended benefits from evidence already available.
- Keep participant activity, staffing and evaluation in distinct sections.
- Use teal budget/delivery table headers with white labels, pale rows and black major titles.

## Native component record

- [Grant Project Summary: native components](references/grant-project-summary/COMPONENTS.md)

These source records provide the actual named shapes, paragraph/table styles, cells or interface selectors. Keep their semantic and functional purposes when applying the brand. A spreadsheet input must still differ from a formula cell; a linked slide or web action must retain a recognizable interaction; source notes must remain close to the claims they qualify.

Logo assets and supporting motifs are different roles. Use motifs where they reinforce section rhythm; do not substitute them for the brand name or imply a missing logo variant. New components must reuse the brand's actual color, type and alignment rules, then receive rendered review.
