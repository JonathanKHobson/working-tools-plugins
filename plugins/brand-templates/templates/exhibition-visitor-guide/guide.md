# Objects and Light · brand guide

A visitor identity that offers a small number of ways to look without telling the viewer what to feel.

[View the two-page visual guide](guide.pdf). Version 0.2.1.

## Recognize the identity

- Pair Optima interpretation with Futura navigational labels.
- Use object numbers as stable anchors from image to caption.
- Give each looking prompt its own space.
- Keep interpretation distinct from object facts and provenance.
- Use rust object labels and route links with dark interpretation text; isolate each object image and its caption.
