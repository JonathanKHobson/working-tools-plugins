# Fieldnotes Workshop brand kit

Open [guide.pdf](guide.pdf) for the visual overview and usage examples. Use [SKILL.md](SKILL.md) with an AI host that supports Agent Skills, or attach this folder for one task. Read [DESIGN.md](DESIGN.md) for the complete specification map.

Included: outlined SVG logo masters, transparent PNG exports, licensed portable fonts, semantic color tokens, source geometry references, brand-specific writing guidance, and editable guide source under `guide-source/`. See [the asset register](assets/manifest.json) for exact files and notices.

Use the SVGs for vector output. Use the included font only under its accompanying license; a source-family dependency may need a user-supplied license. The original native design templates are separate downloads and remain the authority for exact native behavior.

The kit has a bounded application workflow in SKILL.md. It does not need an additional agent persona or automatically executed AGENTS.md. The `DESIGN.md`/support-file names are local conventions; see [Agent Skills](https://agentskills.io/specification) for packaging and [DTCG](https://www.designtokens.org/tr/2025.10/format/) for the token representation.

No universal standard guarantees identical output across AI models. Inspect the actual rendered result, document substitutions and preserve the source facts. The example identity is fictional and its name is not trademark-cleared.
