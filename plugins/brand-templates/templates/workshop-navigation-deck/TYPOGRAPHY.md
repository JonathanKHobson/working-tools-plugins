## Font decisions

- display: Portable variant selected. Avenir Next is a separately licensed Apple/system font; not bundled. Humanist sans substitute for proprietary Avenir/Gill Sans/Trebuchet-like or unspecified system UI source faces; selected from the user's OFL research kit. License: [OFL.txt](assets/fonts/finlandica/OFL.txt).
- body: Portable variant selected. Avenir Next is a separately licensed Apple/system font; not bundled. Humanist sans substitute for proprietary Avenir/Gill Sans/Trebuchet-like or unspecified system UI source faces; selected from the user's OFL research kit. License: [OFL.txt](assets/fonts/finlandica/OFL.txt).
- annotation: Portable variant selected. Chalkboard SE is an Apple/system font; not bundled. Open handwritten display substitute for proprietary Chalkboard and Noteworthy system fonts. License: [OFL.txt](assets/fonts/kalam/OFL.txt).

The source family column describes the originating artifact. An included substitute is an intentional portable alternative, not an exact reproduction or a font-name alias. If a user supplies the licensed source family, retain the source family and recheck line wrapping. Outlined logo masters do not require the font to display.

Preserve display/body/support hierarchy and the source sizing relationships below. Do not shrink body copy merely to fit a specimen box. Test long headings, numerals, punctuation and language coverage with the final font; add a line or page when needed. Retain font license and attribution files with any redistributed binary.
