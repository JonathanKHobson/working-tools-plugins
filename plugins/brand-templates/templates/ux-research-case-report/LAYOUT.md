# The Service Study · layout

## Composition rules

- Use Baskerville for report headings and narrative paragraphs; use Gill Sans for subtitle, metadata, captions and evidence labels.
- Keep study and task near the opening before findings.
- Separate participant observations from the researcher’s interpretation.
- Use dark green-gray table headers with white labels and pale rows; source IDs remain explicit in the black reading text.

## Exact originating-format geometry

The following source extracts retain measured units and actual component positions. EMUs, points, cell units and CSS pixels are not interchangeable. They describe the originating template; adapt by relationships when changing format, and retain exact values when reproducing the original.

- [UX Research Case Report: native layouts](references/ux-research-case-report/LAYOUTS.md)

The guide's applications demonstrate authored extensions; they are not an assertion that all formats share identical geometry.
