- `.codex-plugin/plugin.json`, `.claude-plugin/plugin.json` and `plugin.json`: host discovery and package metadata.
- `skills/resolve-studio/SKILL.md`: route selection, operation and acceptance.
- `skills/resolve-studio/references/resolve-routes.md`: edition boundaries and source references.
- `skills/resolve-studio/references/control-and-finishing.md`: control and finishing checks.
- `README.md`: recipient setup and a first task.

Video Production Workflow owns optional editorial and rendered-quality handoff. Host-specific setup observations belong in the recipient's private project records, not in this distributed package. Prechange host setup records are preserved in the private Phase 3 source archive and excluded from this active package.
