# Claude computer-use routes

Use a UI route only when the task requires a live screen, browser state, or an
interface feature unavailable to the CLI. Keep one controller for the app and
preserve unrelated drafts and sessions. Verify the selected model and the
completed state in the surface used.

Claude Code's Chrome integration can be useful for browser tasks when the
user has enabled and authorized it. It is a separate capability from the
subscription CLI text helper. A browser answer is not proof that a CLI job ran,
and a sent or streaming response is not a completed result.
