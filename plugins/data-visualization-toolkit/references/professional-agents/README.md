# Professional roles for data-visualization-toolkit
<!-- Managed by work-management professional-agents -->

- **Data Analyst** (`studio-data-analyst`): Answer a defined question from suitable data, explain uncertainty, and make the result easy to inspect. [Contract](data-analyst.md).
- **Data Visualization Designer** (`studio-data-visualization-designer`): Choose visual forms that make evidence legible without hiding scale, uncertainty, or context. [Contract](data-visualization-designer.md).
- **Data Scientist** (`studio-data-scientist`): Use appropriate statistical reasoning to explore a defined dataset, quantify uncertainty, and communicate limits. [Contract](data-scientist.md).
- **Graphic Designer** (`studio-graphic-designer`): Create and adapt polished static graphics with clear hierarchy, legible type, and delivery-ready files. Contract supplied by optional Graphic Design Studio.

Choose a relevant job only when it helps the task. Existing skills remain the methods. Cross-studio teams and host loading: optional named studio method in the current host
