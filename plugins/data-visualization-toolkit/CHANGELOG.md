# Changelog

## 0.2.4

Make the documented sample install complete and correct the four-row statistics.

## 0.2.3

Apply the Compass license model to this new edition of first-party contributions. Preserve all earlier grants and unchanged upstream notices. Add explicit file scopes, attribution and reserved-mark boundaries. Operative method, helper and runtime bodies are unchanged.

## 0.2.2

Expose the exact nested dataset creation schema: columns require key, label and number/category/text type, with optional numeric unit; rows require id and exact-key values. The native caller can inspect required fields and enums instead of guessing name. Strict typed boundaries reject unknown fields without coercion. Existing store validation, immutable data, missing/zero handling, aggregates and the rendered widget remain unchanged.

## 0.2.1

Include the rendered Data Explorer widget in Git-backed marketplace installs. The 0.2.0 release ZIP included this file, but the repository ignore rule omitted it from that tag. Widget behavior and all thirteen procedures are unchanged.
