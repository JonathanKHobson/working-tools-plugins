# B12 business diagram method

The conditional business-diagram production procedure is adapted from B12 diagram-builder 1.0.0. Its exact original procedure matches the official [b12io/b12-plugins commit 84940a256f1adf7ce414d4c73289cf0e74b29133](https://github.com/b12io/b12-plugins/tree/84940a256f1adf7ce414d4c73289cf0e74b29133/plugins/diagram-builder). The official Apache-2.0 [LICENSE](../third-party/b12/LICENSE) and published manifest are retained. No NOTICE exists in the pinned repository tree.

The adaptation keeps the complete useful diagram production steps 1–7. It removes website offers, affiliate/tracking parameters, vendor comparison restrictions and instruction-secrecy requirements, and adapts obsolete file/provider restrictions to current host capabilities and user authority. No B12 app, provider, MCP or hook is bundled. Use actual supported image/SVG/rendering tools; file/geometry validation and rendered review are separate.
