# Independent use cases

Select the smallest task owner and read its complete required procedures, examples and templates. The plugin is a package; do not load every skill.

| Skill | Trigger |
| --- | --- |
| [interactive-depth-cards](../skills/interactive-depth-cards/SKILL.md) | Create a standalone HTML or project-local React card with separate art-plane motion, foil, finishes, optional flip and layer views, and accessible static/reduced-motion behavior. No separate provider, API or connected app is needed. |
| [data-visualization](../skills/data-visualization/SKILL.md) | Route data visualization work by analytical question, data shape, delivery surface, and verification need. Use for chart choice, visual critique, or when multiple visualization specialties intersect. This is the discoverable router to the complete Build Web Data Visualization method library. |
| [dense-and-gpu-rendering](../skills/dense-and-gpu-rendering/SKILL.md) | Design and verify dense Canvas2D, WebGL or intrinsic 3D visualizations. Use when mark density, immediate redraw, picking, particles, shaders or scene depth drives the renderer choice. |
| [gantt-and-schedules](../skills/gantt-and-schedules/SKILL.md) | Design, implement or critique Gantt and schedule views involving task spans, dependencies, calendars, baselines, resources, critical path, or project-management imports. |
| [interactive-explanations](../skills/interactive-explanations/SKILL.md) | Build an interactive explanation, chart, calendar, map, diagram, simulation or data explorer within a conversation, or export that visual to standalone HTML. Use bundled original procedures, full MIT methods and actual Data Explorer; route production websites and publication figures to their existing owners. |
| [live-dashboards](../skills/live-dashboards/SKILL.md) | Design or build operational dashboards, monitoring screens and stream-fed visualizations with coordinated interaction, update cadence, stale/offline states and performance limits. |
| [maps-and-cartography](../skills/maps-and-cartography/SKILL.md) | Choose, build or critique analytical and product maps where geography, projection, basemaps, spatial layers or map interaction changes the answer. |
| [reports-and-export](../skills/reports-and-export/SKILL.md) | Package data-rich figures into reports, PDFs, slide decks or documents and plan export assets, regeneration, captions and rendered output checks. |
| [scientific-figures-and-tables](../skills/scientific-figures-and-tables/SKILL.md) | Create or review research figures, benchmark tables, statistical plots, quantitative diagrams, publication exports and evidence-preserving table styles using complete MIT statistical, export and testing procedures. |
| [statistical-evidence](../skills/statistical-evidence/SKILL.md) | Choose and verify displays of distributions, estimates, intervals, sampling, missingness, and uncertainty. Use when analytical distortion is the central visualization risk. |
| [structural-diagrams](../skills/structural-diagrams/SKILL.md) | Design or implement UML, C4, ERD, BPMN, architecture, dependency and node-link diagrams; choose notation, source format, auto-layout and export based on the actual structural question. |
| [visual-stories](../skills/visual-stories/SKILL.md) | Design or implement scrollytelling, parallax, sticky-graphic and staged visual stories where scrolling or scene changes carry evidence. |
| [visualization-verification](../skills/visualization-verification/SKILL.md) | Test and review data visualizations for analytical correctness, visual regression, accessibility, interaction and export. Use when verification or inclusive access is the main task. |
| [web-chart-engineering](../skills/web-chart-engineering/SKILL.md) | Build standard or bespoke 2D browser charts with a declarative grammar, D3/SVG, typed TypeScript, React or Next.js. Use when chart implementation and application ownership are central. |
