# Project map

Purpose: choose and verify truthful visualizations through complete eligible methods and a local saved-table MCP App.

- `skills/`: 14 maintained discovery heads, with complete source routes and original conditional methods/examples.
- `skills/interactive-depth-cards/`: independent local Python/Pillow builder, HTML template, optional project-local React component/CSS/motion hook, art-preparation and input/review references, and design contract. Embeds supplied raster layers in standalone output; no network, account, server or separate app. `tests/test_depth_cards.py` covers output and input boundaries. Edit motion in the template or React hook and keep both routes' interaction contract aligned.
- `libraries/build-web-data-visualization/`: 164 byte-preserved MIT source files, 18 full skills, references, examples, templates and original metadata; additional declared-license terms explain the missing original notice.
- `runtime/data-explorer/`:actual MCP server, SQLite saved-view store, web app, offline preview harness, build configuration and behavior tests. Generated app resource is in `dist/widget.html`.
- `scripts/data_explorer_mcp.py`, `mcp.json`, `.mcp.json`:portable local launcher and server configuration.
- `scripts/resolve_provider_source.py`, `references/provider-methods.md`, `examples/provider-sources.json`: read-only discovery of separately held complete Visualize/scientific procedures and explicit missing-dependency handling.
- `tests/`: launcher precedence, configuration failures and provider-source resolution checks; `runtime/data-explorer/tests/` tests saved-table behavior.
- `references/`:saved-view procedure and professional role contracts/notices.
- `docs/installation.md`, `PUBLIC_DISTRIBUTION.md`, `THIRD_PARTY_NOTICES.md`, `PROVENANCE.json`:standalone setup, exact scope, licensing and file inventory.

Flow: authoritative supplied data → relevant complete method → actual execution owner → data checks and rendered/interaction QA. The native Visualize renderer is optional and separately installed. Its proprietary source and the scientific style corpus without a redistribution grant are excluded from distribution. The same active heads load complete configured provider sources when available, otherwise they use the complete MIT statistical/export/testing methods and identify the missing provider depth. No private Atlas corpus or host-binding configuration is supplied.

Verify all local Markdown links, manifest identities, frozen source hashes, MCP tool/resource metadata, behavioral tests and a real synthetic stdio task. Static/build/protocol success does not establish native app rendering, publication, participant outcomes or external renderer availability.

- The data-visualization and interactive-explanations heads select existing charts/views proactively from analytical and interaction needs. Runtime contracts and render/interaction verification remain authoritative; no dataset or renderer was added.
