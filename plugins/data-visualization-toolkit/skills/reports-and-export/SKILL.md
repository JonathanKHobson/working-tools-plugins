# Reports and export

Read the complete [Reports, PDFs and Slide Automation procedure](../../libraries/build-web-data-visualization/skills/reports-pdfs-and-slide-automation/SKILL.md) before building a figure package or document. Follow its original report structure, PDF generation, PowerPoint/Google Slides and document-embedding references. The preserved [HTML report](../../libraries/build-web-data-visualization/assets/templates/html-report-starter.html), [Playwright PDF](../../libraries/build-web-data-visualization/assets/templates/playwright-pdf-starter.ts), export checklists and editorial examples are available as source templates, with placeholders to adapt to the actual project.

Use the selected document, PDF, slide or web provider for file mechanics. Keep source data, figure, caption and alt summary in a reproducible relationship, then inspect the actual exported page or slide. The [root router](../data-visualization/SKILL.md) governs authorization and surface boundaries.

For publication-grade scientific figures or evidence-preserving analytical tables, additionally load [Scientific figures and tables](../scientific-figures-and-tables/SKILL.md) and its complete required source files. Do not substitute export preflight for scientific integrity or final-size rendered QA.
