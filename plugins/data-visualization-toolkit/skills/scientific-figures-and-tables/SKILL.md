# Scientific Figures And Tables

For the optional Scientific Visuals and Tables route, follow [provider source setup](../../references/provider-methods.md) and run `python3 scripts/resolve_provider_source.py scientific` from this plugin root. When it returns `available: true`, **read the complete procedure at the returned path** and every core reference it requires. The instructions in the following paragraphs apply to that configured complete source. Use the complete evidence lock, visual specification, form selection, final-size implementation, chart/table integrity, adaptive rules and rendered QA procedures. Read its required north-star, style-contract, form-selection, quality-gate, reference-index and token files in full. Apply the original examples and templates; this head provides discovery, not a summary replacement.

Read the source templates, scripts, schemas, reference corpus, provenance and examples under that configured source root; none is bundled in the public plugin. Resolve its relative paths there. Use the deterministic reference selector, Python plotting templates, LaTeX/CSS table templates and QA scripts when appropriate, after inspecting their inputs and dependencies. A script check supplements final-size visual review. The provider's corpus includes URLs rather than all remote image bytes; verify and open the relevant original source when matching a cited figure, and disclose unavailable sources.

User-supplied formats and current host instructions govern style and tools. The source's Astra/OpenAI-inspired style is a design reference, not an official brand standard or a claim about model capabilities. Keep values, denominators, uncertainty and scientific meaning intact. Explicit generative illustration goes to Graphic Design/image generation; mixed tasks retain separate evidence and art paths. For standalone LaTeX, use the host's built-in editor/compiler when available. For in-chat interactive explanations, use `interactive-explanations`; for production web charts, use the other Data Visualization specialists.

Use the full `visual_qa.py` checker with its 8 pt final-size minimum by default. The older tiny `astra_visual_qa.py` helper allows 7.5 pt and checks only two conditions; it is preserved as source, but is not the full quality gate or the default release check. The current requested publication specification takes precedence where it is stricter.

## When the provider source is unavailable

Name the missing provider method, style corpus, reference selector, QA scripts and templates. Use the complete [statistical and uncertainty procedure](../../libraries/build-web-data-visualization/skills/statistical-and-uncertainty-visualization/SKILL.md), [report/export procedure](../../libraries/build-web-data-visualization/skills/reports-pdfs-and-slide-automation/SKILL.md), and [testing procedure](../../libraries/build-web-data-visualization/skills/testing-data-visualizations/SKILL.md), including their task-specific references and templates. Preserve exact values, denominators, uncertainty and final-size readability; verify the rendered export. These are the included MIT methods, not a substitute copy of the ungranted provider system.

Scientific Visuals & Tables 2.2.0 by Navish Kumar has no established redistribution grant in the reviewed source. Configuring an authorized local copy permits this method to locate it; it does not grant publication rights. See [distribution scope](../../PUBLIC_DISTRIBUTION.md).
