# Scientific figures and tables

Read the complete [statistical and uncertainty procedure](../../libraries/build-web-data-visualization/skills/statistical-and-uncertainty-visualization/SKILL.md), [report/export procedure](../../libraries/build-web-data-visualization/skills/reports-pdfs-and-slide-automation/SKILL.md), and [testing procedure](../../libraries/build-web-data-visualization/skills/testing-data-visualizations/SKILL.md), including the linked task-specific references and templates. These are the bundled complete method owners.

Preserve supplied values, denominators, uncertainty, ordering and evidence limitations. Choose the plot for the analytical question before applying styling. Use the requested plotting tool for scientific export; preserve a reproducible source, exact data, dimensions, caption and source note. Inspect the final-size rendered figure/table, check label fit and contrast, compare values and intervals with the authoritative input, and verify the requested export. Scripts alone do not prove publication quality. User specifications and host instructions govern tools, style and authorization.

The separate Scientific Visuals & Tables 2.2.0 source system by Navish Kumar is excluded because no redistribution grant was found in its package or public listing. This public route uses the included MIT methods and does not claim to include that system, its style corpus, selectors, QA scripts or templates. See [distribution scope](../../PUBLIC_DISTRIBUTION.md).
