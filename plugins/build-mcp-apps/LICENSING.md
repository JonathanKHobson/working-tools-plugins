# Licensing

This edition applies the Compass licensing model to Jonathan Kyle Hobson's original contributions: AGPL-3.0-only for code and CC BY-SA 4.0 for documentation, prompts, skills, methods and eligible creative templates. The package aggregate label describes distinct file scopes, not multiple licenses applied indiscriminately to every file.

Read [the code license](legal/LICENSE-CODE-AGPL-3.0.txt), [the documentation policy](legal/LICENSE-DOCS-CC-BY-SA-4.0.md), [brand and attribution](legal/BRAND-AND-ATTRIBUTION.md), [NOTICE](NOTICE.md), [third-party notices](THIRD_PARTY_NOTICES.md) and the machine-readable [scope inventory](LICENSE-SCOPE.json).

The inventory classifies original material, retained upstream material and mixed adaptations using the existing source provenance and source paths. For mixed files, the new grants cover only author-owned additions. Existing upstream licenses, copyright notices, imported LICENSE files, font OFL notices and generated bundle license comments continue to govern the underlying material. Merely calling a file a method does not relicense imported method text.

Prior released versions remain licensed under their original grants. Exact prior license texts and licensing metadata are archived under legal/prior-grants with hashes and their original version. Unchanged bytes previously available under MIT or Apache remain usable under that earlier grant. This policy applies prospectively to the new edition and does not revoke prior permissions. Archive versions and tags are retained, not replaced.

Personal and official marks are reserved as identity marks. Eligible fictional template artwork remains share-alike creative material. Private inputs, corpus excerpts, recipient data and independently supplied provider assets are not licensed by this repository. Third-party dependency code installed by recipients retains its separate terms.
