# Alpic 1.0.1 source provenance

`libraries/alpic-1.0.1/` is a read-only snapshot of the installed vendor cache
from the historical curated Build MCP Apps 1.0.1 cache
captured on 2026-10-06. It preserves the complete `build-mcp-apps` and
`use-alpic` skills, references, plugin manifests and assets used for this local
fork. `LICENSE` was retrieved from the official source:
https://raw.githubusercontent.com/alpic-ai/alpic-plugin/main/LICENSE

The upstream repository identifies the plugin as Apache-2.0 and currently
reports plugin version 1.0.2. This fork keeps the installed 1.0.1 snapshot
separate from current upstream claims. The snapshot is not modified by local
guidance edits.

See `snapshot-sha256.txt` for file hashes. Recompute and review the diff before
replacing the snapshot through a supported plugin update path.
