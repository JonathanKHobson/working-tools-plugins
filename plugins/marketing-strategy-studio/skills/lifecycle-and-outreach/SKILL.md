# Lifecycle And Outreach

When qualifying customers or consuming an ICP/audience brief, apply [customer fit and evidence handoff](../../references/strategy-methods/customer-fit.md). Preserve the relevant profile version/status, intended reader role and claim limits; distinguish fit, readiness, engagement and confidence. This does not add an intake gate to a routine message or authorize sending.

For event follow-ups, imported recipient lists, forwarding variants or unsubscribe handling, read [event email operations](../../references/strategy-methods/event-email-operations.md). This adapter adds list and delivery boundaries to the matching source method; it does not require a marketing campaign process for a routine reply.

For paid-service discovery, proposals, pipeline stages or handoffs, start with the [service-sales adapter](../../references/strategy-methods/service-sales.md), which selects the existing complete sales-enablement and RevOps methods. Do not create a new CRM or duplicate sales workflow.

Start with the matching complete method directly: [emails](../../libraries/marketingskills/skills/emails/SKILL.md), [cold-email](../../libraries/marketingskills/skills/cold-email/SKILL.md). Read only the relevant method and its required support. For a different specialist request, select the full method from [additional procedures](../../docs/procedures/lifecycle-and-outreach.md). Read [source/host adaptation](../../docs/source-host-adapter.md) when a procedure invokes an external provider, source command or setup operation. All unique methods, templates, examples and exceptions remain intact; this head is selective routing, not a summary replacement.

Lifecycle email, newsletters, cold outreach, referrals, SMS and customer communication sequences; sending remains a separate authorized action. Start from supplied facts and evidence; the current user request controls scope, tone, external actions and acceptance criteria. Distinguish proposed, prepared, sent, scheduled, published and measured. The source's named agents, MCPs, CLI commands and account stores are not automatically installed or authorized. Use the actual host provider and disclose missing execution capability. Strategy methods remain usable with supplied data even when an optional provider is absent.

When this skill owns the whole requested deliverable, finish it directly. Use the strategy operator only when audience, offer or cross-channel priorities remain unresolved; do not cycle through sibling skills. Live source research belongs to Research Studio; channel content and previews to Social Content Studio; image-led craft to Graphic Design; general editorial work to Writing Quality; connector/security work to Master Security and Work Management.

The complete original local method also supplies [Channel Rules](../../references/strategy-methods/channel-rules.md). Load the relevant section for local templates or checks; it is preserved in full.

When the deliverable includes copy or a writing brief, use `writing-quality-studio:voice-and-style` if installed and exposed; otherwise use the complete local [copy-editing](../../libraries/marketingskills/skills/copy-editing/SKILL.md) method and current user voice preferences. If available, use it for selectable Writing Voice Lab templates and contextual blends. Honor named choices; otherwise vary suitable structure/openings by audience, awareness, platform, proof and purpose. V01 Decision first, V05 Skeptical investigator, V09 Plain-language service, V15 Spoken invitation, V22 Reflective critic and V23 Conversational micro-essay offer different mechanisms. Use ethical relevance, honest curiosity and supported proof; no invented scarcity, urgency, consensus, guarantees or promised conversion lift. Keep the current user’s approved brand identity and voice preferences stable across outreach and articles; do not assume a named person’s tone for a new recipient. Template choice does not authorize sending or publishing.
