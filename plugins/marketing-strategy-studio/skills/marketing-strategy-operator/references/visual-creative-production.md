# Marketing Visual Production

Use this reference when the requested deliverable is a marketing visual or a
reviewable set of visual directions. Strategy owns the offer, audience, promise,
proof, channel, and decision. The visual workflow makes those choices visible;
it does not supply missing business facts.

## Brief and scope

Record the subject or supplied asset, audience and occasion, channel and
placement, campaign goal, approved claims and exact copy, source evidence,
identity details to preserve, dimensions or safe zones, and the choice the
visuals should help make. For an exploratory request, make a small set of
distinct directions with one asset per option. Vary composition, context,
hierarchy, crop, product placement, or visual treatment deliberately. Do not
invent a price, testimonial, certification, metric, product feature, partner
mark, or endorsement. Mark absent facts as unknown.

Choose the route that matches the request: ad or campaign concepts, offer or
landing hero, product or service scene, camera/crop variant, style system,
positioning direction, logo concept, or chart treatment. When adapting a source
image, preserve the requested subject identity, proportions, materials,
packaging, marks, and approved details. For charts, preserve the data, labels,
ordering, sources, and meaning. Keep exact text, logos, chart values, dimensions,
and safe zones in a deterministic final layer; image generation is for visual
treatment. A concept image is not a final export.

If there is no concrete subject or deliverable, use a brief natural-language
question or the Creative Production starter board when its tool is available;
do not manufacture placeholder creative.

## Available production routes

- Use the host's image generation or editing capability when visual generation
  is requested and available. If the user asks only for a brief or critique,
  stop at that artifact. Do not call an API-backed image runner just because a
  helper exists.
- The installed Creative Production plugin currently owns the
  `creative_production_board` MCP tool. Use it only when the host exposes it.
  Call the tool directly so the host can show its widget. Open one board, keep
  its `boardId`, begin placeholders only when generation starts, then complete
  each item with the matching ID and an existing local image path; mark failed
  items as failed. Reuse the board for selection and revision. Its server stores
  board data and imported images under the user's Codex home. Do not present a
  board as available when the tool is absent.
- The board is a review surface, not an image generator. The original Creative
  Production plugin must remain installed for that interactive board. Its
  proprietary bundled MCP server and helpers are not part of Marketing Strategy
  Studio. Do not point a new MCP declaration at its cache path or copy its
  bundle. Without the provider, use normal local files and the host's visual
  display, and state that the board is unavailable.

For a final channel asset, confirm the required platform specs, keep exact
content deterministic, save the actual export and source/provenance in a durable
project location, then inspect the rendered result at the target size. Map
3–8 source or viewport anchors before making visual claims and verify the
changed anchors. Show what was made, what to compare or select, and which
claims or specifications still need approval. Publishing, posting, ad spend,
account changes, and API charges follow their separate authorization gates.
