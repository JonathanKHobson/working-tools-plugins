# Included marketing methods and execution tools

Copy revision, search content, conversion and ecommerce usability are included Studio workflows. Use [copy-editing](../libraries/marketingskills/skills/copy-editing/SKILL.md), [copywriting](../libraries/marketingskills/skills/copywriting/SKILL.md), [search-and-discovery](../skills/search-and-discovery/SKILL.md), and [conversion-and-offers](../skills/conversion-and-offers/SKILL.md) with complete licensed supporting methods. No separate prose or UX method plugin is required.

For a copy revision, identify audience, offer, proof, channel and intended action. Preserve evidence and qualifiers, remove filler and unsupported promises, make the proposition concrete, and compare the final text with the source. Match supplied voice rather than adding a fabricated customer story. For search content, answer the actual query, preserve meaningful terminology and source links, and use the included search method to check intent, structure and evidence; rankings or AI citations cannot be guaranteed.

For a conversion or commerce task, map entry, comparison, selection, commitment, payment or submission, confirmation and recovery. Identify what users need to know at each decision, including total cost, terms, availability and reversibility. Review labels, form errors, keyboard paths, mobile layout and truthful urgency. Prioritize observed friction and testable hypotheses rather than invented conversion lifts. Use the complete included [CRO](../libraries/marketingskills/skills/cro/SKILL.md), [offers](../libraries/marketingskills/skills/offers/SKILL.md) and [product marketing](../libraries/marketingskills/skills/product-marketing/SKILL.md) methods for deeper work.

Asset generation and account execution use actual host tools. The optional OpenAI Creative Production workflow can coordinate supported creative tools when installed and exposed; it is not required to write a production brief. The included [marketing-creative-production](../skills/marketing-creative-production/SKILL.md), [image method](../libraries/marketingskills/skills/image/SKILL.md), and [brand-design](../skills/brand-design/SKILL.md) own the task. If no image or video tool is available, deliver the concrete brief and distinguish it from a rendered asset. External accounts, spending and publication retain their actual authorization and readback requirements.

Cross-Studio routes are optional. Check an installed sibling before loading it. Without Writing Quality, follow the current user's stated voice, use [copy-editing](../libraries/marketingskills/skills/copy-editing/SKILL.md), and keep factual proof and audience fit from this Studio's first-party methods. Without Research, use supplied evidence and label unanswered facts. Without Social, prepare a manual channel-ready draft and state that platform preview or posting is unverified. Without Graphic/Video, deliver a production brief and mark native asset creation open. Without Work Management, use this package's task map and owner contract. External actions still depend on actual available tools and the current request.
