# Installed provider methods and complete local routes

The local and public Marketing Strategy Studio package is the same implementation. The linked first-party methods and retained licensed source packs are complete task procedures. Optional provider methods are separately installed by their publishers; this package never copies their bodies or activates accounts by naming them.

On a Codex host, check the current skill inventory before loading an installed provider method. The verified IDs are `aihumanizer:marketing-copy`, `aihumanizer:seo-content` from `aihumanizer@openai-curated-remote` 1.0.0; `uiuxdesigner:conversion-optimization`, `uiuxdesigner:ecommerce-ux` from `uiuxdesigner@openai-curated-remote` 1.1.0; and `creative-production:intake`, `creative-production:produce` from `creative-production@openai-curated-remote` 0.1.25. Install or enable the named official plugin through the native plugin manager if the user wants that method and it is available. Refresh discovery in a new host session, verify the specific skill ID, then read that installed skill and its required support in full. Claude loading of those official Codex plugin IDs is unverified. Do not claim access from this document alone.

When the provider is missing or unsupported on the host, keep the task moving with the complete relevant local route: [conversion-and-offers](../skills/conversion-and-offers/SKILL.md) plus [CRO](../libraries/marketingskills/skills/cro/SKILL.md), [offers](../libraries/marketingskills/skills/offers/SKILL.md) and [product marketing](../libraries/marketingskills/skills/product-marketing/SKILL.md) for UI conversion; [marketing-creative-production](../skills/marketing-creative-production/SKILL.md), [copywriting](../libraries/marketingskills/skills/copywriting/SKILL.md), [image](../libraries/marketingskills/skills/image/SKILL.md) and [brand-design](../skills/brand-design/SKILL.md) for creative briefs and production using actually available tools; [copy-editing](../libraries/marketingskills/skills/copy-editing/SKILL.md), [copywriting](../libraries/marketingskills/skills/copywriting/SKILL.md) and [search-and-discovery](../skills/search-and-discovery/SKILL.md) for copy and search.
