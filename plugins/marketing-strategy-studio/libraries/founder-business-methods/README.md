# Founder business methods

Eleven complete business-planning procedures and four standard-library Python helpers, incorporated into the existing Marketing Strategy Studio. Start with the [governing adapter](ADAPTER.md), then the full task method selected by the [focused route](../../references/strategy-methods/founder-business-methods.md). All support, examples and tests are included.

Source: Jake Schincariol, [founder-skill](https://github.com/Jakeschincariol/founder-skill), commit `fd9385b0cfe1b96bebce3898fbd506d73eff5a9d`, retrieved 2026-10-22. The [MIT license](LICENSE) and [original README](README.upstream.md) are retained. `upstream-metadata/` preserves historical plugin declarations as `.source` data; this library registers no plugin, hook, app or provider.

The full methods remain intact with a governing adapter link. Local helper adaptations bound defaults, validate numeric/path inputs, separate synthetic diagnostics from financial scenarios, and label the evidence accurately. The original README's installation steps and marketing claims are historical source material, subject to the adapter. The Product lens is a framework interpretation, never a person or endorsement.
