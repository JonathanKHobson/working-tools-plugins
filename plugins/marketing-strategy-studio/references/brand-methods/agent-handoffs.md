# Bounded brand-specialist responsibilities

These contracts can be used by the host's available workers. They do not install an agent runtime or assert that a custom role is callable. The lead owns integration and verified completion; the human retains identity/design decisions. Use one or two useful independent lanes rather than an automatic committee.

| Responsibility | Inputs and owned output | Boundary / stop condition |
| --- | --- | --- |
| Brand discovery facilitator | Decision, allowed episodes/artifacts, consent boundaries → evidence map, tensions, provisional themes and contextual profile | No personality declaration, channel crawl or adoption of identity on the person's behalf; stop at the requested synthesis |
| Positioning/message strategist | Audience decision, alternatives, supported claims → message ladder and proof/gap map | No invented exclusivity, testimonials or demand; does not turn all personal interests into offers |
| Brand designer | Profile scope, source anchors, references, applications → distinct territories or selected system brief with examples | Craft and rendered QA use existing Graphic/UX/Video owners; a mockup is not live deployment |
| Brand consistency reviewer | Current approved-for-scope rules, output and evidence → specific conflicts, legitimate exceptions and revisions | Does not enforce proposed/rejected rules or overrule current user instructions; technical pass is not personal acceptance |

Every assignment states exact allowed sources, owned files, external-action limits, expected evidence and stop condition. Return observations, interpretation and recommendation separately, with source/anchor pointers. Simulated audience reactions remain hypotheses. Do not transmit private discovery material beyond the authorized worker scope. The project profile is the handoff artifact; no duplicate personal memory store, background monitor or autonomous campaign is implied.
