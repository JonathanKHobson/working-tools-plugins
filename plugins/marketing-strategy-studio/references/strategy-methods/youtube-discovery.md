# YouTube discovery and an honest viewer promise

Use for a video's search/discovery brief, title direction, course-series positioning or catalog refresh. Native uploads and metadata readback stay with Social Content Studio; finished media stays with Video; thumbnail craft stays with Graphic Design. Do not substitute a website SEO audit or advertising setup for this task.

## Establish the actual content

Read the reviewed transcript, lesson objective and render/source receipt. Identify audience, problem, prerequisites, demonstrated result, limitations and next useful action. Keep project names and channel-specific voice in the owning project record. For courses, promise what a learner can practice or make; views and completion do not prove learning. For portfolio or event promotion, use authorized proof and verified current event facts.

Create a compact evidence row: content ID/version, source path and timestamp, audience need, demonstrated outcome, claim limits, intended discovery surface (search, browse, suggested, series/playlist, external), and destination. Unknown search demand is unknown; do not invent volumes or trends.

## Match intent before keywords

Use supplied native search terms or bounded current research to name the question the video answers. Distinguish task/learning intent from product comparison, inspiration and entertainment. Compare relevant search results for the actual need; personalization and changing results prevent treating one observed ranking as universal. Research owns deeper live investigation. Choose natural wording that accurately describes the demonstration, including useful tool/version context where it changes relevance. Avoid keyword stuffing and unrelated trends.

YouTube describes search in terms of relevance, engagement and quality; title, description and video content should match the query. Payment does not buy organic rank. Tags play a small role, chiefly where spelling ambiguity matters. These principles are not a guarantee of discovery. Sources checked 2026-10-01: [search](https://support.google.com/youtube/answer/16090438?hl=en), [tags](https://support.google.com/youtube/answer/146402?hl=en).

## Build the package together

Write only as many meaningful alternatives as the request needs. Each candidate pairs a title, thumbnail concept and opening payoff. Mark the proof timestamp for every outcome or before/after claim. Title conveys a concrete task or useful question; image supplies complementary evidence or tension. Repeating a necessary tool name is acceptable; word overlap is not a failure score. Do not invent a number merely to improve a title score, imply unavailable earnings, or use a face/screenshot without permission.

Handoff table: variant ID | audience/intent | exact title | thumbnail concept | promise/proof timestamp | first demonstration/payoff | limitation | test question. Send Graphic the actual title, source frames, series identity, required facts and placement. Send Video only an identified mismatch between promise and opening; do not rewrite a published video automatically. Native title/thumbnail experiments and receipts route to Social, with analysis through marketing-measurement.

## Prepare discoverable supporting material

Draft a concise description lead that states value and accurate prerequisites. Provide only relevant verified destinations, source/credit disclosures and a coherent next lesson. Use Video's description-chapter procedure on the final reviewed edit; course-site chapter JSON alone does not prove YouTube-valid timestamps. Use captions/transcripts for accessibility and accurate terminology. Playlist membership should communicate a useful learning sequence; evaluate YouTube Courses only after checking live eligibility and the actual instructional structure. Do not infer account capability from documentation.

Deliver copy and a placement checklist with prepared/applied/readback state. Social owns current fields, restrictions and saved metadata verification; this method adds no publishing permission. Review results with the [native performance method](youtube-performance.md) before proposing another refresh. Refresh changing platform rules from official sources at execution, rather than perpetuating fixed dimensions or algorithm folklore.

## Acceptance scenario

A screen-recorded beginner lesson yields an accurate task title, a demonstrable thumbnail idea and a relevant next lesson. The plan contains no made-up search volume, guaranteed rank, universal CTR target or claim of saved metadata. An urgent title revision uses existing context and finishes directly without a new campaign intake.
