# OpenSEO methods in Marketing Strategy Studio

Use for query-to-page mapping, local visibility, SEO competitor comparison, link prospecting, or an evidence-backed SEO report. This is a customized method integration of [every-app/open-seo](https://github.com/every-app/open-seo), revision `db8bde17e245d01f9ca4ab06acaf37fe22aac361`, MIT. All ten complete methods and the original HTML template remain in the conditional library. No OpenSEO server, account, MCP or DataForSEO credits are installed by this method.

## Start from the available evidence

Use the existing owning project and its brief. Record site, audience, offer, country/language, primary conversion, important pages and decision. Fill only missing information that affects the task. Prefer the current user’s first-party Search Console exports, existing course and video catalog, current page content, and supplied research. For free educational offers, useful conversions can be a course start or a qualified subscriber; do not invent revenue or replace the actual project goal with traffic volume. Keep current project names and status in that project, not this shared skill.

## Local host adaptations

Apply these explicit changes when using the preserved source; do not execute source setup commands merely because they appear there.

1. **Evidence mode first.** Read the project's existing evidence and current available tools. OpenSEO `whoami`, project IDs, metric tools and report tools refer specifically to that provider; never call an unrelated same-named tool. With no verified OpenSEO provider, use supplied exports and ordinary public-page research. Replace project context read/write with the owning project record within the requested scope. Do not require an OpenSEO signup, pretend its tools ran, or stop useful work just because the upstream method assumes MCP.
2. **No invented replacement metrics.** An export supports only its actual dimensions, filters, dates and coverage. An ordinary web search is not a geo-controlled rank tracker or a keyword-volume database. Unknown volume, difficulty, CPC, backlinks, competitor traffic or grid rank stay unknown. Skip an unsupported numeric chart. Label qualitative intent mapping as judgment, and incomplete local grids as unavailable. Never fill missing GSC query/page joins by cross-joining separate exports.
3. **Spend control.** Use already available evidence before any paid call. Cached research must match domain, locale, intent and time window; the upstream 30-day suggestion does not establish current rankings. Any later provider use must verify current tool schema, account, price and approved budget. A stated zero-cash advertising preference does not authorize SEO charges, API keys or auto top-ups. No credit-spending discovery calls as a connection test.
4. **Actual authority.** The current user request controls local saves, tool writes, account changes, publishing and sends. Reuse authorization already given; do not add redundant confirmation for local drafts. Source requests to save context or keywords do not authorize remote mutations. Link prospecting prepares evidence and drafts; sending requires explicit human instruction and the existing send review. For an existing public report, editing it is a publishing action because viewers see changes.
5. **Reports work locally.** Default to the requested deliverable in the owning project. The upstream requirements to use `save_report`, stop without its companion, and never save local files do not apply in evidence mode. Use the full report reasoning and optional self-contained HTML template when a report is requested; a short question can receive a short answer. Preserve a user-selected document template and brand treatment over the upstream fixed CSS. Escape untrusted values as text, allow only safe link destinations, avoid remote resources/scripts, and perform rendered QA before a visual report is delivered. Credit the adapted OpenSEO method accurately; do not claim that the OpenSEO app generated or hosted it.
6. **Select a useful next action.** Use the audit's explicit opportunity comparison: inspect relevant page families, retain winning pages, compare the strongest runner-up, tie the recommendation to qualified audience value and distinguish observations from causes. Do not force numbered choices, repeated questions, canned coaching or a large report into every response.
7. **Route downstream work.** Search website intent and evidence here; YouTube discovery uses this owner's existing video method. Social Content Studio owns channel copy/distribution, Graphic Design owns thumbnails and promotional assets, Video Studio owns media production, and Writing Quality reviews prose. A local business profile is relevant only to a real eligible operation; online courses alone do not imply a storefront.

## Done means

The decision is tied to real evidence with dates and limits; queries map to pages without unjustified duplication; unknown metrics remain explicit; one worthwhile next action and its verification are clear. Record sources and changed artifacts through Work Management evidence-review when this is a release or portfolio-worthy result. Installed methods are not proof of a live OpenSEO service.
