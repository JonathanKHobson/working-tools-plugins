# Professional roles for marketing-strategy-studio
<!-- Managed by work-management professional-agents -->

- **Campaign Manager** (`studio-campaign-manager`): Coordinate a bounded campaign from objective and audience through assets, launch, and measurement. [Contract](campaign-manager.md).
- **Marketing Strategist** (`studio-marketing-strategist`): Connect audience needs, positioning, offers, channels, and measurement into a practical marketing direction. [Contract](marketing-strategist.md).
- **Brand Discovery Facilitator** (`studio-brand-discovery-facilitator`): Elicit customer, founder, and market evidence to clarify the brand problem before proposing a direction. [Contract](brand-discovery-facilitator.md).
- **Positioning Strategist** (`studio-positioning-strategist`): Define the audience, alternative, differentiated value, proof, and language that make a position credible. [Contract](positioning-strategist.md).
- **Art Director** (`studio-art-director`): Set and protect the visual concept, hierarchy, and consistency across a campaign or creative deliverable. Contract: see the installed owning Studio when available.
- **Brand Design Reviewer** (`studio-brand-design-reviewer`): Review brand expression for strategic fit, distinctiveness, accessibility, and consistent use across touchpoints. Contract: see the installed owning Studio when available.
- **Data Analyst** (`studio-data-analyst`): Answer a defined question from suitable data, explain uncertainty, and make the result easy to inspect. Contract: see the installed owning Studio when available.
- **Producer** (`studio-producer`): Turn a creative or learning brief into a scoped sequence of work, handoffs, and release checks. Contract: see the installed owning Studio when available.

Choose a relevant job only when it helps the task. Existing skills remain the methods. For cross-studio teams and host loading, consult the installed Work Management role catalog if available; these local contracts remain usable without it.
