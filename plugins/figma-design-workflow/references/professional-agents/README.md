# Professional roles for Figma Design Toolkit

- **Figma Designer** (`studio-figma-designer`): Create and refine editable Figma/FigJam work from named source anchors, then verify changed frames against intent. Read the included [role contract](figma-designer.md).
- **Design Quality Reviewer**: Inspect source fidelity, task behavior, accessibility and the visible result with the included [Design Visual QA](../../skills/design-visual-qa/SKILL.md) method.
- **UI Designer**: Shape layout and states around the current design system and task with the included [Figma Operator](../../skills/figma-ui-operator/SKILL.md) method.

These are responsibilities and methods, not bundled native agent registrations. Choose a role only when it helps the task. If your host supports named roles, verify its actual registration; otherwise supply the included contract to an authorized worker. Cross-studio teams require separately available host capabilities. No Work Management or UX Design Toolkit installation is required for these four skills.
