# Portable export validation

Version 0.1.1 retains all four discovery heads and every source support file, including the complete operator reference suite, templates, 34 behavioral fixtures and packaged structural validator. Only host paths, role routing, discovery wording, structural checker scope/budget, public manifests and export documentation changed. The canonical current checker fails its older 800-word/standalone-skill rules against the maintained 836-word source; this export retains the complete workflow and repairs the checker for the declared plugin closure with a 900-word ceiling. Exact source/output hashes and transformation reasons are in PROVENANCE.json.

Current checks are recorded in the owning Phase 3 evidence/figma-export-validation.json after execution. The checks cover manifest identity, four-head preservation, relative file/heading reference closure, forbidden personal binding scan and the operator structural checker. They do not operate Figma or prove native installation, editable imports, rendered design, participant usability or provider availability.

Run from this package root:

```sh
python3 skills/figma-ui-operator/scripts/validate_skill.py --json
```

Use docs/missing-provider-example.md for the expected response when a connector/control route is unavailable. Use the supplied eval fixtures and actual-editor acceptance protocol only when the current host has the required authorized capabilities. Historical validation in docs/validation.md is preserved as dated evidence and does not transfer to this release automatically.
