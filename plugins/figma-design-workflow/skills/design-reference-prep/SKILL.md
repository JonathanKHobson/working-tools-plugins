# Design Reference Prep

Use one visual direction to advance the user's requested screen or flow. Read [design direction](../figma-ui-operator/references/design-direction.md) for Claude Desktop, conditional Claude Design use, built-in imagegen, and verified Stitch attachment.

Resolve the one design gap and output before opening another tool. Claude consultation helps with reasoning or prior project context; Claude Design can supply a mockup when actually available; imagegen supplies a bitmap reference; Stitch creates screens for editable Figma transfer. These are optional routes, not a mandatory chain.

Use the computer runtime's current contract. Keep the relevant Claude/Stitch project and drafts intact. Send consultation prompts and project data only within existing user authorization. Generated advice and imagery are proposals, not confirmed requirements, user research, functional interfaces, or permission to expand scope.

For imagegen, load the installed imagegen skill and use its built-in default. Inspect input images, preserve approved content, and follow the actual tool schema rather than copied examples. Store the selected project-bound reference at a stable workspace path. Visually inspect it using anchors before sending it onward.

Verify the actual image attachment in the correct Stitch draft/project, with a prompt stating what the image guides and what textual requirements override it. Keep one accepted direction and request the named screens. Report generated, selected, attached, and generated-as-screens as distinct states.
