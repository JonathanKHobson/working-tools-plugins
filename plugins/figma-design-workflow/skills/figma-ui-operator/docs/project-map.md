# Figma Operator package map

- `SKILL.md`: discovery, scope, observe/act/verify workflow, guide routing.
- `agents/openai.yaml`: display name, invocation prompt, normal automatic discovery.
- `references/runtime.md`: current runtime entry contract, UI/API routing, handoff.
- `references/design-direction.md`: optional Claude/imagegen preparation and verified Stitch attachment.
- `references/stitch-to-figma.md`: source selection through editable import verification.
- `references/import-and-presentation.md`: arrangement and recorded failure lessons.
- Other `references/`: task-specific Figma procedures and dated source ledger.
- `assets/`: optional session, calibration, and evaluation templates.
- `evals/evals.json`: unrun behavioral fixtures; results belong outside the fixture.
- `scripts/validate_skill.py`: offline metadata, internal links, and package checks.

Read the entrypoint, runtime, and only the guide for the requested operation. Edit a behavior in its owning guide, update relevant fixtures, and run the validator. Do not encode live project IDs, credentials, screenshots, persistent coordinates, or private recordings in this reusable package. The outer release kit owns installation documentation, non-overwrite installer tests, build evidence, and checksums; those are not operating instructions.
