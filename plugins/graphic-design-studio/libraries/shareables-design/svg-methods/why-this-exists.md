## Why This Exists

SVG is a strong medium for agent-made visuals because it is text, inspectable, diffable, scalable, and safe to inline in single-file HTML when validated. The weakness is that AI-generated SVG often drifts into generic symbols, broken paths, noisy geometry, inconsistent style, weak accessibility, and unreadable small-size details.

The quality target is a visual system, not a one-off drawing:

- Data before drawing.
- Tokens before style.
- Grammar before variation.
- Determinism before randomness.
- Semantic variation before decoration.
- Validation before integration.
