## Style-Source Expectations

Each style source should have a distinct visual posture. Passing the gate means the samples are not the same icon recolored six times.

| Style source | Visual posture |
| --- | --- |
| `core-utility` | Plain, direct, clean, practical, low ornament. |
| `warm-editorial` | Paper-like, tactile, friendly, offset, warm. |
| `structured-bridge` | Organized, relational, modular, sturdy, slightly editorial. |
| `product-studio` | Polished product UI, precise geometry, high signal, modern controls. |
| `dark-analytics` | Instrument-panel clarity, luminous data accents, restrained contrast. |
| `research-academic` | Evidence-first, annotated, calm, reference-like, citation-aware. |
