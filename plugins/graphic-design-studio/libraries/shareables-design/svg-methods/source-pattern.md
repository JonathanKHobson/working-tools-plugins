## Source Pattern

The transfer pattern from the SVG skill lab is:

```text
visual brief
  -> style tokens
  -> shape grammar
  -> semantic motif slots
  -> generated SVG family
  -> technical validation
  -> small-size visual review
  -> human feedback
  -> recipe repair
  -> only then integration
```

For Shareables, that becomes:

```text
Shareables style source
  -> icon role and audience
  -> named concept ledger
  -> token-constrained SVG grammar
  -> utility control samples plus personality samples
  -> gallery at 24, 32, 48, 96, and display size
  -> review packet
  -> Kyle approval or recipe revision
```
