# Graphic design specification handoff

Deliver `DESIGN.md` alongside a designed artifact's editable source, or at its
template skill root with a relative link from `SKILL.md`. Its job is to preserve
the specific visual decisions that another person or AI needs to adapt it.
Reuse the source's existing specification. The UX Design Studio design-systems
owner maintains the portable Google DESIGN.md alpha adapter and full template
contract; do not duplicate that format or install another runtime here.

In that existing entry, distinguish the reader/job and content selection from
structural template and style choices. For a new or materially adapted medium,
record include, exclude/retained destination, priority, region budget and an
observable check. Follow [medium content planning](../../campaign-format-adaptation/references/medium-content-plan.md) for a filled example and recomposition decisions; preserve evidence and necessary qualifications when shortening copy. A small update reuses the current contract.

Capture the real palette and element roles, type hierarchy, page/canvas sizes,
margins/grid, recurring components, image placement/crop, logo clear space when
specified, source assets and permitted adaptations. Distinguish observed values
from approved rules and unknowns. Retain native print units and color profiles;
web CSS tokens do not encode a complete print specification. A raster image
does not establish the original font family or editable geometry.

Keep a small design in one document. Split typography, colors, layouts,
components or adaptation rules into linked Markdown only when detail warrants
it. Preserve asset/font notices and identify missing licensing evidence without
granting rights. For a PDF, include the editable source when available; document
reconstruction limits otherwise. Execution steps belong in the template skill;
per-template role-play personas or duplicate AGENTS.md files add no fidelity.

Verify all relative references from an extracted bundle, source fingerprints,
and representative rendered anchors using Graphic Design Review. Record the
renderer, font substitutions and untested print conditions. Specifications
support reproducibility; they do not establish identical cross-model output,
printer acceptance or a universal AI industry certification.
