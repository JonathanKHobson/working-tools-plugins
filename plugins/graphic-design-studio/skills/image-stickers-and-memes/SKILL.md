# Image stickers and meme layouts

Keep stickers and memes as distinct jobs. A sticker is a reusable isolated asset that must read at small size. A meme is a composition whose exact copy, image reaction and timing work together. Inspect the source before editing, preserve identity-bearing details, and use the user's supplied brief. The host's built-in image tool may generate or edit inside the conversation when available and authorized; this workflow requires no separate API, account, app, renderer or service. A user who explicitly requires offline local computation stays on the Pillow route and must supply source alpha or a mask for a subject cutout.

## Sticker construction

For an opaque photo needing an isolated subject, use the built-in image-editing tool with the inspected source as a reference and request genuine transparency. Identify the subject boundary, fragile parts, distinctive colors or marks, and any source text before generation. Set transparent background when requested. Inspect the saved alpha result at full size and as a 128 px preview. Native generation can change proportions or add a broad halo; reject that candidate and repair it, or use a verified source mask with the local helper for a faithful edge. A geometric crop is an explicit alternative, never evidence of segmentation.

If the user has not selected a style, start with a Clean Cutout: faithful subject, tidy silhouette, medium white edge, subtle short shadow and transparent surroundings. Other source-led interpretations are Emoji (stronger expression and simpler forms without lost identity), Label (flatter compact badge-like print treatment), and Die-cut (production-clean tactile edge with optional slight registration variation). Keep one coherent subject or group, simplify internal detail only enough to survive chat size, preserve exact source wording and identity cues, and avoid new props, sparkles, facial features or decorative icons unless requested. An outline should be continuous and optically even; widen narrow gaps when the border would close them. Keep shadow soft, short and secondary. Respect user-selected outline, shadow and background choices over defaults. A new sticker from text is possible only when requested; otherwise require the source image.

## Meme copy and layout

When the user supplies words, keep exact language, case, punctuation, emoji, line order and explicit line breaks. Do not translate, paraphrase, sanitize or invent replacement wording. If the brief asks to approve wording before final copy, propose two or three short options and wait for the user's choice before rendering text. If the user authorizes generated copy, keep it concise and avoid impersonation or fabricated claims.

Choose a deliberate reading order: image beat first or caption beat first. Keep faces, gestures and reaction cues clear. Top + Bottom supports a two-beat setup/payoff; Top or Bottom supports one premise or reaction. Poster integrates exact copy into a designed field with a chosen aspect ratio and expressive type/image relation, using the native image tool plus direct copy verification or controlled typography. The local Pillow helper supports only top/bottom white caption text with black stroke at the source's native oriented dimensions; it is not a poster-layout engine. Tone may be Playful (friendly exaggeration), Dry (restrained deadpan) or Dramatic (stronger scale and contrast without invented facts); a user-defined tone takes priority.

Prompt the native tool with the exact copy and intended breaks, then inspect every visible character at delivery size. If it alters words or emoji, use controlled text composition or repair and verify again; do not report the generated preview as exact. Proofread mobile readability, safe margins, reaction visibility and selected aspect ratio. Preserve source identity without unrelated people, logos or events.

Create a derivative from a user-supplied source, preserving its identity-bearing details. The optional [local composition helper](scripts/compose.py) uses an already available Python 3.9+ interpreter with Pillow 10.1+ (tested with Pillow 11.3.0). That helper makes no API calls, uploads or installs; it writes only the selected output file and, during explicit overwrite, a temporary file beside it. Use only files the user is authorized to adapt. If the requested sticker or meme depends on a source image and none is available, ask for it; do not fabricate a cutout or substitute an unrelated generated subject. A text-origin sticker is a separate explicit request.

For the deterministic local helper, choose the mode that matches the actual source. `sticker --shape cutout` requires meaningful source transparency or a separately supplied matching grayscale/alpha mask. The helper trims visible alpha, adds transparent padding and a white or selected border, and keeps the original visible pixels at native size. A supplied mask is a stencil, not evidence that the correct subject was segmented; inspect it against the photo and preserve identity-bearing details. An opaque photo without a mask can become a `rectangle` sticker retaining its full frame, or a `circle` sticker with an explicit center square crop. Neither geometric mode extracts a subject. For an opaque-photo subject cutout in an offline-only run, obtain or create a mask through a separately authorized method and inspect its edges before passing it here. Do not silently invoke a network model or relabel a rectangular crop as background removal.

`meme` places top and/or bottom caption text on the EXIF-oriented image at its native dimensions. It preserves explicit newline breaks and wraps only within each supplied line. It resolves a local bold font from the script's documented list or takes an explicit local `--font`. The output line reports the actual font path. Text wraps within a 5% safe margin and each caption has a bounded top/bottom region; font size reduces only to the chosen minimum. If the text cannot fit legibly, preserve the exact copy and use a larger image or an explicit alternate layout; propose shorter wording only for the user to approve. The helper fails rather than clipping. Captions use white text with a black stroke; inspect contrast and glyph support against the specific image and font.

Run `python3 scripts/compose.py --help` and the selected subcommand's `--help` from this skill folder. Example commands, with paths changed to the actual files:

```bash
python3 scripts/compose.py sticker /path/to/transparent-art.png /path/to/sticker.png --shape cutout --padding 16 --border 12
python3 scripts/compose.py sticker /path/to/photo.jpg /path/to/photo-sticker.png --shape circle --border-color '#ffe066'
python3 scripts/compose.py sticker /path/to/photo.jpg /path/to/masked-sticker.png --shape cutout --mask /path/to/mask.png
python3 scripts/compose.py meme /path/to/photo.jpg /path/to/meme.png --top 'WHEN THE TESTS PASS' --bottom 'ON THE FIRST TRY' --font /path/to/local-bold.ttf
```

The output directory must exist. Output is PNG and is never replaced unless `--overwrite` is explicit; input and output cannot be the same file. Inputs must be local raster PNG/JPEG/WebP/TIFF/BMP, at most 50 MiB, 8192 pixels per side and 40 million pixels. SVG, URLs and data URIs are rejected. EXIF orientation is applied before masking and composition; a separate mask must match the oriented dimensions. The helper does not remove photo backgrounds, synthesize captions, detect faces, create poster layouts, infer rights, or certify platform upload specifications. The built-in image tool can isolate an opaque-photo subject and render an expressive layout, but its actual result still needs transparency, identity, text and dimension verification.

Inspect the saved artifact itself. For a sticker, check subject identity, edge and border at full and 128 px size, transparency, trim, narrow gaps, shadow and crop. For a meme, check every visible character, explicit line breaks, safe margins, focal obstruction and readability at intended display size. Report the source, selected mode, actual dimensions and font when relevant, and whether the derivative was visually reviewed. A successful command establishes a saved derivative, not aesthetic acceptance or publication.
