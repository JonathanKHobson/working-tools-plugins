# Animate a supplied still image

Use when the user wants a short animated image, loop or video from one supplied still. Read the actual image before choosing motion. Preserve the source's identity, physics, composition and approved style. This method does not require an external renderer or app. Use a built-in ChatGPT video capability only when one is actually available for the task; follow that capability's source-image instructions. If it is unavailable, deliver a production-ready motion brief or storyboard and state plainly that no video was rendered.

## Plan the shot

1. Separate foreground, subject, middle ground and background only where the source supports those layers. Do not invent depth behind an occluding person or object as if it had been observed.
2. Mark protected regions: faces, hands, readable text, logos, architecture, rigid geometry and identity-bearing subject details.
3. Choose one dominant motion idea. Avoid piling camera, light and subject movement together to make a still seem active.
4. Record the intended aspect ratio, duration, strength and loop behavior from the user. Infer a restrained value only when it is routine for the requested result; mark unrendered timing as planned, not observed.
5. Specify first frame, middle change and final frame. For a loop, describe the reset as well as the expressive motion.

The motion families are:

- **Parallax:** restrained source-supported layer separation with plausible depth; inspect for cardboard edges and exposed gaps.
- **Push in:** one smooth camera move toward a stable focal anchor, protecting crop and source geometry.
- **Light flow:** localized movement in reflections, haze, water, light or shadow only where the scene can plausibly support it.
- **Subject motion:** small source-consistent movement such as breathing, fabric, foliage, water or an intentional gesture; keep face and body identity stable.

Subtle means barely perceptible motion; Balanced uses one readable effect; Bold allows controlled emphasis without chaos. Keep text, signage, faces, fingers and rigid lines from morphing. Do not invent audio unless requested.

## Execute and review

When a native video tool is available, supply the inspected still, protected regions, selected motion family, aspect ratio, duration, strength and loop intent. Review the actual first, midpoint and final frames plus playback at delivery size. Check identity drift, edge tearing, geometry wobble, unwanted text mutation, abrupt speed changes and loop discontinuity. For a loop, compare opening and ending framing, velocity, light and pose. A rendered file and reviewed playback are separate states.

If no native video tool is available, return a concise shot specification containing source image, protected regions, one chosen motion family, first/middle/final frames, duration, strength, aspect, loop reset, and the exact checks above. Label it as an unrendered brief or storyboard. A Video Production handoff is optional when the user's tool constraints allow it; do not present the handoff as a completed video or require a separate app.
