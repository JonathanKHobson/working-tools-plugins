# Vector asset checks

Use when integrating supplied SVGs or producing vector work permitted by the current host and task. This is not permission to substitute hand-coded illustration for a required image-generation workflow. Sites has its own restrictions on representational SVG/CSS artwork; consult its current skill when it owns the deliverable.

State what the asset communicates and whether it is functional, meaningful, decorative or quantitative. Keep recognition-bearing shapes separate from optional ornament. For an icon family, decide which details disappear at small display sizes and inspect actual outputs at the smallest intended size, normal use size and enlarged detail size. Do not apply a fixed shape count, four-color quota or universal 24px requirement to every project.

Check the visible silhouette, centers, bounds, repeated strokes and alignment. Mathematical symmetry is useful evidence when symmetry is intended; it does not replace optical balance or justify centering an intentionally asymmetrical mark. A complex path or a valid SVG document alone establishes neither recognition nor quality.

Use the approved project's color roles and test relevant foreground/background pairs. Decorative accents must not be confused with warnings or data. Keep meaningful shapes distinguishable without relying only on hue. Derive family consistency from shared proportions and roles, not merely recoloring the same unrelated motif.

Before reuse, inspect the SVG as source as well as rendered art: viewport and clipping, external resources, scripts/events, embedded private paths, IDs that collide when composed, and unescaped inserted text. Treat unknown files as untrusted; do not execute embedded behavior. Preserve a trusted original and resolve required external dependencies deliberately.

For digital integration, hide purely decorative assets from assistive technology; give meaningful and interactive assets appropriate accessible names through their actual host component. A static image export does not test that integration. Check clipping, masks and exported appearance separately.

Rejected samples, paused themes and exploratory galleries remain reference evidence until approved. Do not promote an old example to a reusable default just because it exists in a repository. A repeated family-wide problem belongs in the family's existing guidance; an isolated artistic choice does not become a universal ban.
