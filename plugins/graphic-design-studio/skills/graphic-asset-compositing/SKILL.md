# Graphic asset compositing

Inspect the actual sources before deciding placement. Identify each asset's purpose: identity, evidence, explanation, subject, or atmosphere. Record origin, intended use, original file, derivative, and any known permission limits in the project's working notes. Do not infer permission from a download or a previous private use.

Preserve originals. Use separate layers or derivatives for masks, crops, tonal adjustments, and effects. Keep exact text, brand marks, and machine-readable codes under direct control. Generated art may establish mood, but cannot prove real attendance, customer results, or actual gameplay.

For a selected editorial, flat graphic or collage rebuild of a supplied still, use [source-image-reconstruction](../source-image-reconstruction/SKILL.md). Its full visual grammar and quality rubric apply to that chosen image direction, while the user's brief and project brand retain priority.

For a sticker or captioned meme from a supplied image, use [image-stickers-and-memes](../image-stickers-and-memes/SKILL.md). The built-in image tool may isolate an opaque subject or render an expressive poster layout when available and authorized. Its deterministic local helper requires source alpha or a supplied mask for a true cutout; geometric photo stickers preserve the frame or use an explicit circular crop. Neither route requires a separate external app or API.

For an explicitly requested image-to-3D asset, to3D is an optional external generation provider with glTF output. It remains a separate service, not a capability recreated by this plugin. Inspect its current upload/URL contract, source rights and any cost or authorization requirements before submitting; use the returned job identity for status and retrieve the actual result. Verify geometry, materials and the intended importer separately. If unavailable, preserve the 2D source and disclose the missing 3D route rather than calling an image or mockup a model.

For permitted vector/icon work or integration of supplied SVGs, use [vector asset checks](references/vector-assets.md). Resolve meaning and small-size behavior before adding decorative detail; the current host's image-generation and Sites rules still govern how imagery is made.

When a supplied SVG must animate or become Lottie, use [animated vector fidelity and interop](references/animated-vector-interop.md) for structure, target-specific support, frame range, and visual comparison. Preserve the source and name the actual player; a static SVG check cannot verify moving masks, morphs, or export fidelity.

For image generation or editing, use the available image tool according to its current instructions and the user's chosen workflow; route built-in image edits through `imagegen` when available and inspect the supplied reference first. Set a source-specific communication job before generating and apply [generated object consistency](references/spatial-contact.md#generated-object-consistency) when the scene depicts physical relations. Use native transparency when supported; chroma key is an optional fallback with spill and edge-quality costs. Reopen the actual saved result, confirm its dimensions and source detail, and place that file. An inline preview alone does not establish a reusable project asset.

Integrate images through crop, scale, overlap, direction, and a common visual environment. Match edge sharpness, light direction, color temperature, perspective, and texture when realism matters. Deliberate collage can violate realism coherently; name that style rather than judging it by photographic rules.

If an object must grip, wrap around, emerge through, sit on, or cast a shadow onto another, define the front/back relationship first. Read [spatial contact](references/spatial-contact.md). A dark halo or rotated sticker does not by itself create contact. Preserve the identity-bearing details the brief requires.

For text over art, first move or crop the image into a quiet reading area. If that is insufficient, use a local theme-appropriate field, controlled shadow, or contrast adjustment. Do not flatten a strong whole image unless that is the intended art direction. Protect QR quiet zones and logos from decorative effects.

Verify full-page integration and detailed edges separately. Repeated decorative stamps, clipped silhouettes, matte fringes, accidental tangencies, and conflicting shadows require rendered inspection. Keep asset IDs, prompts, and QA notes out of visitor-facing copy. If the task asks for integration, deliver the integrated graphic rather than only loose assets.

For permitted SVG/icon visual-system work, read and apply the complete procedures in [the Shareables method map](../../docs/shareables-svg-procedures.md), including its templates and size/accessibility/geometry checks; the shorter vector checks do not replace that method.

For generated media or a handoff to video production, apply the complete [operation, required-media and receipt method](references/generated-media-handoff.md). Validate the actual provider schema before generation, preserve references and keep submitted, downloaded and visually accepted states separate.

For an icon-library search or retrieval gap, read the complete [icon discovery and rights workflow](references/icon-discovery.md). It uses a bounded optional lookup helper, preserves collection-specific licensing, and keeps project mutation and visual acceptance with the current design task.
