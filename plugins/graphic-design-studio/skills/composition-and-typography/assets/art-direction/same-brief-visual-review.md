# Proposed worked review: same brief, different directions

Give three designers one immutable fictional brief (use `examples/README.md`). Require each direction to answer a different reader task, with a one-sentence rationale and a complete artifact. Do not count palette changes as a new route.

For A, inspect whether “room for yours” and the four empty modules make the contribution path understandable; check that twelve existing workshops and every event condition remain readable. For B, inspect whether the opening question attracts without hiding exact logistics and whether the dense list scans by topic. For C, ask a reader available only Thursday to find eligible courses and week ranges while distinguishing the event date from term schedule.

Use the existing `graphic-design-review` anchor map with three to eight regions per artifact. Record source + viewport/page, approximate region, observation, intended correction and recheck. Test at desktop/poster scale and narrow mobile; a CSS parse or text search alone is not visual QA. For a print claim, inspect a correctly sized physical proof. Evaluate concept fit, coherence, clarity, originality, accessibility and production feasibility separately; never turn them into an invented aggregate score.

Transfer checks: (1) A twelve-course infographic must preserve categories, times and an understandable comparison purpose. (2) An information-dense dashboard must preserve units, states, real controls and severity ordering; reject the attractive equal grid if it hides exceptions. (3) A brand-constrained version must use the existing mark/type/palette, changing reading route without gratuitous redesign. These are proposed tests until executed.
