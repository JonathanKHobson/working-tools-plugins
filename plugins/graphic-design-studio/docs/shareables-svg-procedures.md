# Full SVG visual-system procedures

For permitted SVG/icon work, read the complete relevant method blocks below, including concept ledger, construction, palette, shape budget, size degradation, accessibility, verification and failure examples. These are complete original sections, not summaries. The approved current brief controls style, palette and geometry; historical Shareables palette tables and Kyle approval statements describe their source project, not universal rules or fresh permission requirements. Respect current image-generation/tool rules. Technical validity is separate from rendered visual quality.

The dated rejected gallery and private review ledger remain in the external Shareables project. No rejected asset is imported, approved or promoted by this merge. Source project state is historical; this merge adopts reusable procedures only. Original CC BY-SA documentation and attribution notices are retained.
