# Project map

- `skills/motion-design/references/motion-pattern-recipes.md`: sixteen original screenshot-informed effect recipes, source anchors, prompts and verification criteria; no imported board or runtime.

- `skills/motion-design/references/reference-to-motion-prompt.md`: reference-transfer and targeted-repair prompts, with UX/Sites versus rendered-media handoff.

This plugin contains focused design skills and the read-only Image Gen Templates MCP. It has no account credentials or hooks. The optional `scripts/icon_library.py` helper performs explicit public Iconify GET requests and returns JSON to stdout; it has no project-file access or persistence.

- `.codex-plugin/plugin.json`: plugin identity and discoverable skill root.
- `skills/graphic-design/`: end-to-end direction; cited research lives in its `references/` folder.
- `skills/infographic-design/`: static information graphics and composed explainers; quantitative chart decisions and transformations remain with visualization specialists.
- `skills/promotional-design-copy/`: message and claim decisions.
- `skills/composition-and-typography/`: layout, type, and color; deeper decision guide under `references/`.
- `skills/graphic-asset-compositing/`: image integration; spatial-contact guide under `references/`.
- `skills/campaign-format-adaptation/`: composition across channels and dimensions. Its `references/medium-content-plan.md` applies the UX-owned content contract with original filled print/feed/story/web/slide examples and paired review cases; Graphic Design owns recomposition, not a parallel schema or web provider.
- `skills/motion-design/`: visual direction, styleframes, kinetic type and review across time; Video Production owns timed scenes, rendering, audio and narration.
- `skills/motion-design/references/illustrated-vector-sequences.md`: conditional source-to-pose, paint-order and playback review for illustrated SVG sequences.
- `skills/graphic-asset-compositing/references/animated-vector-interop.md`: conditional animated SVG/Lottie fidelity and player feature matrix; `docs/motion-svg-source-notices.md` records source and licenses.
- `skills/graphic-design-review/`: rendered review and teachable critique.
- `skills/print-and-export-preflight/`: output checks; optional read-only PDF inspection script under `scripts/`.
- `docs/`: package provenance, ownership, validation, and integration decisions. Three complete standalone heads live under `skills/hatch-pet`, `skills/html-presentation-builder`, and `skills/lavish-axi`; `provenance/standalone-source.json` records their source hashes and rights. Original local review receipts remain in the author’s source archive where their private path and dated host state are relevant.
- `docs/distribution.md`: eligibility, source boundaries and verification scope.

Every skill owns its instructions and UI metadata. Sibling links remain relative inside the package. Read the main skill first, then only the relevant specialist and reference. Research is supporting evidence, not a required reading assignment for every flyer.

Put future format-specific instructions with format adaptation, compositing lessons with compositing, and deterministic file inspection with preflight. Infographic design owns static composition and explanatory structure; Data Analytics and Build Web Data Visualization own quantitative transformations, chart selection, and chart encoding. Do not add dashboard runtimes, persistent remote asset providers, broad marketing strategy, social scheduling, or publishing automation here. Original source skills remain independently maintained.

The PDF checker uses Python with PyMuPDF. QR decoding additionally needs Pillow and zxing-cpp; those dependencies are optional until QR checks are requested. It does not install packages. Preview rendering and JSON reports are written only to explicitly supplied output paths. A structural or mechanical pass cannot certify aesthetics, rights, human approval, or print-shop acceptance.

For maintenance, run the system skill-creator validator for each skill and the plugin-creator validator for this root. Recheck relative links. Exercise any changed script with a good file and a deliberately failing file. Reinstall a changed local package using the plugin-creator cachebuster flow; new tasks pick up the installed skills.

## Full-fidelity additions

AI Graphic Design and the complete Visual Production Workflow are integrated. Complete conditional source trees retain examples/templates/supporting files; active heads require reading selected full procedures. Private use and provider availability remain distinct from public redistribution or connected runtime verification.

Art direction: `skills/composition-and-typography/references/art-direction-brief-selector.md` selects five complete `direction-cards/` methods. `assets/art-direction/` preserves original examples, full evaluation fixtures and source/rights records. Precedent transfer extends the existing `graphic-design/references/design-sources.md`; no new production provider or style presets are registered.

Video-thumbnail concept method: `skills/campaign-format-adaptation/references/video-thumbnail-concepts.md`; retained MIT reference source in `libraries/youtube-packaging-source/`. Graphics owns the actual image, Marketing intent/measurement and Social native delivery. No new runtime or provider.

Icon discovery: `skills/graphic-asset-compositing/references/icon-discovery.md` owns selected public catalog lookup, per-collection license checks and local asset handoff. `scripts/icon_library.py` is an independent standard-library helper; `tests/test_icon_library.py` checks request and passive-SVG boundaries. `libraries/better-icons/` retains the inactive source method and MIT provenance; upstream MCP, configuration mutation and home usage history are excluded.

Procedural-video art direction stays in `skills/motion-design/`; the Video Production owner routes complete Animate/Charlie methods and the shared video-style selection surface. No additional Graphic template catalog or renderer is registered.

- `runtime/image-workflows/`: original bounded image recipe catalog, validated read/search/prepare tools and domain editor adapter. It reads Design Templates’ canonical `runtime/library-chooser/` at render time, or the existing local UX compatibility projection when present; no copied generic runtime.
- `scripts/image_workflows_mcp.py` and `.mcp.json`: launch using an explicitly prepared interpreter or the existing recipient-owned studio-tools interpreter binding and Design Templates chooser.
- `skills/graphic-design/references/image-workflows.md`: canonical cross-domain guidance; official imagegen remains the execution owner.
- `docs/image-workflows.md`: runtime ownership, source scope and verification limits.

- `skills/graphic-design/references/design-specification-handoff.md`: DESIGN.md with editable graphics/templates, native dimensions, conditional support and extraction/export verification; routed from Graphic Design and Print Preflight.
- `skills/graphic-design/references/brand-guide-production.md`: conditional visual guide/kit production, demonstrated source-specific rules, truthful font/logo specimens and separate fidelity, craft and delivery checks; selected from Graphic Design and Graphic Design Review. Marketing retains strategy/status; UX retains the native extraction contract.

The conditional image-set production method lives in graphic-design references; its B12 source/adaptation notice is `docs/b12-method-provenance.md`. Official host imagegen executes generation and edits.

- `skills/motion-design/references/lottie-authoring.md`: conditional brief-to-Lottie authoring, safe scene targeting, frame/loop and editable-value checks; existing vector interop owns format fidelity and UX owns live playback.

Public 0.3.0 adds `skills/html-presentation-builder/` (full presentation procedure/pattern map), `skills/lavish-axi/` (full optional local review wrapper/pilot) and `skills/hatch-pet/` (full fourteen-file Apache deterministic atlas workflow). `docs/standalone-visual-workflows.md` owns receiving-host/provider/Pillow and asset boundaries; `provenance/standalone-source.json` tracks exact source hashes and transformations.
