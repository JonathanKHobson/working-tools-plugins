# Standalone visual workflows and receiving-host contract

Three full source families are bundled: [HTML Presentation Builder](../skills/html-presentation-builder/SKILL.md) and its complete upstream-pattern map; [Lavish AXI](../skills/lavish-axi/SKILL.md) and full pilot/Shareables procedure; [Hatch Pet](../skills/hatch-pet/SKILL.md), its original Apache license, all eight deterministic scripts, three complete references and agent metadata. Their source metadata is in [standalone provenance](../provenance/standalone-source.json).

HTML Presentation Builder is an original synthesis of viewport, density, navigation, data/diagram and visual-review methods. No upstream installer, commercial renderer, social scraping/publishing runtime or paid media API is copied. Native presentation tools and Shareables remain optional external hosts. A generated deck must receive the procedure's desktop/mobile/short-height rendered review; including this method does not claim a deck was produced.

Lavish AXI is the original wrapper around a separately installed MIT provider (`lavish-axi@0.1.31` in its historical review). This is an HTML annotation/poll/layout review loop, not a pen plotter. Set `LAVISH_AXI_BIN` to your actual reviewed executable. Keep telemetry off and any approved pilot loopback-only, sandboxed and free of hook/config changes unless those were specifically requested. Runtime state, watcher/server/browser behavior and provider version need current review. Missing provider availability leaves the original pattern-adoption/local-QA workflow usable; do not fabricate an annotation loop. Final artifacts must contain no Lavish overlay, local endpoint, SDK or private path. No provider runtime is bundled here.

Hatch Pet is a full Apache-licensed source workflow with original/local adaptations and original LICENSE.txt retained. Installed host imagegen owns normal pet/base/row/repair generation; the deterministic scripts only prepare prompts/guides, extract frames, mirror an explicitly approved directional row, inspect frames, compose/validate an atlas and create contact-sheet/GIF review media. Python 3.10+ and Pillow are required for those scripts; install [requirements-pet.txt](../requirements-pet.txt) in your explicitly selected environment. Resolve `SKILL_DIR` to this package's skill folder. No API key or image provider is installed. Reference assets must be yours to use, with roles inspected before editing.

The fixed atlas and custom-pet layout are the source's declared native contract, not an acceptance receipt for the current desktop app. Confirm that your receiving host supports custom pets and its destination before copying a package there. Normal instructions reference `${CODEX_HOME:-$HOME/.codex}/pets`; choose the actual supported recipient destination, preserve existing pets and authorize only the selected run's writes/cleanup. Test fixtures and deterministic passes do not establish pet identity, correct semantic motion, native display or approved generated art.

A synthetic helper check may use simple mechanical fixture frames solely to exercise geometry/alpha/order/error handling. Those fixtures are not replacements for imagegen-created production pets. Generated-art acceptance still requires all original nine-state identity and motion review gates, with recipient-owned source media. No real pet, private recording, private image asset or native installation is included in this export.
