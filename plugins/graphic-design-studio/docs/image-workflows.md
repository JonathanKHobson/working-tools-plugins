# Image workflow runtime

Four real tools search, read, browse and prepare the 16 original static recipes. Browse alone has app metadata. Subject, prompt, ratio preference, detail, background and reference descriptions are editable. Inputs are bounded, IDs/revisions validated, and preview paths restricted to catalog-authored basenames. The resource uses public Design Templates' chooser, bridge and controls plus this package's domain editor. Host messages are feature-detected; copy is the fallback. Drafts stay in memory; the shared item/view intent uses best-effort session storage. The server makes no outbound requests and reads no user-selected files.

Previews were generated through official imagegen. Interior and Headshot used synthetic source images. Original source records attribute the covers to Jonathan Kyle Hobson; no real-person reference or third-party artwork is bundled. Icon and motion-asset covers include alpha. Fine edge fringes and examples do not establish approved production assets. All 17 original preview files are retained, including the separate paper-moon sample. No external originals, per-generation private receipts or host connection history is shipped.

Required-reference recipes require an actual attached image; notes are not uploads. Official imagegen remains generation/edit execution owner. Ratio and detail are prompt preferences, not extra tool parameters. A prepared/sent request is distinct from generated/saved/reviewed output. Run the package's synthetic example for executable protocol evidence. See distribution documentation for current validation scope.
