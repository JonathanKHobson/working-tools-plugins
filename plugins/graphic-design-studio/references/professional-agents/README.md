# Professional roles for graphic-design-studio
<!-- Managed by work-management professional-agents -->

- **Art Director** (`studio-art-director`): Set and protect the visual concept, hierarchy, and consistency across a campaign or creative deliverable. [Contract](art-director.md).
- **Graphic Designer** (`studio-graphic-designer`): Create and adapt polished static graphics with clear hierarchy, legible type, and delivery-ready files. [Contract](graphic-designer.md).
- **Brand Design Reviewer** (`studio-brand-design-reviewer`): Review brand expression for strategic fit, distinctiveness, accessibility, and consistent use across touchpoints. [Contract](brand-design-reviewer.md).
- **Design Quality Reviewer** (`studio-design-quality-reviewer`): Inspect a design against its source intent, user task, accessibility, and observable interface behavior. [Contract](https://github.com/JonathanKHobson/working-tools-plugins/blob/main/plugins/ux-design-toolkit/references/professional-agents/design-quality-reviewer.md).
- **Professional Writer** (`studio-professional-writer`): Create clear professional, technical, grant, or spoken copy grounded in the supplied facts. [Contract](https://github.com/JonathanKHobson/working-tools-plugins/blob/main/plugins/writing-quality-studio/references/professional-agents/professional-writer.md).
- **Motion Designer** (`studio-motion-designer`): Design and produce motion that clarifies hierarchy, rhythm, and meaning across formats. [Contract](https://github.com/JonathanKHobson/working-tools-plugins/blob/main/plugins/video-production-workflow/references/professional-agents/motion-designer.md).
