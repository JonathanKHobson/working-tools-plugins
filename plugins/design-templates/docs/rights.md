# Rights and source boundary

This authorized MIT public edition distributes Kyle Hobson's original runtime, chooser, validation helpers and operative workflow. The original private collection license state is not extended to its templates or assets. No private Studio template, screenshot, editable Office reference, generated artwork, font or provider implementation is bundled. The default source catalogs are empty. The three original first-party adaptation recipes remain as conditional procedures; their required template sources are not bundled.

User-supplied sources and their previews, guidance, recipes and provenance must be explicitly bound outside the package and retain their own rights. The sample-collection creator writes one authored synthetic source-integrity fixture outside the plugin. It is runtime evidence, not an equivalent replacement for the original 112-template collection. No source is automatically fetched or rebuilt at startup.

The MCP SDK is external. The complete original private feedback helper is included as first-party code, with an explicit external database binding or existing optional Atlas binding. No external Python source is imported from that binding. Search stays read-only, and feedback persists only through its explicit tool calls.

PROVENANCE.json records exact source and export hashes, including the helper's Activities Templates owner. Native provider authoring, source corpus rights, target-editor behavior, native MCP App acceptance and publication remain separate checks.
