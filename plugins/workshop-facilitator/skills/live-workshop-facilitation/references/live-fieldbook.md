# Live fieldbook

Choose one situation. These are proposed scripts, not diagnoses or guaranteed interventions.

| Observable situation | Immediate move and speakable words | Watch / stop |
|---|---|---|
| One person takes consecutive turns | “I'm pausing us for a minute of writing. Then we'll hear one idea per person, with a pass option.” | More contributors enter; stop the round at the stated limit |
| Nobody answers | “Take 30 seconds to write one example. You can share it, put it in chat, or pass.” | Whether the prompt becomes answerable |
| Several people ask what to do | Show one completed example: “Your output is one claim and the evidence for it.” | Someone can restate the task |
| Options are being judged during generation | “Capture that concern. For two more minutes, we're collecting options; we'll apply criteria next.” | Options stop being prematurely removed |
| The group is arguing about facts | “Which fact would change the choice? Let's record it as unknown and name how to check it.” | A bounded uncertainty replaces circular debate |
| The group is arguing about values | “Which criterion matters differently to us?” | Criteria become explicit; do not pretend more facts settle the value difference |
| The decision owner is absent | “We can produce a recommendation today. We'll label the final decision as pending.” | Status remains honest |
| Technology fails | “Use paper or the shared text document. Write the same output; we'll capture it afterward.” | Learners can continue the core task |
| Ten minutes remain in an overfull session | Cut extra reports: “One key difference per group. We'll use the last five minutes to capture the result and next step.” | Closeout is protected |
| Personal attack or unsafe conduct | “Pause. We can discuss the idea; we cannot continue with personal attacks.” | Stop activity and use the established response if conduct continues |

## Transition
Name what was produced, what happens next, and the remaining time. Example: “We have six distinct problems. Now we'll check the evidence for the two most consequential ones.”

## Attention
Respond to observed task behavior. A quiet camera, lack of eye contact, or movement does not by itself show disengagement. Do not force energizers as punishment. Offer a break or change in interaction only when it fits the task and participants.

## Live completion
A useful intervention has a cut condition. Return control to the human facilitator. In live mode do not generate a literature review, redesign the whole workshop, or ask several intake questions.
