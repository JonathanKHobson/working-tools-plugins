# Evidence workflow

## Source layer
For each image, board, or recording retain ID, locator, original filename, contributor if actually known, capture date if known, and uncertainty. Use a small visual anchor map for images:
ID | source/page/viewport | region | visible text or element | observation | intended action.

Do not infer handwriting authorship or finish a cropped sentence. Preserve an illegible token as `[illegible]`; an uncertain reading can be `[uncertain: ...]`. Keep corrections separate.

## Transcription table
Source ID | locator | exact wording | confidence/uncertainty | context supplied.
Keep repeated contributions as separate rows. If a note was physically duplicated, retain that distinction rather than counting it as an independent participant.

## Organization layer
Place related rows near each other without changing the text. Preserve the raw order or supply an index back to it. If the task is exact organization only, stop here.

## Synthesis layer
Theme ID | analyst label | source IDs | representative exact excerpts | conflicting evidence | interpretation | limitation.
Theme names are analysis. A new phrase in a theme label is not a participant quote. Do not convert note counts into percentages of users unless the unit and denominator warrant it.

## Recurrence
Report “five notes mention onboarding” separately from “three identified participants mentioned onboarding.” One participant contributing five times is not five independent confirmations. Unknown authorship prevents reliable unique-participant counts.

## Recommendations
When authorized, connect recommendation → theme/evidence → assumption → expected result → way to check. Keep a workshop opinion distinguishable from observed user behavior. An impact/effort estimate should not silently become a fact.

## Final checks
All quotes have locators; uncertainty is visible; duplicates preserved; analysis separate; dissent represented; counts have units; no hidden external share. Avoid embedding raw private notes in a reusable plugin or public artifact.
