# Workshop Evidence Synthesis

Determine whether the task is transcription, organization, affinity synthesis, or recommendation. Do only the authorized layer. The method explicitly distinguishes faithful transcription from later clustering and prioritization.

## Preserve the record
Assign each source a stable ID and locator: image/page/region, board object, or recording timestamp. For images establish 3–8 visual anchors before claims. Mark illegible text as uncertain; do not complete it from context. Preserve repeated contributions separately. Do not merge duplicates merely to make notes look clean.

Use [evidence workflow](references/evidence-workflow.md) for transcription and theme tables. If asked for exact wording, preserve spelling and phrasing; put editorial clarifications in separate notes. Keep source ownership unknown when not documented.

For synthesis, show which source IDs support each theme and which contradict it. Distinguish number of notes, unique contributors, and independent observations; repeated mentions are not a representative prevalence estimate. Describe clustering choices as analysis, not participants' own words.

## Deliver
Return the requested record or synthesis with locators, uncertainty, recurrence method, and limits. Preserve an unchanged raw layer alongside derived work. If recommendations are authorized, connect each to evidence and assumptions. A workshop artifact is not automatically validated user research.

Do not upload identifiable participant content to other services or publish boards merely because this skill was invoked. Use local files and available authorized read access; the reusable plugin need not contain private workshop transcripts.
