# Critical reasoning

For “what can Reasoning Toolkit do?”, setup or getting-started help, read the capability, first-task and setup sections of the [plugin introduction](../../README.md) and recommend one relevant first task; skip maintainer notes unless updating the package. Help alone does not start a diagnosis, scan, audit or external action. For a concrete request, use the matching procedure below without loading the whole plugin.


Start from the user's exact claim and intended use. For an authorized critique of a claim, essay, paper or substantial argument, proactively select the fitting Critical Compass check without requiring a named-tool request. Briefly explain its contribution when that helps the human follow the review. Offer a scored council/report with checkpoints when useful; everyday reasoning does not require a full audit. Separate observation, interpretation, assumptions, values and uncertainty. Preserve the strongest supported case and test it against the strongest credible alternative; do not manufacture objections or treat all views as equally supported.

For a short check, use `claim_stress_test`; for supplied prose, use `quick_scan`. A full content or paper audit uses `audit_text`. Read the [Critical Compass contract](../../docs/critical-compass-integration.md) before a tool workflow. Keep the current pause block, mode consent, provenance, dissent and report-readiness fields. Preserve actual human answers. Use sample reviewer answers only when the user explicitly authorizes simulation, and label their origin. Show a lightweight findings preview before reflection questions; verify supported answer acknowledgment instead of treating a tool call as human visibility. Testing a pause is not completing an audit. Academic abstracts cannot support claims about unseen full methods or results.

For an explicitly requested advanced human-loop or independent-panel audit, read the [full-audit route](references/full-audit.md). It uses the packaged on-demand client to access the canonical full profile without enlarging the standing MCP catalog. The host still performs real user questions and independent analyst execution.

For source-dependent claims, read [critical source evaluation](references/critical-source-evaluation.md). New research belongs in Research Studio; academic prose belongs in its academic-writing skill. A simple argument check needs neither a research pyramid nor a research record.

When generic recommendations recur, a ban merely shifts the default, or an originality request lacks a selection rule, use [positive decisions](references/positive-decisions.md). Choose from the actual outcome, source material and constraints, test the closest credible alternative, and separate rule compliance from independent quality evidence. Settled choices and routine answers bypass this step.

When a named framework or a material reasoning gap warrants a lens, read [scoped Atlas retrieval](../../references/atlas-library.md), search 3–8 candidates, then read 1–3 selected full entries. Use its existing models, methods, frameworks and patterns, not a new skill per entry. Framework matches and diagnostic scores are not corroboration. Inspect source readiness and applicability before use.

Return the calibrated conclusion, strongest objection, consequential uncertainty and smallest evidence check that could change the answer. Stop when the requested question is resolved or its evidence gap is explicit. For interactive coaching use `socratic-questioning`; for competing interpretations use `alternative-perspectives`. Ordinary retrieval, citation formatting and simple factual answers bypass this workflow.

Use [the shared drawing board](../../references/draw-think.md) when an argument map, causal chain, option comparison or worked explanation will make the current reasoning easier to inspect or revise. The user need not explicitly ask for a widget. Start a small editable board when it clearly helps; use prose when clearer and offer the canvas briefly when its value is uncertain. Load the drawing contract only when using it. Keep its image/evidence and edit-revision boundaries; a diagram does not establish a claim's truth.

For interactive inspection of completed analysis, use [Critical Review](../../references/critical-review-widget.md). It preserves methods, excerpts, uncertainty and human provenance; it does not replace audit consent or human checkpoints.
