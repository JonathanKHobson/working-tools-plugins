# Replace a default with a decision

Use when an open-ended recommendation repeatedly falls into a familiar template, a prohibition merely shifts the default, or a requested originality/quality improvement lacks a positive selection rule. Routine factual answers, settled choices and narrow repairs bypass this method. Familiarity alone is not a defect, and novelty is not evidence of value.

1. State the intended outcome and the consequential choice still open. Separate the observed repetition from an explanation for it. A small demonstration can expose a failure mode without proving its prevalence or cause.
2. Replace a negative instruction with a positive criterion grounded in the task, authorized source material and constraints. For example, after removing a generic summary, choose what the reader must decide and which evidence would help. Do not simply prescribe a different fashionable template.
3. Consider the nearest credible alternative, including retaining the conventional approach when appropriate. Compare only the dimensions that affect the outcome. Generate more options only if a real unresolved choice justifies them; routine work needs no brainstorming ceremony.
4. Commit to a provisional choice, its supporting evidence and the smallest check that could disconfirm it. Make decisions before constructing an elaborate rationale. Where evidence is absent, name the hypothesis or gap rather than inventing specificity.
5. Separate what a check measures from the intended outcome. Passing a rule written into the generator proves compliance with that rule, not independent quality, originality or usefulness. Test legitimate counterparts as well as known failures, retain counterexamples, and use outcome evidence outside the rule set when available. A checker, model vote or simulated persona does not establish human acceptance.

Keep the first answer as a baseline, not an error to discard. When evidence or alternatives could change the result, vary mechanisms and underlying sources rather than repeatedly asking the same question. Trace apparently different references to their originals. Independent worker assessments can expose assumptions; agreement is not independent factual support. Root causes remain hypotheses until supported by discriminating observations. A conventional answer can be the best supported one.

For an unclear problem or method-selection gap, use the installed `prompt-playbook-studio:prompt-refinement` problem-framing and method-selection reference when available; Work Management owns live skill discovery and the existing scoped Atlas route owns source retrieval. Apply a useful complete method after reading it; do not add a framework inventory or mandatory research phase. Missing access stays explicit, and an authorized execution request continues through the actual result.

For a visual task, the design owner resolves hierarchy, expression, content and rendered verification. This reasoning check does not authorize a redesign or replace the existing identity. A consistent brand can still have weak task structure or generic copy; an unfamiliar appearance can still hide an incorrect answer. Keep correctness, task fit, expressive judgment and measured outcomes distinct.

Stop when the choice is supported at the requested evidence level or the blocking uncertainty is clear. Report a static adaptation as such; do not promise that a new instruction guarantees better outputs.
