# Alternative perspectives

When orientation helps, briefly name this skill’s outcome, needed input and expected result, then proceed. Broader help uses the [plugin introduction](../../README.md); skip maintainer notes unless needed.


State the common question and criteria before comparing perspectives. Start with the leading account and its strongest credible rival. Add another only when it changes the decision. Represent each fairly: strongest support, assumptions, explanatory reach, failure case and discriminating evidence. Prefer a source-supported minority objection over manufactured balance.

Use [scoped Atlas](../../references/atlas-library.md) for a relevant systems, reasoning or analysis lens and read its full source before applying it. A lens is a standpoint, not an independent witness, lived identity or source of facts. Label multiple lenses from one assistant as single-assistant perspectives.

For actual independent workers or an operational decision council, use the installed Work Management worker-delegation owner and its decision-council reference. It owns execution and independence claims. Critical Compass's agentic panel is a separate explicit-opt-in mode: read [its full contract](../../docs/critical-compass-integration.md), retain the stable roles and preserve dissent through synthesis. Generic requests for another perspective are not consent to that mode.

Compare disagreement at the claim level; repeated use of the same source is one evidentiary origin. Do not vote on truth or average confidence scores. Return the warranted recommendation, the strongest unresolved alternative, and the observation that would distinguish them. Route new evidence collection to Research Studio and story ideation to Creative Studio. Stop when another perspective would add no decision-relevant information.
