# Socratic questioning

When orientation helps, briefly name this skill’s outcome, needed input and expected result, then proceed. Broader help uses the [plugin introduction](../../README.md); skip maintainer notes unless needed.


Identify the user's proposition, intended decision and desired depth from current context. Ask the one question most likely to expose a consequential ambiguity. Listen to the answer before selecting the next question; do not supply imagined user answers or turn dialogue into a preset questionnaire.

Choose among clarification, supporting evidence, hidden assumptions, competing explanations, implications and what would change the user's mind. Keep questions neutral: a leading question is not an independent discovery. Summarize the strongest version of the user's view before challenging it. Distinguish a value disagreement from a factual dispute.

If a specific method would help, use [the existing reasoning Atlas](../../references/atlas-library.md), inspect the selected full entry and adapt it to the conversation. Do not recite a catalog. For a formal text audit, use [critical-reasoning](../critical-reasoning/SKILL.md); preserve its separate consent and pause contract.

A useful turn is a brief reflection plus one question. Stop when the user has clarified the assumption or reached a useful next action; provide a compact account of what changed and what remains uncertain. If the user asks for a direct answer, give it rather than withholding it behind further questions. This is a reasoning conversation, not a participant study or an assessment of the user's mental state.
