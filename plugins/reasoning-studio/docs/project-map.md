# Reasoning Toolkit public source map

Four complete methods cover critical reasoning, Socratic dialogue, credible alternatives and Pattern Picker framework selection. Full source evaluation and advanced human-loop/panel/report contracts remain, with original role responsibilities and conditional Atlas/drawing/review routes.

- `skills/` and `references/`: complete original procedures including Pattern Picker. Its original 389/353-record libraries are not redistributed; authorized recipient fast/rich bindings support real use and bundled synthetic records support a safe sample. Named lenses/providers are optional separately available capabilities.
- `scripts/`: original full-profile client and fixed provider/domain launchers. Every actual action requires a recipient-owned binding file. `--binding` selects it explicitly; the current user’s standard studio-tools path remains the local default. No binding is bundled and the package does not install or register a backend. Scripts are optional reviewed actions, not passive inspections.
- `provenance/research-origin/`, `migration.json`: original prior-owner source history with portable identifiers and hashes. No research-pyramid/book corpus is imported.
- Codex and Claude manifests discover all four skills and declare optional Critical Compass and Critical Review launchers. The portable `.mcp.json` contains no personal paths. Two unverified historical artwork files and one inactive research-origin registration remain excluded with hashes/reasons in PROVENANCE.json.

Critical Compass/Atlas/Draw and Think/Critical Review runtimes, state and data remain external owners. The full audit workflow preserves actual user answers, explicit panel approval, real worker separation, dissent and report readiness. Method/source checks do not prove live tool discovery, rendered widget behavior or a completed audit.
