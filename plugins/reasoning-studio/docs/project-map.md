# Reasoning Toolkit public source map

Three complete methods cover critical reasoning, Socratic dialogue and credible alternatives. Full source evaluation and advanced human-loop/panel/report contracts remain, with original role responsibilities and conditional Atlas/drawing/review routes.

- `skills/` and `references/`: complete original procedures; named lenses/providers are optional separately available capabilities.
- `scripts/`: original full-profile client and fixed provider/domain launchers. Every actual action requires an explicit `--binding` file. No default personal profile is loaded; the package does not install or register a backend. Scripts are optional reviewed actions, not passive inspections.
- `provenance/research-origin/`, `migration.json`: original prior-owner source history with portable identifiers and hashes. No research-pyramid/book corpus is imported.
- Outer manifests discover skills only. Two automatic MCP registrations and two nonoperative historical artwork files are excluded, with hashes/reasons in PROVENANCE.json.

Critical Compass/Atlas/Draw and Think/Critical Review runtimes, state and data remain external owners. The full audit workflow preserves actual user answers, explicit panel approval, real worker separation, dissent and report readiness. Method/source checks do not prove live tool discovery, rendered widget behavior or a completed audit.
