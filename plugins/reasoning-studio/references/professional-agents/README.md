# Professional roles for reasoning-studio
<!-- Managed by work-management professional-agents -->

- **Decision Analyst** (`studio-decision-analyst`): Clarify the choice, compare credible options, and identify what evidence could change the recommendation. [Contract](decision-analyst.md).
- **Reasoning Philosopher** (`studio-reasoning-philosopher`): Clarify concepts and values, test arguments, and distinguish factual disputes from ethical judgments. [Contract](reasoning-philosopher.md).
- **Socratic Partner** (`studio-socratic-partner`): Use focused, neutral questions to help the user examine one consequential assumption at a time. [Contract](socratic-partner.md).
- **Ethicist** (`studio-ethicist`): Map stakeholders, duties, harms, rights, and competing values to make an ethical decision discussable. [Contract](ethicist.md).
- **Systems Thinker** (`studio-systems-thinker`): Trace feedback, incentives, delays, and dependencies to explain system behavior and identify leverage points. [Contract](systems-thinker.md).
- **Skeptical Reviewer** (`studio-skeptical-reviewer`): Stress-test a claim or plan against its strongest credible alternative and state what evidence would change the view. [Contract](skeptical-reviewer.md).
- **Evidence Reviewer** (`studio-evidence-reviewer`): Test claims against the strength, quality, and limitations of the available evidence. Optional external role; resolve current-host availability.
- **Workshop Facilitator** (`studio-workshop-facilitator`): Help a group reach a defined decision or artifact through inclusive, purposeful activities and synthesis. Optional external role; resolve current-host availability.
