# Stitch Design Toolkit

Turn a brief or existing project into a selected Stitch screen, component, flow, or verified export through the current browser interface. Bring the audience and task, target screen or project, content, visual references, and the output you need. The workflow can also recover historical work with provenance or review an implemented design against the selected source.

Try a first request:

- “Explore two directions for this onboarding screen using this copy and brand reference; refine the stronger one.” Result: a selected screen with the decision and source location recorded.
- “Make these three subpages share a header and type system while keeping their distinct content.” Result: coordinated screens and a compact system map.
- “Export this selected component into the current app and verify the result.” Result: the actual saved export, implementation when requested, and visual comparison.

For a broad request or a capabilities/getting-started question, begin with [Stitch Workbench](skills/stitch-workbench/SKILL.md); it routes to the right specialist while preserving the current draft. This README is a human guide and is not automatically loaded into AI context.

| Task | Skill |

| Keep related screens coherent | [Design System](skills/stitch-design-system/SKILL.md) |
| Produce a specific UI component or asset | [Component Assets](skills/stitch-component-assets/SKILL.md) |
| Connect screens and recovery states | [Flow Prototyping](skills/stitch-flow-prototyping/SKILL.md) |

| Inspect a design or implementation | [Design Review](skills/stitch-design-review/SKILL.md) |

Use an available browser/computer tool and your existing Stitch account. No Stitch MCP, SDK, API key, server, or extra billing is required by this package. Account access and current product limits still apply.

The [project map](docs/project-map.md) lists the specialist skills. Use `stitch-library-evidence` to distinguish original historical work from new proposals, and `stitch-design-review` to inspect a bounded implemented flow.

## Install and discovery

Install this public edition through the Working Tools marketplace. See the repository [installation guide](https://github.com/JonathanKHobson/working-tools-plugins/blob/main/docs/install.md). A fresh task discovers newly installed skills. Browser/computer tools and a Stitch account are separate prerequisites. No provider implementation or account is included.

## Scope and verification

[Project map](docs/project-map.md) describes the package. [Research](skills/stitch-workbench/references/research.md) records sources and adoption decisions. [Dated UI observations](skills/stitch-workbench/references/current-ui.md) distinguish inspected features from untested exports/generation. Skill instructions are guidance, not a guarantee of product availability, historical provenance, accessibility compliance, or delivered messages.

The skill text is original. Upstream source files are not bundled. Google Stitch and Claude remain their respective providers' products; this plugin is independent.
