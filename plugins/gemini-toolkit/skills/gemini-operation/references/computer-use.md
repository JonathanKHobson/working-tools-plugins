# Gemini computer-use routes

Use Antigravity UI or a browser route when the task genuinely needs live screen
state, web interaction, or a visual interface. Keep one controller for the
browser and preserve unrelated tabs and drafts. Verify the resulting state in
the provider surface and record whether the result came from CLI or UI.

The Gemini API also documents specialized computer-use and agent models, but
API availability does not grant an Antigravity subscription capability. Treat
those as separate routes requiring their own live account, tool, and billing
checks. Do not silently switch from the authenticated CLI to an API key.
