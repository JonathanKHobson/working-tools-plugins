# Gemini model evidence

Model evidence is host-specific and dated. Keep the live account, CLI version,
alias list, and returned model receipt in the receiving project's capability
record rather than this portable plugin.

Refresh with `agy models` and record a pinned headless receipt before relying
on any dated list. Official model documentation describes model families and
tool routes, but task-specific results remain the acceptance evidence.


Public documentation snapshot, reviewed 2026-10-17: Google’s [Antigravity model guide](https://www.antigravity.google/docs/models/) and [Gemini 4 Argon announcement](https://www.antigravity.google/blog/gemini-4-argon-in-google-antigravity) describe Gemini 4 Argon and the CLI model surface. Live `agy models` controls actual selectable versions/efforts; Flash and third-party offerings may vary by account and product. Gemini API, consumer UI and Antigravity have distinct model lists and billing/access. Do not equate a published model family with a working account route. Refresh on access failure or a requested capability review, without installing recurring monitoring.
