# Gemini task fit

Use task fit as a routing hypothesis, not an inherent-specialization chart.

- Gemini Flash is a starting choice for high-throughput, low-latency, routine
  transformations and bounded multimodal or administrative work when the
  required files or browser tools are explicitly available.
- Gemini Argon is a starting choice for harder multi-step reasoning, agentic
  software tasks, and longer synthesis when the task justifies additional
  latency. Verify the live alias and the resulting output.
- Antigravity is especially useful when a task needs an agent that can inspect
  a scoped workspace and use permitted tools. A text-only headless run cannot
  prove browser, spreadsheet, physics, or 3D performance.

For each handoff, state the task, evidence, allowed tools, output shape,
acceptance checks, and stop condition. Compare providers on the same real task
and measure completion, correctness, tool success, latency, and review burden.
Do not claim a provider is best for a domain from marketing descriptions or
benchmarks alone.
