# Research references

These first-party notes preserve the source study behind the video workflow. They are dated research, not current install instructions, verified platform specifications, or rights grants for linked repositories and media. Check the current [optional integration guide](../docs/OPTIONAL_INTEGRATIONS.md) before choosing a runtime. The [source registry](SOURCE_REGISTRY.md) and [rights method](LICENSING_AND_PROVENANCE.md) keep provenance and review criteria visible.

The optional [fetch helper](../scripts/fetch_research_sources.sh) clones candidate repositories only when explicitly run. It does not install their code, update existing checkouts, or grant redistribution rights. Downloaded repositories and populated indexes remain outside this package.
