# Music-Synced Slideshow Example

This fixture contains only synthetic images and audio generated by `make_video_example.py`. It exercises mixed orientations, title cards, text overlays, motion, transitions, music, captions, rendering, storyboard generation, and QA.

Regenerate the original assets with `python scripts/make_video_example.py`. The script draws simple geometric compositions and synthesizes the waveform locally; it uses no outside image, music, model or provider.
