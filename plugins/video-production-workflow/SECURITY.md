# Security and Privacy

- Treat source media, transcripts, faces, voices, locations, and project metadata as sensitive.
- Prefer local analysis where feasible and obtain consent before cloud upload.
- Never write API keys into manifests, logs, prompts, rendered metadata, or source registries.
- Build subprocess commands as argument arrays and validate paths/settings.
- Download remote media only with rights and site permission.
- Keep generated scripts inside project workspaces and review before executing privileged installers.
- Redact secrets and private paths from shared QA/research bundles.
