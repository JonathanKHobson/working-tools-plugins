# Contributing

Use the `evolve-video-workflow` skill. Begin with a repeated failure, missing capability, or routing problem; add a scenario or failing test before implementation. Keep SKILL.md compact, place deep knowledge in references, and mechanical operations in scripts. Update source/license cards, cross-references, schemas, examples, and migration notes with the change.

Run `make verify`. Do not commit proprietary media, API keys, generated vendor checkouts, copyrighted fonts, or unreviewed third-party code.
