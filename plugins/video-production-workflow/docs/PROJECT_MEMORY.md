# Project Memory Format

Keep project learning in `project.md` or structured JSON beside the manifest.

Record:

- creative decisions and user approvals;
- rejected approaches and why;
- recurring technical fixes;
- user feedback about pacing, crop preservation, text overflow, platform controls, source repetition, and copy constraints;
- tool versions and environment changes;
- source hashes and cache lineage;
- review notes tied to timestamps/file hashes;
- delivery spec review dates;
- unresolved risks;
- candidate reusable lessons.

Do not promote a candidate lesson into a global skill until it repeats or a pressure scenario proves the general gap. Project memory may contain taste; global skills should preserve choice.
