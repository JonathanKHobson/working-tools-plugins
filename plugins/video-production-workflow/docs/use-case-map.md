# Independent use cases

Select the smallest task owner and read its complete required procedures, examples and templates. The plugin is a package; do not load every skill.

| Skill | Trigger |
| --- | --- |
| [analyze-music-pacing](../skills/analyze-music-pacing/SKILL.md) | Use when edits, photos, text, animation, or scene changes should respond to music and the workflow needs tempo, beat, onset, energy, silence, phrase, section, or loudness evidence rather than intuition alone. |
| [analyze-video-content](../skills/analyze-video-content/SKILL.md) | Use when footage or a rendered video must be understood through transcripts, scene changes, frames, speakers, faces, objects, motion, image quality, or specific moments before editing or review. |
| [compose-slideshow-video](../skills/compose-slideshow-video/SKILL.md) | Use when photos, illustrations, scans, screenshots, cards, music, narration, or short clips must be assembled into a polished montage or slideshow with intentional framing, pacing, transitions, and text. |
| [conform-video-delivery](../skills/conform-video-delivery/SKILL.md) | Use when a finished edit must become platform, client, archive, broadcast, presentation, web, social, vertical, square, captioned, localized, thumbnail, or multi-codec deliverables with current technical constraints. |
| [create-motion-graphics](../skills/create-motion-graphics/SKILL.md) | Use when a video needs animated diagrams, data, UI demonstrations, kinetic typography, transparent overlays, explainers, charts, compositing, 3D, or reusable motion components beyond simple FFmpeg transforms. |
| [create-video-typography](../skills/create-video-typography/SKILL.md) | Use when a video needs titles, captions, lower thirds, labels, callouts, credits, kinetic type, localization, or readability/accessibility decisions across changing imagery and multiple aspect ratios. |
| [design-video-storyboards](../skills/design-video-storyboards/SKILL.md) | Use when a production brief, assets, transcript, or music analysis must become a beat sheet, storyboard, shot list, layout system, motion language, and timed editorial plan before rendering. |
| [edit-dialogue-footage](../skills/edit-dialogue-footage/SKILL.md) | Use when interviews, talking heads, podcasts, tutorials, multi-take performances, presentations, or narrated footage need transcript-led selection, clean cuts, b-roll, reframing, captions, or shortform extraction. |
| [edit-davinci-resolve](../skills/edit-davinci-resolve/SKILL.md) | Use when an edit must be imported, assembled or finished inside DaVinci Resolve and delivered as a verified editable project/timeline plus rendered media. |
| [evolve-video-workflow](../skills/evolve-video-workflow/SKILL.md) | Use when completed projects, failures, user feedback, new tools, repeated manual fixes, plugin-eval findings, or changed specifications suggest the video plugin or its neighboring skills should be tested, refactored, extended, merged, or deprecated. |
| [exchange-video-timelines](../skills/exchange-video-timelines/SKILL.md) | Use when a code-generated editorial timeline must move to or from another tool, editor, team, archive, or renderer through OpenTimelineIO, CMX3600 EDL, XML, sidecars, or a documented handoff package. |
| [ingest-video-assets](../skills/ingest-video-assets/SKILL.md) | Use when receiving photos, footage, audio, captions, fonts, logos, graphics, URLs, or generated media that must be inventoried, probed, hashed, normalized, proxied, rights-checked, and made safe for downstream editing. |
| [install-video-toolchain](../skills/install-video-toolchain/SKILL.md) | Use when a video workflow cannot start or reproduce because local binaries, Python packages, Node renderers, codecs, fonts, GPU support, environment variables, licenses, or cross-platform setup are missing or uncertain. |
| [mix-video-audio](../skills/mix-video-audio/SKILL.md) | Use when dialogue, voiceover, music, room tone, ambience, sound effects, or generated audio must be edited, balanced, ducked, faded, synchronized, measured, normalized, or delivered as a reliable video mix. |
| [plan-video-production](../skills/plan-video-production/SKILL.md) | Use when recording a supplied Google Slides lesson in Google Vids, planning generated footage, or starting or substantially revising a video project, especially when purpose, audience, assets, runtime, story, style, rights, accessibility, or delivery requirements are not yet a coherent production brief. |
| [render-video-project](../skills/render-video-project/SKILL.md) | Use when an approved video manifest, storyboard, EDL, animation slots, captions, and audio must be compiled into deterministic preview or final media with caching, resumability, renderer routing, and failure recovery. |
| [validate-video-quality](../skills/validate-video-quality/SKILL.md) | Use when a preview, master, export, or renderer output must be checked for structural, visual, audio, caption, timing, accessibility, continuity, platform, or subjective production problems before approval. |
