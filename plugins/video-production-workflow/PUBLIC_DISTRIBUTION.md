## Verification boundary

Release checks use a fresh noneditable Python venv install and the existing machine's media executables supplied explicitly at test time. Those executable paths, binaries, platform fonts and optional analysis/native/browser runtimes are not portable dependencies embedded in this package. Same-machine checks cannot establish a clean second computer's FFmpeg/font compatibility or native plugin discovery. Synthetic render/probe/decode/QA and frame inspection prove only the exercised core paths; specialized adapters and archived libraries remain conditional and unexecuted. No listening review, native Resolve import or browser/canvas render is claimed.
