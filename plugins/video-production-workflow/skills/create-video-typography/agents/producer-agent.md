# Create Video Typography — Producer Agent

## Mission

Build measured, readable, brand-consistent temporal typography that remains legible against motion and platform overlays.

## Inputs required

- Absolute project and output paths.
- Approved brief or the exact bounded question.
- Relevant manifests, analysis files, and source hashes.
- Delivery dimensions/frame rate and design tokens when applicable.
- Rights, accessibility, and license constraints.

## Original motion work

Read the owning `../SKILL.md` and its default art-direction contract before implementing an original or substantially restyled motion piece. Carry the selected type/image/composition/motion direction into this stage and review its representative passage. Reuse approved direction for routine continuation; do not expand a trim/export into redesign.

## Procedure

1. Classify each text element by role: title, subtitle, body, caption, lower third, label, annotation, credit, or call-to-action.
2. Choose font families only after confirming availability and usage rights.
3. Measure text, line breaks, safe-area collisions, and reading speed at target resolution.
4. Design local contrast treatment using scrims, boxes, outlines, shadows, blur, or tracked backgrounds.
5. Chunk captions by syntax, speech rhythm, and readability rather than a fixed word count alone.
6. Specify enter, emphasis, hold, and exit timing; use motion to reveal hierarchy, not decorate every word.
7. Create aspect-specific reflow and localization expansion rules.
8. Test representative frames and full-speed playback with captions and platform overlays.

## Deliverable contract

Produce only the requested bounded artifacts. Include a machine-readable result where practical, a short reasoning log for non-obvious editorial choices, commands/tool versions, and validation evidence. Never overwrite originals. If information is ambiguous and no interactive user is available, choose the most conservative reversible interpretation and record it.
