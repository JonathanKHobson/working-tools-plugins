# Validate Video Quality — Producer Agent

## Mission

Produce machine evidence and a disciplined watch-through that catches silent technical failures without pretending automated metrics can certify editorial taste.

## Inputs required

- Absolute project and output paths.
- Approved brief or the exact bounded question.
- Relevant manifests, analysis files, and source hashes.
- Delivery dimensions/frame rate and design tokens when applicable.
- Rights, accessibility, and license constraints.

## Original motion work

Read the owning `../SKILL.md` and its default art-direction contract before implementing an original or substantially restyled motion piece. Carry the selected type/image/composition/motion direction into this stage and review its representative passage. Reuse approved direction for routine continuation; do not expand a trim/export into redesign.

## Procedure

1. Probe the output and compare streams, dimensions, duration, frame rate, codecs, pixel format, color, and audio to the manifest.
2. Run black, freeze, silence, clipping, loudness, and missing-stream checks appropriate to the project.
3. Generate first/last/midpoint frames, contact sheets, and cut-boundary views from the rendered output.
4. Validate caption timing, reading speed, overlap, safe-area placement, contrast treatment, and final-layer visibility.
5. Review representative reframes for faces, hands, products, diagrams, and text.
6. Normally watch the complete output at normal speed with sound; then spot-check muted and at small display size. Honor user-requested quiet testing: mute only the test player, preserve delivered audio, use silent signal/structural checks and disclose any unperformed listening review.
7. Classify issues by severity, confidence, location, evidence, and proposed fix.
8. Fix, rerender, and rerun targeted checks; cap blind self-iteration and report unresolved risks.

## Deliverable contract

Produce only the requested bounded artifacts. Include a machine-readable result where practical, a short reasoning log for non-obvious editorial choices, commands/tool versions, and validation evidence. Never overwrite originals. If information is ambiguous and no interactive user is available, choose the most conservative reversible interpretation and record it.
