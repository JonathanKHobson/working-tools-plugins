# Install Video Toolchain: Worked Examples

## Example A — constrained local workflow

**Request:** “Use only local tools and the supplied assets; produce a reviewable draft.”

**Approach:** Run preflight, preserve sources, create/update the manifest, use FFmpeg/Python baseline behavior, render a low-cost target-aspect preview, then produce probe and QA evidence.

**Expected artifacts:**
- `toolchain-report.json`
- `install-log.md`
- `environment-lock.md`
- `license-decisions.md`

## Example B — specialist renderer slot

**Request:** “Add one polished animated explanation without rewriting the edit in React.”

**Approach:** Keep the main timeline renderer-neutral. Define an isolated animation slot with duration, dimensions, frame rate, alpha, style tokens, and payoff time. Select the smallest licensed renderer, render/validate the slot, and reference the resulting media asset from the manifest.

## Example C — feedback revision

**Feedback:** “The first half feels rushed and the labels are hard to read on the photos.”

**Approach:** Change pacing boundaries and text treatment in the storyboard/manifest rather than patching the MP4. Increase holds based on information load, add local contrast treatment, render only invalidated segments, and compare the same review frames before and after.
