## Adapt to the actual project

1. Keep one observable takeaway and a source record for factual claims. Bind each beat to what the learner should notice, do and check. A sequence of labels alone is not a lesson; distinguish an illustrative metaphor from literal mechanism or measured data.
2. Preserve the selected brand's actual logo, fonts, painted art and character identity. Supplied images can be hash-bound assets; do not redraw a brand mascot into a new style merely because a procedural kit is available. Describe rigid cutout movement accurately. New acting, derived poses or logo motion retain their own review scope.
3. Use drawing order when it teaches construction or dependency. A fade, still hold or normal live text may be the right choice elsewhere. Reject the source's universal “something changes every second” rule when it competes with reading or accessibility.
4. For a drawing lesson, author the full step text, look/how/mistake, mark IDs, dependencies, erased guides and explicit correction events. Validate schema and order, compare last timelapse frame with the complete still, and test cold versus cached/out-of-order drawing. A reconstruction from a supplied picture is one possible drawing order, not a historical record of its creation.
5. Choose a reviewed existing renderer. Upstream scaffold, HTML builders, dynamic film loaders, sound downloads and optional backends are executable tools with separate admission requirements. Do not run them just to inspect source. Never call a generated HTML file safe because it opens offline.
6. Resolve all assets before frame zero. Keep context-safe labels, local files and explicit frame units. Validate input sizes and geometry before loops or allocations; source primitives assume trusted authoring input. Reset the owned context, seed randomness, bound caches and test direct seeks after a source or asset change.
7. Render the hardest passage at delivery scale, then inspect the encoded file continuously. Review reading holds, character/prop integrity, frame edges, timing and the final static explanation. Same-runtime repeatability is narrower than cross-machine pixel identity or instructional effectiveness.

For a dependency-light, asset-configured three-step lesson, use the [educational motion example](../../../examples/educational-motion/README.md) and the [educational acceptance contract](educational-animation.md). It supplements the full methods; it does not turn every lesson into a fixed 12-second format.
