# Educational animation: explain, then let the learner act

Use for a conceptual explainer, animated worked example, drawing lesson or short teaching sequence. Instructional Design owns the objective, learner assumptions and evidence of learning; Video owns motion, timing and encoded media. Reuse approved lesson decisions and existing project records.

Define a learner action and an observable check before choreography. Map each beat to the concept, the visual change that explains it, exact words or narration, the learner's attention target, and a readable hold. Record sources and simplifications. A charming character, a smooth transition or a high completion score does not prove learning.

Use actual brand assets with source hashes, dimensions, content bounds, registration and approval status. Keep a static approved logo static unless logo motion is in scope. Preserve full limbs, prop grips, paint texture and reading space. Native pose exposure, moving cutouts and newly authored character acting are distinct. Private asset bindings belong to the consuming project, never a generic plugin.

Choose a visual mechanism for the concept: draw a dependency, compare before/after, trace one relationship, reveal a correction, or demonstrate a controlled example. Use supplied artwork as guide/actor rather than decorative clutter. Avoid animation that implies unmeasured speed, causality, certainty or success. A loading orb is an indeterminate status signal; it cannot establish that an answer is correct or that a learner understands.

For narration, lock the authentic source edit and verified landmarks before fine motion. For silent work, keep all necessary meaning in readable text/visuals and supply a transcript or static companion. Add a small practice prompt with a success check when the deliverable is a lesson. Do not add a quiz or a new course when the request is only a media component.

Compose each requested aspect ratio independently. Test actual phone-scale reading, long/Unicode labels, start/transition/hold/end frames, and reduced/static playback. Previews start paused with accessible controls; exports derive from explicit frame time. A static first frame and a complete final overview support users who cannot play motion. Bind review to final source, assets and export hashes separately.

The [asset-configured Canvas example](../../../examples/educational-motion/README.md) provides a complete three-step starting point with deterministic seek, local hash-checked assets, two layouts and MP4 verification. Adapt the words, source evidence, timing and visual mechanism to the learning task. It is a reusable production example, not a learning benchmark or a requirement to use Canvas.

Acceptance: verify the declared learner action is represented truthfully; inspect target-size reading and visual integrity; test direct seek, missing assets and hostile path/label input; decode the actual export; watch its complete timing; provide source and a meaningful static alternative. Report participant testing, listening and LMS compatibility only when actually performed.
