# Synthetic community example

Fictional source: a host asks whether a volunteer can assist next Saturday. The user wants only a draft and has not offered availability. Read the relevant parent/replies, resolve the date and timezone, and draft a concise response that asks about the role without promising attendance. Keep an unverified signup estimate qualified. Do not inspect unrelated communities, install a bot, post, react or schedule monitoring.

If a later explicit edit request is authorized, verify message ownership, exact destination and resulting content. An edit control or Return event is not proof that the final revision persisted. Current message IDs/readback establish state; historical recordings are not send permission.
