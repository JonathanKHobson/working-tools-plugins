First-party adaptation and helper contributions by Jonathan Kyle Hobson are released under Apache-2.0. Professional-role derivative contracts retain three original MIT notices.

Private named-client routing, invoice/template numbers, host paths, historical chat locators, activity-attribution defaults and historical scan/install receipts are excluded or replaced with recipient-owned client setup. No actual invoice/client/bank/settlement data, document template, account connector, transaction capability or financial-provider runtime is included. The independent invoice-preparation procedure is first-party original method text; no external private client skill/template is copied or required for the generic workflow.

Selected upstream skill heads are named SKILL.original.md and remain inactive evidence. All source bytes/licenses are unchanged. Current account coverage, legal/tax terms and a native host install remain separate verification. The synthetic helper task demonstrates explicit exact-decimal allocation, not bank verification or source completeness. `PROVENANCE.json` records file-level rights and hashes.
