# Source and distribution boundary

The runtime derives from the existing private Knowledge Atlas `ai-layer/studio_library` implementation inspected on 2026-10-08. `domains.json` and the Activities adapter retain the existing domain-membership and chooser contracts. The shared UI's canonical presentation is maintained by Design Templates. The migration's recoverable source snapshots and exact source/destination hashes live in the owning consolidation task's private evidence directory.

Adaptations: `catalog.py` imports a packaged `atlas_common.py` containing only the existing collection map and exact stable slug behavior. `server.py` requires explicitly supplied data/vault paths instead of the author's machine defaults. `binding.py` and the launcher supply portable external configuration, execute this package's runtime, and retain the original feedback-store default relative to the supplied catalog. `search_misses.py` can receive that external path through `ACTIVITIES_SEARCH_MISSES_DB`. Search/read/browse names, fixed domain rules, full-source read behavior, scoped related links and resource URIs remain intact.

The runtime contains reusable code, not the source corpus. No private vault notes, SQLite catalog, feedback database, logs, host binding or original source exports are included. Synthetic verification records are authored fixtures, labeled as examples. The public 461-guide editorial projection is registered in `library/public-edition.json` as an external reference with unresolved redistribution rights; its availability and prior editorial review do not supply a blanket content license. No corpus is copied or automatically fetched.

The original source manifest was Private. This authorized public edition licenses only the original first-party runtime and workflow under MIT. Referenced methods and the external guide corpus retain their own rights; neither is bundled. Recipient installation and rendered host acceptance remain separate checks.
