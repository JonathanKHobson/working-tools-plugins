# Writing Quality Studio

Eleven writing skills edit prose, shape source-grounded communication, match a supplied voice, revise long and technical text, answer document comments and carry grant work from eligibility through closeout. Bring a draft or verified facts, reader, requested change and exact language that must remain. The [task map](docs/use-case-map.md) selects the right skill.

Start with `natural-prose-editor` for a final outgoing email or article pass, `communication-crafter` for a message whose point and evidence need design, `voice-and-style` for explicitly requested personal or brand voice, or `humanizer-deep-audit` for source/citation and style-drift evidence. A substantive argument audit routes to Reasoning Toolkit (`reasoning-studio:critical-reasoning`), which owns Critical Compass; return here for prose editing.

The package includes full first-party procedures, scripts, synthetic examples, the CC BY-SA 4.0 Wikipedia archive and complete licensed methods. The [native procedure map](library/source-procedures/INDEX.md) covers ordinary editing, voice, language, technical, long-document and spoken tasks without a separate method plugin. [Human Writing](library/source-procedures/marketplace/human-writing/human-writing/SKILL.md) retains its unchanged author-confirmed MIT head and clearly identified first-party support repairs. Research papers remain linked records. [Source coverage](docs/source-coverage-limitations.md) records excluded historical bodies and current implementation limits.

## Recipient setup

Install this plugin through native Codex Plugin Management or a configured Claude Code marketplace, select the matching skill and supply your draft, sources, authentic sample when relevant, and permissions. Both host manifests expose the same native methods. No personal corpus, private profile, Google connection, grant record or Atlas database is bundled. Connected source retrieval and Google comment writeback need available tools and the task's authorization. The optional writing Atlas is described [here](references/atlas-library.md); the Studio makes no MCP declaration. Explicit selection of OpenAI's Write Like Me remains a separate supported method choice.

## First-use checks

- Give `natural-prose-editor` a two-sentence synthetic email containing one unsupported outcome claim. Confirm the result preserves facts, flags that claim and supplies a clean revision.
- Give `technical-instructions` a three-step synthetic procedure and ask for a plain-language version. Confirm the original steps remain.
- Ask `voice-and-style` for a personal match with no authentic sample. It should request or use an authorized sample, not invent a style profile.
- With external writing-method plugins absent, request a sample match, a long-document comparison and a spoken rewrite. Each should deliver from the bundled procedure without an installation prompt, invented facts or unsupported duration/voice claims.
