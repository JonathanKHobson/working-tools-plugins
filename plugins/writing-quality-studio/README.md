# Writing Quality Studio

Eleven writing skills edit prose, shape source-grounded communication, match a supplied voice, revise long and technical text, answer document comments and carry grant work from eligibility through closeout. Bring a draft or verified facts, reader, requested change and exact language that must remain. The [task map](docs/use-case-map.md) selects the right skill.

Start with `natural-prose-editor` for a final outgoing email or article pass, `communication-crafter` for a message whose point and evidence need design, `voice-and-style` for explicitly requested personal or brand voice, or `humanizer-deep-audit` for source/citation and style-drift evidence. A substantive argument audit routes to Reasoning Toolkit (`reasoning-studio:critical-reasoning`), which owns Critical Compass; return here for prose editing.

The package includes full first-party procedures, scripts, synthetic examples, the CC BY-SA 4.0 Wikipedia archive and full licensed third-party methods. [Provider methods](library/source-procedures/provider-methods.md) explain optional publisher-installed AIHumanizer and Write Like Me depth. Their exact bodies are not redistributed. [Human Writing](library/source-procedures/marketplace/human-writing/human-writing/SKILL.md) is Kyle’s retained MIT method, with newly authored first-party prose and narrative support guides. Its original method remains unchanged; the support repair is identified in [provenance](library/source-procedures/marketplace/human-writing/human-writing/PROVENANCE.md). Research papers are linked records, not bundled copies. These absences are called out at the task route; they do not turn a local procedure into a claim of provider equivalence.

## Recipient setup

Install this plugin through native Codex Plugin Management or a configured Claude Code plugin marketplace, select the matching skill and supply your own draft, sources, voice sample and permissions. The `.claude-plugin/plugin.json` manifest exposes the same root skill directories without carrying Codex provider installations into Claude. For optional publisher methods, install and enable `aihumanizer@openai-curated-remote` or `write-like-me@openai-curated-remote`, then verify their skill availability. Their marketplace identities are Codex-specific. On another host, verify a supported publisher route separately. No personal corpus, private profile, Google connection, grant record or Atlas database is bundled. Google comment writeback needs an available connected provider and explicit authorization. The optional writing Atlas is described [here](references/atlas-library.md); the Studio itself makes no MCP server declaration.

## First-use checks

- Give `natural-prose-editor` a two-sentence synthetic email containing one unsupported outcome claim. Confirm the result preserves facts, flags that claim and supplies a clean revision.
- Give `technical-instructions` a three-step synthetic procedure and ask for a plain-language version. Confirm the original steps remain.
- Ask `voice-and-style` for a personal match with no authentic sample. It should request or use an authorized sample, not invent a style profile.
- For an optional publisher method, check `codex plugin list --json` and select its exact skill. If unavailable, the response must name the missing provider and use the packaged method only within its stated scope.
