# Independent use cases

Select the smallest task owner and read its complete required procedures, examples and templates. The plugin is a package; do not load every skill.

| Skill | Trigger |
| --- | --- |
| [communication-crafter](../skills/communication-crafter/SKILL.md) | Shape supplied facts into audience-aware messages, business writing, shared voice guides, spoken scripts or evidence-based follow-ups with a clear point, proof and next action. Use when communication strategy or source/status distinctions matter; routine messages with a clear ask can be drafted directly and receive the final natural-prose-editor pass. For line editing use natural-prose-editor. Also use for writing quality studio capabilities or getting-started questions. |
| [google-comment-responder](../skills/google-comment-responder/SKILL.md) | Scan eligible existing Google document threads, draft or post authorized replies, and verify writeback through a connected comment API. |
| [grant-process-crafter](../skills/grant-process-crafter/SKILL.md) | Full grant lifecycle: prospecting, hard eligibility and go/no-go, source-linked NOFO/RFP compliance, credible project/evaluation design, budget/finance handoff, proposal drafting/review, human submission readiness, award reporting, closeout and resubmission. |
| [humanizer-deep-audit](../skills/humanizer-deep-audit/SKILL.md) | Audit substantial prose against a source corpus, citation record, or authentic author sample, or help respond to a disputed AI-writing allegation using process evidence. Use for citation integrity, style-drift review, or a comprehensive pattern and false-positive analysis. For an ordinary rewrite or natural-voice edit, use natural-prose-editor instead. Never infer authorship from style or promise detector evasion. |
| [long-document-editing](../skills/long-document-editing/SKILL.md) | Edit a long document in controlled passes, compare versions, preserve claims and terminology, control length, or perform final editorial polish. |
| [natural-prose-editor](../skills/natural-prose-editor/SKILL.md) | Edit prose and review final outgoing emails, contact messages, articles and Substack/newsletters for clarity, facts, natural voice and house style. Apply before delivery or publication even when no review is requested; deeper source audits use humanizer-deep-audit. |
| [plain-language-editing](../skills/plain-language-editing/SKILL.md) | Rewrite or audit text for plain English, non-native readers, accessibility of language, multilingual clarity, and preserved technical meaning. |
| [spoken-and-scripted-writing](../skills/spoken-and-scripted-writing/SKILL.md) | Prepare a speech, presentation script, spoken explainer, narration or performance-friendly rewrite with realistic timing and spoken rhythm. |
| [technical-instructions](../skills/technical-instructions/SKILL.md) | Write or review technical documentation, procedures, manuals and safety instructions, including controlled Simplified Technical English when specifically required. |
| [voice-and-style](../skills/voice-and-style/SKILL.md) | Find relevant attributable writing through connected apps and compose in the user's style; match a supplied personal or brand voice, build a reusable style profile or adjust tone without inventing personal experience. |

| [writing-voice-library](../skills/writing-voice-library/SKILL.md) | Compatibility bridge only for an explicit generic Writing Library request; the separate Writing Templates plugin owns selection, guides, MCP and QA. |

Writing Quality Studio exposes 11 focused heads; optional publisher methods remain separate. Personal matching remains `voice-and-style`; use only relevant authorized authentic sources. Ordinary editing does not browse Writing Templates by default.
