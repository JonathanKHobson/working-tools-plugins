# Evaluation: executed checks and future probes

This is a Codex-authored packet of fictional prose. No real message was sent, registered, submitted or published. No human readers, participants or survey respondents evaluated these versions. No plugin baseline/upgraded generation comparison was run. Model-authored judgment is not evidence of comprehension, persuasion, authenticity or outcome.

## Executed within this packet

- Six complete versions V1–V6 were written from the same eleven-item fact/qualification ledger. Codex performed a line-by-line writer audit for name, dates/time zone, audience, fee, total capacity versus unknown availability, deadline, input choice, caption/recording states, outcome status and nonlive CTA. The audit is reported under examples/same-fact-voices.md; it is not an independent reviewer test.
- A complete claim/grounds/warrant/backing/qualifier/objection/response map and prose response were written for a current-state publication decision in examples/argument-and-neutrality.md. The neutral survey counter-route was drafted but not administered.
- Current Writing Quality Studio source paths, three full user-authored rhetoric extracts, targeted U13 passages and selected direct external pages were inspected. sources.json records source class and access extent. Vale's repository was inspected read-only; no code or dependency was installed or executed.
- Source-led claims were limited: Aristotle is historical theory; Purdue explains Toulmin; NCA is normative; Mailchimp is a brand example; the 1997 web-reading study is task- and era-specific; Reddit is anecdotal. Unsupported efficacy numbers and a universal word-cut rule were not encoded.

## Six benchmark tasks for later same-input comparison

1. **Explanation:** Explain the lab to a first-time adult reader using all F1–F11; ask a reviewer what they believe is confirmed.
2. **Recommendation under incomplete evidence:** Advise whether to publish the announcement while the CTA is not live; require explicit warrant and qualifier. The packet supplies a worked example, not a decision-owner approval.
3. **Serious objection:** Answer “waiting cuts lead time before the deadline” without calling availability known or minimizing the cost. A worked response is present.
4. **Narrative passage:** Write a restrained reflection that reaches the logistics quickly. V4 is an authored candidate; it has not been reader tested.
5. **Neutral survey question:** Ask about any change after attendance without presupposing improvement; Survey Studio must review and own an actual instrument. One draft question is present.
6. **Long-form consistency:** Draft announcement, FAQ and follow-up with stable F1–F11 status language and justified tone shifts. Not run.

Use identical brief, facts, model settings and sample access for a future current-skill versus staged-reference comparison. Capture exact outputs and reviewer background; blind review where practical. A stronger preference rating is not proof of better decisions. Reject any version that violates a hard fact or agency gate regardless of style score.

These definitions add no always-on scoring pass and claim no executed behavioral result; any externally run comparison needs its own output and review record.
