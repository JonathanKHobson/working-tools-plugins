## When to use

Use this reference only when the user asks to gather raw material, shape a pile into an article, or build a piece beat by beat. Use Shape when raw source notes need organization. An already structured brief can be drafted through the main skill without this procedure.

## Explore versus shape

- **Explore** widens what could be written. Collect fragments. Impose no outline.
- **Shape** commits to structure. Treat the pile as read-only input. Produce a separate draft in the requested output medium; this may be inline in chat and need not create a file.

Name the mode you are in. Do not drift between them silently.

## Explore steps

1. Use the supplied path or the existing writing project and its structure. Choose a routine draft location when clear. Ask only if the destination affects scope or could overwrite someone else’s work. A conversational exploration does not require creating a file.
2. Preserve original wording. Keep the user's phrasing intact and add a reworded variant beside it only when asked.
3. Capture fragments from the conversation the user started for this purpose. Do not run a forced interview. Ask a question only when it helps the user's stated goal.
4. Mention each capture briefly, such as "adding that". Stop capturing when the session ends. No silent ongoing capture in later work.
5. Notice a recurring phrase that names the central idea. Offer it as a working concept, preserving the original fragments; do not force a slogan.

Minimum file shape:

```markdown
# Working title

First fragment, as written.

---

Second fragment.
```

## Shape steps

1. Read the whole pile first.
2. Establish the audience and concepts they already know from the brief. Ask only when a material uncertainty prevents a useful draft.
3. Track conceptual dependencies after that. A block may lean only on grounded concepts. Ground a new concept before relying on it, or promote it to a prerequisite.
4. If exploration or alternatives are requested, offer 2 or 3 openings with distinct angles. Otherwise choose the best supported opening and continue drafting.
5. Build a coherent draft in the requested scope. Choose prose, lists, tables, quotes or code to support the reader. Do not stop after each block unless the user selected participatory drafting.
6. Name gaps plainly: "The pile lacks an example here."

## Optional beat-by-beat mode

This is an optional Shape interaction, with the same whole-source reading and concept-dependency checks. Re-read changed source notes as evidence without editing them or switching to Explore. Use only when the user requests it. Offer 2 or 3 reachable beats, each noting what it requires and grounds. Write only the chosen beat, then stop and offer the next set.

## Edit safety

Before editing, re-read the current file and preserve concurrent user changes. Keep the raw fragment source intact; write the shaped draft separately unless the user requests in-place transformation. Apply targeted changes, not stale whole-file replacements.

## Finish

Run the final text through the existing natural-prose-editor route. Continue any already authorized delivery through its owning workflow; drafting alone does not authorize publishing. Fiction, campaign strategy and curriculum retain their existing owners.
