# Communication practice loop

Use for an explicit learning or rehearsal request. Scale down if one example and one attempt will suffice.

```markdown
## Practice goal
- Subskill and scenario:
- Reader, channel, and constraint:
- What success would look like:

## Worked example
[One short model response.]

## Why it works
- Main point:
- Proof:
- Tone and ask:

## Guided attempt
[Partial scaffold: context → point → proof → ask.]

## Independent attempt
[A new version under the same constraints.]

## Feedback
- Audience fit, clarity, tone, evidence, ask, and risk:
- One next revision:

## Transfer
- Adapt for a different reader or channel:
- Next real-world test:
```
