# Academic writing handoff

The current owner is `research-methodology-local:academic-writing`. Use it for scientific manuscript structure, frozen technical content, problem/mechanism/evidence reasoning, essays and reviewer responses. Its conditional references preserve the previous academic review guidance and add section-level craft.

Academic Writing Toolkit supplies its existing citation, BibTeX, reading-note, paragraph and British-spelling tools when exposed; a tool result is not source or scientific verification. Ordinary prose editing remains in Writing Quality Studio. General citation/author-sample audits may still use this deep-audit skill when that is the requested output.

This is a routing reference, not a second academic workflow.
