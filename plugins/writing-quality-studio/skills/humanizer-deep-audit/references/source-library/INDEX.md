# Research source records

The public package does not redistribute the source host's research PDF/XML cache because grants vary by deposit. Use the primary records in [source bibliography](../source-bibliography.md), and verify the selected full paper, version, license, claim and quote in the recipient's own access context. ACL Anthology papers generally carry CC BY 4.0 for post-2016 publications; that is not a blanket license for arXiv, PMC or publisher PDFs. This package makes no local-full-paper claim.
