# Fast Pattern Index

This is the quick routing sheet. Use the linked full references for diagnosis and examples.

| Cue | Inspect | Default repair |
| --- | --- | --- |
| Importance, legacy, landscape, broad debate | `content-patterns.md` | Replace with a sourced consequence or cut |
| Media lists, “independent coverage,” active presence | `content-patterns.md` | State what the source establishes |
| Trailing `-ing` interpretation | `content-patterns.md` | Stop at the fact, source the inference, or attribute it |
| Brochure, press-release, or product praise | `content-patterns.md` | Name the observable feature, action, or result |
| Experts, observers, critics, widely regarded | `content-patterns.md` | Name and count sources accurately |
| Challenges/future uplift or repeated conclusion | `content-patterns.md` | End on the real constraint, decision, or final fact |
| Dense watch-list vocabulary | `language-patterns.md` | Replace abstractions with actor, action, object, and condition |
| Serves as, stands as, features, boasts | `language-patterns.md` | Test a plain `is`, `are`, or `has` construction |
| Not just X but Y, no X just Y | `language-patterns.md` | Remove imaginary correction; state the distinction directly |
| Repeated three-part lists | `language-patterns.md` | Use the natural number of facts or one strong example |
| Forced synonyms | `language-patterns.md` | Repeat the precise noun or combine sentences |
| Title case, bold, label-colon lists | `structure-and-formatting-patterns.md` | Match house style and the reader’s scanning need |
| Dense em dashes, emoji headings, tiny tables | `structure-and-formatting-patterns.md` | Choose punctuation or structure by function |
| Prompt preamble, offers, cutoff disclaimer | `communication-and-markup-patterns.md` | Remove the conversation; state the evidence boundary |
| Placeholders, mixed markup, tool artifacts | `communication-and-markup-patterns.md` | Block release until values or sources are recovered |
| DOI, ISBN, URL, page, or reference mismatch | `citation-integrity.md` | Verify existence, identity, location, and entailment |
| Suspicion based on grammar, formality, quotes, or one word | `human-signals-and-false-positives.md` | Use provenance, baseline, and clusters; avoid a verdict |

For paired practice examples, use `revision-example-bank.md`. For every source-derived category, use `source-coverage-map.md`.
