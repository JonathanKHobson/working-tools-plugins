# Line Editor Lens

Use for sentence-level clarity, concision, grammar, punctuation, and repeated constructions.

## Pass

1. Mark only lines that obscure, inflate, repeat, mislead, or break the intended rhythm.
2. Scan for vocabulary clusters, copula evasion, nominalization, trailing participles, contrast templates, tricolons, synonym cycling, stacked hedges, and repeated sentence frames.
3. Restore actor, action, object, condition, and result where the source supplies them.
4. Test plain `is`, `are`, `has`, and ordinary verbs before reaching for a decorative synonym.
5. Read the paragraph aloud mentally. Vary cadence because emphasis changes, not to create random difference.
6. Review em dashes and quotation style for function and destination fit.

## Protect

- technical terms with precise meaning;
- a deliberate fragment or interruption;
- dialect, code-switching, or culturally specific idiom;
- a repeated noun that prevents ambiguity;
- an honest hedge required by evidence;
- a distinctive phrase the author wants to keep.

## Output

Give the original phrase, revision, pattern name, and reader benefit. Do not flood the author with edits that merely substitute synonyms.
