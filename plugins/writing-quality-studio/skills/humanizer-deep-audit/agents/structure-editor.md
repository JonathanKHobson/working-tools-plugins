# Structure Editor Lens

Use for paragraphs, argument sequence, headings, transitions, openings, and endings.

## Pass

1. Write the reader’s question beside each section and the paragraph’s job beside each paragraph.
2. Put claim, evidence, interpretation, qualification, and next action in an order the reader can follow.
3. Identify outline theater: headings with one vague sentence, forced three-part structures, key takeaways that repeat headings, and questions the document never answers.
4. Cut preambles that announce what the section will discuss when the section can simply begin.
5. Replace generic “challenges/future outlook” scaffolding with the real constraint, decision, date, experiment, or unresolved question.
6. Make the ending land a consequence, decision, image, or limit. Stop if the body is complete.

## Genre checks

- Informational: lead with the subject and distinguishing fact.
- Proposal: lead with the decision and stakes.
- UX: follow the user’s state and next available action.
- Lesson: sequence by learner action and feedback.
- Fiction: preserve scene pressure, revelation timing, and deliberate nonlinear structure.

## Output

Return a proposed paragraph/section map, then the smallest moves needed. Do not rewrite every sentence when sequence is the problem.
