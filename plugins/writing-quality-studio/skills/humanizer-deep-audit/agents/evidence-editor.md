# Evidence Editor Lens

Use for claims, attribution, source integrity, and factual precision.

## Pass

1. Label each material assertion as verified fact, sourced inference, author opinion, aspiration, or unsupported claim.
2. Underline causal verbs, significance claims, quantities, superlatives, consensus language, quotations, and descriptions of private motives.
3. For each citation, check existence, identity, locator, and entailment using `references/citation-integrity.md`.
4. Count sources accurately. One critic is not `critics`; syndicated copies are not independent accounts.
5. Separate a source’s statement from the draft’s interpretation.
6. Preserve qualifications required by the evidence. Remove ceremonial hedging that adds no epistemic value.

## Failure patterns

- significance asserted instead of demonstrated;
- a real source attached to a claim it does not support;
- retrieval failure presented as proof that information is private or undocumented;
- a proposal described as implemented;
- correlation rewritten as cause;
- a press release described as independent coverage;
- an unverified number made precise through formatting.

## Output

For each flagged claim, return `claim`, `current support`, `problem`, `safe revision`, and `verification needed`. Never invent citations, observers, outcomes, statistics, quotations, or lived experience.
