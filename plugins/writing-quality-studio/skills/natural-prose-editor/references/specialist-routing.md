# Natural prose specialist routing

Use only the route the current writing task needs. The everyday final pass, meaning checks, and correspondence rule stay in [the entrypoint](../SKILL.md).

| Trigger | Read |
| --- | --- |
| Style matching, a long or source-bound document, spoken lesson, survey wording, or a substantial/public piece | [Conditional editorial depth](#conditional-editorial-depth) |
| A task owned by communication, UX writing, grant, academic, reasoning or deep audit specialists | [Specialist ownership](#specialist-ownership) |
| A named retained method, pattern review, variant comparison, template, or local text helper | [Named methods and full procedures](#named-methods-and-full-procedures) |

## Conditional editorial depth

For an explicit style-matching or Write Like Me task, use [voice and style](../../voice-and-style/SKILL.md) directly; its complete methods own that workflow. Ordinary edits here preserve supplied voice without requiring profile retrieval. A request for clearer professional writing does not activate historical personal-voice matching. Keep the existing audience, clarity and outgoing-review defaults; do not load a private voice appendix merely because it exists.

For a long document, competing drafts, a binding length limit or source paraphrase, read [document revision and version choice](document-revision.md). For translation, regional localization or learner-oriented English correction, read [language-sensitive editing](language-and-learning.md). Neither reference is needed for a small ordinary edit.

For lesson narration or a software walkthrough, use [spoken lesson scripts](spoken-lesson-scripts.md) when the task involves authentic prior delivery, spoken versus production text, or a recording-readiness pass. Teaching sequence belongs to Instructional Design Studio; footage editing belongs to Video Production Workflow.

For survey questions, scales, screeners, or consent text, use the [survey wording handoff](survey-wording-handoff.md). Survey Studio owns the instrument, logic, coding, accessibility, and analysis; this skill can polish wording against those constraints without taking over the method or export.

For a substantial or public-facing piece, read [the editorial gate](editorial-gate.md). It contains conditional voice, citation and release checks. For a small edit, compare the result directly with the source and stop when the meaning is intact and the sentence works.

## Specialist ownership

When the job is to decide the audience, hook, proof, structure, or ask, use `communication-crafter`. For product-interface copy, use the UX-writing specialist to decide placement, state and interaction, then apply this final wording pass within that contract. For grant opportunities, eligibility/go-no-go, NOFO/RFP compliance, project design, proposal work or post-award obligations, use [grant-process-crafter](../../grant-process-crafter/SKILL.md); apply this skill only as a language pass against its established evidence and constraints. For fiction scenes, game canon, academic submission rules or job-application packaging, use the owning specialist and apply this skill only as an editorial pass.

For detailed citation/source verification, comparison with an authentic author sample, or a corpus-backed/full release audit, use [humanizer-deep-audit](../../humanizer-deep-audit/SKILL.md). Its archive and scripts remain unloaded for ordinary edits.

For academic drafting, manuscript argument, section structure, essays or reviewer responses, route to `research-methodology-local:academic-writing`; keep this skill as an optional prose pass. For citation consistency, reading-note templates, BibTeX format checks, paragraph-logic cues or requested British spelling, use the available Academic Writing Toolkit tool. Tool output alone does not verify sources or claims.

For a substantive audit of a claim, argument, plan, or method, route to `reasoning-studio:critical-reasoning`, which owns Critical Compass. Return here for an optional clarity and prose pass after the reasoning review; do not treat an editorial pass as a Critical Compass audit.

## Named methods and full procedures

### Full source procedures

For a request matching a named procedure, consult the [native procedure map](../../../library/source-procedures/INDEX.md), then read the selected complete bundled body and its applicable support. Use the current facts, scope and requested artifact; every ordinary editorial task operates without a separate writing-method plugin.
When asked to match the user’s own style, use the [Write Like Me provider route](../../../library/source-procedures/provider-methods.md#write-like-me) if installed and select authentic, relevant examples through authorized sources. If unavailable, use the packaged bounded style pass and label it accurately.

### Distinct writing routes

Use `voice-and-style` for personal/brand voice; `plain-language-editing` for reader accessibility and multilingual clarity; `technical-instructions` for documentation; `long-document-editing` for version and document passes; and `spoken-and-scripted-writing` for narration. Each routes directly to complete bundled methods. Occasional UX follow-up remains in communication.

When the user requests a named slop-pattern review or edit, read the complete [No AI Slop method](../../../libraries/no-ai-slop/skills/no-ai-slop/SKILL.md) and its full evaluation file before applying it. Preserve its named pattern examples, voice and detect-only boundaries; source self-promotion is not a required footer. Treat inherited pattern evaluations as conditional prompts, not automatic bans on contrasts, headings, punctuation, repetition, true category counts, passive voice, nominalization, accurate inanimate subjects, courtesy or established motifs. The supplied facts, reader task and deliberate voice govern; a successful review may retain the text. For a pattern-driven restructure, read the [inventory and symmetry check](controlled-contrast-revision.md#inventory-before-enforcing-symmetry). This copy comes directly from the original publisher’s pinned repository because the marketplace has a same-name collision. Do not attribute it to the different Slop Curator package.

For Human Writing specifically, read and apply the complete retained [Human Writing procedure](../../../library/source-procedures/marketplace/human-writing/human-writing/SKILL.md), including its prose-pattern and narrative-choice guides for the modes they govern. The original method is Jonathan Kyle Hobson’s author-confirmed MIT text; [provenance](../../../library/source-procedures/marketplace/human-writing/human-writing/PROVENANCE.md) identifies its newly authored support repair. No separate provider installation is needed. Preserve the method’s narrative scope, source inventory and prohibition on authorship or detector claims.

When comparing substantive variants or reviewing a consequential rewrite, use the full [controlled contrast and mutation audit](controlled-contrast-revision.md). Preserve deliberate personality and material qualifications; do not generate variants merely to polish an ordinary sentence.

For an explicitly selected generic template or blend, use [the template handoff](../../voice-and-style/references/writing-templates.md) to preserve its chosen architecture, the author’s audience-appropriate correspondence voice and continuing voice through articles. Ordinary drafting and rewriting use the supplied voice and reader task without browsing the generic library. Humanizing must not smooth every piece into the same cadence; effective text can remain unchanged.

For grammar that hides responsibility, repetitive structures across a supplied series, or an anti-slop edit that may erase courtesy or a refrain, read [research-informed pattern review](research-pattern-review.md). Apply its source-grounded repair/keep checks before the inherited No AI Slop evaluation; that evaluation cannot require invented specificity or removal of purposeful devices.

For deterministic local text cleanup, Unicode inspection, stock-language cues or a before/after panel (including li-human intent), read [local text hygiene](local-text-hygiene.md). Use its safe helpers when useful; never treat the observations as AI detection or mutate language to satisfy a numeric target.
