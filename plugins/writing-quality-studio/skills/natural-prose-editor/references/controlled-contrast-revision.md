# Adopted writing decision method

Integrated 2026-09-30. Read the full card for its actual trigger; routine correspondence does not require a rhetoric exercise. Historical coverage statements describe the pre-integration audit. ## P5 — Revise by controlled contrast, not polish alone

**Decision:** Did an edit make the text easier to use without distorting it or erasing a deliberate personality?

**Current coverage inspected:** natural-prose-editor/SKILL.md protects strongest detail, cadence and uncertainty; the legacy voice-ai-sludge-checks.md detects generic filler and overpolish; format-and-voice.md separates fact boundaries from tone. These already cover much of the work.

**Source:** E05's same-information test supports examining different arrangements and styles on a defined web task; it does not prescribe a universal 50% cut or guarantee a result on this announcement. Vale (E06) can mechanically check chosen terms offline, but its README/LICENSE/go.mod inspection does not make it an argument or authenticity judge.

**Mechanism:** Create 2–3 purposeful alternatives from one ledger. For each, compare opening move, paragraph order, clause length, direct address, evidence placement and cadence. Audit every changed noun, number, time, status verb, modal and promise against the ledger. Preserve a distinctive useful rough edge if it serves the author; cut only generic filler that obscures the point. A critique may say “this sounds like a press release” and cite exact sentences; it cannot declare a voice objectively authentic without the author's judgment. Stop when further polish changes taste but not task fit.

**Conditions / counterexample:** Use for multi-option or high-stakes writing. Skip repeated variant generation on a routine reply. Counterexample: converting “captions are planned” to “captioned sessions” in pursuit of a stronger headline. **Owner:** natural-prose-editor, with communication-crafter for decision quality. **Overlap:** no new lint dependency or voice catalog. **Effort:** XS. **Test:** 6-version mutation table retains F1–F11; two blind readers can identify structural distinctions and flag any hidden uncertainty. Reader preference remains untested until such review occurs.

## Check relationships after a shape edit

Use this addition when merging or splitting clauses, compressing a list, turning labeled bullets into prose, or rearranging examples changes how facts relate. A cosmetic punctuation fix that leaves the proposition intact does not need a separate audit. Continue to use the existing fact ledger and deliberate voice choices above.

1. Before changing the shape, identify any ranking, sequence, simultaneity, quantity, causation, contrast, scope, condition, or attribution expressed by that shape. “At once,” “first,” “best,” “only,” “before,” “after,” “each,” “both,” “may,” and a shared list introduction can carry claims even when names and numbers do not change.
2. Draft the revised paragraph around its point. Preserve supported claims and purposeful detail; keep technical, legal, narrative, and author-sample constraints. Do not add a reaction, opinion, first-hand anecdote, or a more specific relationship solely to make the paragraph sound personal. Fictional invention stays within the separately authorized creative scope.
3. Compare the relationship as well as the vocabulary. A sentence can retain every noun and number while losing that two people act simultaneously, converting a favorite into the only option, or making a later step sound like an alternative. Restore the relationship or flag a deliberate material cut against the requested limit.
4. Read the result for cadence and clarity, then repeat the comparison after any further restructuring. Report an unresolved source question rather than repairing it with a plausible fact. Finish in the user's requested mode: final prose for a rewrite, precise locations and suggested fixes for a review, variants only when asked or already justified by the task.

**Source facts (fictional product note):** “Two people can edit the same document at once. Each change appears live for both. Comments remain anchored to the sentence as text changes. The feature is free on every plan.”

**Meaning-preserving edit:** “Two people can edit one document at the same time, with each change appearing live for both. Comments stay anchored to their sentence as the text changes. The feature is free on every plan.”

**Rejected compression:** “People can edit documents, see changes, and add comments for free.” It drops simultaneous editing, live delivery to both editors, comment anchoring during changes, and the every-plan scope. A clean list does not establish fidelity.

**Ranking example:** “My favorite tart came from Graça” can become “I liked the tart from Graça best.” It cannot become “Graça has the best tarts” without broadening a personal preference into a general claim.

### When the requested edit is a file

For a prose-only edit, mark the editable spans before writing. Preserve code blocks, inline code, commands, paths, identifiers, YAML/frontmatter, data, and link targets byte-for-byte unless the user also authorized changes to those spans. Compare the file diff after editing, check the relationships above, and confirm that protected spans survived. Do not infer a link repair or metadata change from a request to improve the prose. If prose is embedded in code or structured data, use the owning format's tools and validate its syntax; never perform a blind whole-file punctuation replacement.

Adapted from Humanizer v3.1.0's “How to work” steps 2–4, “Voice,” “File mode,” and the information-preservation cautions attached to patterns 6, 9, and 19. This pass improves reader clarity and meaning fidelity; it has no authorship-classification or detector-evasion objective.


## Inventory before enforcing symmetry

Use this check when shortening, relabeling or reorganizing substantive content, or when a requested pattern review raises triads, parallel wording or repeated contrast. Inventory the actual points, requirements, evidence, caveats and exceptions before selecting their number or shape. Compare the result to that inventory as well as the fact ledger. A polished set of equal items fails if it deletes a substantive distinction or pads the content with a new claim.

Keep parallel wording when readers compare genuinely comparable things. Keep three items when the source supplies three. Keep “not X, but Y” when it corrects a real misconception with supported distinctions. Revise a repeated construction when it obscures the point or imposes a false model; do not remove it to make the prose appear less familiar. The [plain-language adapter's paired examples and evidence limits](../../plain-language-editing/references/contextual-plain-language.md) show this distinction without defining an authorship test.

**Revise:** A comparison of three plans describes the first plan's confirmed price, the second plan's uncertain availability, and the third plan's mandatory eligibility check. Forcing each into “Fast. Flexible. Simple.” removes the conditions readers need. Preserve their unequal content and status.

**Retain:** “Basic: $10 per month. Plus: $20 per month. Team: $40 per month.” If these are the verified options and comparison is the task, parallel fields and three entries help the reader. Do not add a fourth option or ornamental variation.

For interface labels, onboarding steps, pricing fields or repeated screen copy, hand off task model, content grouping, component choice and interaction/accessibility validation to the available UX-writing/design owner. Carry the inventory, exact claims, proposed wording, constraints and unresolved questions into that handoff. Writing owns meaning and voice; it does not establish that the workflow or rendered layout works. If that specialist is unavailable, complete the bounded wording pass and state which task or presentation checks remain unverified. No cross-plugin file is required to use this method.

## A supplied series or batch

For several pieces that pass individually but reuse the same opening, argument order and ending, apply [cross-piece template review](research-pattern-review.md#compare-pieces-when-the-set-is-in-scope). Distinguish useful recurring structure from cosmetic variations of one frame. Keep required formats and evaluate fact fidelity separately from collection variety; a single rewrite needs no new corpus search.
