# Writing Library bridge

For an explicit generic template, resource ID or same-facts comparison, use `writing-templates:writing-templates` when that plugin is installed. Its `browse_writing_voice_library` and `prepare_writing_voice_handoff` tools can inspect the catalog and prepare a verified selection. The selected bundle includes a compact editorial companion before final QA. If unavailable, use the [public Writing Library](https://activity-atlas.jkylehobson.chatgpt.site/writing-library/) and its selected portable guide. Do not claim that a public download or prepared handoff is an installed skill, a generated draft or a sent message.

Writing Quality Studio owns personal and brand voice matching, natural prose editing, communication and deep audit. An ordinary edit or message does not trigger a generic catalog browse. If a template was deliberately selected, preserve its useful structure during the language pass, along with the user's facts, voice and requested format.
