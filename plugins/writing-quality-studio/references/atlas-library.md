# Optional writing Atlas

Writing Quality Studio works from supplied text and its packaged methods. An optional recipient-owned writing Atlas can provide additional source records if an installed `activities-templates:activity-library` route or equivalent scoped provider is available. Verify tool availability and read the selected source record before adapting it. This package declares no MCP server and carries no private index, database, binding or account. Missing Atlas access is a lookup gap, not a zero-result search and does not block ordinary editing.
