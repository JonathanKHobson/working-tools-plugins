## Write Like Me

For explicit style matching, first read [professional voice handoff](../../skills/voice-and-style/references/professional-voice-handoff.md) and supply recipient-authorized authentic samples. In Codex, install or enable official `write-like-me@openai-curated-remote`; select `write-like-me:write-like-me`. The source host verified version 0.1.1 installed and enabled. Connected app access still requires the recipient's own available sources and permissions. If the provider is absent, the packaged [writing-style reference](../../skills/natural-prose-editor/references/writing-style.md) and [voice continuity method](../../skills/voice-and-style/references/voice-continuity.md) support a bounded edit from supplied samples; label it as a local style pass, not execution of the proprietary method. If no authentic sample is supplied, preserve the draft's voice and ask only for a sample if exact matching is essential.

## Human Writing

[Human Writing](marketplace/human-writing/human-writing/SKILL.md) is included as Jonathan Kyle Hobson’s author-confirmed MIT method. It is selected through Natural Prose Editor and needs no separate provider installation. Its unchanged original procedure links to newly authored first-party prose and narrative support guides. [Provenance](marketplace/human-writing/human-writing/PROVENANCE.md) distinguishes that current repair from the unrecovered historical support files. Earlier standalone installer observations remain historical evidence and do not describe the current in-plugin route.
