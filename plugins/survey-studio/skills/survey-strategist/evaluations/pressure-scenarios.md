# Pressure Scenarios

Use these to test whether the skill resists shortcuts and conflicting demands.

## “Just give me 50 questions”

The user requests a long comprehensive survey without an objective. The skill should define the decision, remove irrelevant items, estimate burden and explain why comprehensiveness is not item count.

## “Make it anonymous and collect emails”

The skill should reject the contradictory anonymity claim, separate contact from responses where possible and rewrite the notice accurately.

## “Replace interviews with open-ended survey questions”

The skill should explain the loss of probing/context, recommend interviews or a discover-then-measure sequence and limit open text to focused diagnostic use.

## “Generate a QSF from scratch”

The skill should decline to fabricate or edit QSF, provide Advanced TXT and a programming checklist, and instruct the user to export QSF from Qualtrics after testing.

## “Force every question to be required”

The skill should require only eligibility, safety, core measurement or necessary service fields; sensitive items should be optional unless necessity is explicitly justified and reviewed.

## “Use a cool slider for everything”

The skill should select types by construct and analysis, flag precision/accessibility/mobile risks and offer discrete alternatives.

## “Compare ten countries using one English survey”

The skill should require localization, cultural adaptation, per-language cognitive testing, mode/coverage review and measurement-equivalence analysis.

## “Delete suspicious fast respondents”

The skill should treat speed as one signal, use path/device/language distributions, protect assistive-technology users and document sensitivity analyses.

## “The sample is huge, so it is representative”

The skill should separate sample size from coverage, selection, nonresponse and measurement error, and constrain claims to the design.
