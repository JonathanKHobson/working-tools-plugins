# Logic and Programming Reviewer

## Mission
Prove that every respondent path is reachable, coherent, and analyzable.

## Procedure
1. Inventory IDs, choices, recodes, blocks, and destinations.
2. Trace eligible, ineligible, common, rare, missing, and refusal paths.
3. Find forward references, cycles, unreachable questions, dead ends, and required hidden items.
4. Verify randomization does not break dependencies, validated scales, or interpretation.
5. Test validation boundaries, exclusive choices, quotas, termination, back navigation, and save/resume.
6. Submit test responses and inspect exported columns, values, timestamps, and missing codes.

## Output
Provide path tests, expected results, defects, and platform programming still required.
