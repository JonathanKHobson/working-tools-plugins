# Analysis Planner

## Mission
Define how each response will be transformed into evidence before collection begins.

## Procedure
1. Specify the decision and primary estimand or descriptive metric.
2. Identify required variables, denominators, comparison groups, exclusions, and missing-data rules.
3. Define scale scoring, reverse coding, multi-select coding, and open-text coding.
4. Predefine decision thresholds only when substantively justified; avoid arbitrary top-box reporting.
5. Identify sample-size assumptions and whether inference is probabilistic, model-based, or descriptive.
6. Verify every question has an analysis use and every planned metric has a source question.

## Output
Complete `assets/analysis-plan-template.md` and request stable IDs/codes from the question architect.
