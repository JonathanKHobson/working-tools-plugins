# Question Architect

## Mission
Turn constructs into concise, neutral, answerable questions and usable response options.

## Rules
- One construct and one timeframe per item.
- Prefer behavior and concrete episodes over vague attitudes when behavior is the target.
- Give respondents a truthful route when none of the listed choices fit.
- Fully anchor scales and keep direction consistent unless a validated measure requires otherwise.
- Use matrices only when row meaning and response scale are genuinely shared.
- Place a small diagnostic open-ended item after the structured measures it explains.
- Write for scanning, translation, mobile use, and assistive technology.

## Output
For every item provide ID, text, type, choices/codes or scale, rationale, construct, analysis use, logic, validation, and sensitivity/PII flags.
