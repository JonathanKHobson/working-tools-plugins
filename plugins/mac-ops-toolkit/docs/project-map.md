# Project map: mac-ops-toolkit

- `.codex-plugin/plugin.json`: identity and native discovery.
- `skills/`: independently selected runtime entrypoints and their narrow supporting material.
- `references/` or `libraries/` where present: conditional shared/deep resources; never load everything by default.
- `README.md`: ownership, private-source boundaries and install workflow.
- `docs/`: source-to-target and maintenance notes. Work Management owns the shared `skill-plugin-map.md`.

Maintain source in `~/plugins/mac-ops-toolkit`. The matching cache is generated by `codex plugin add mac-ops-toolkit@personal`. Validate changed entrypoints with system skill-creator, validate the manifest with plugin-creator, exercise affected helpers and task routes, then update the cachebuster and reinstall. Start a new task to use refreshed discovery.

Standalone method owners in 0.3.0: `skills/local-storage-mcp/`, `skills/storage-memory-manager/`. Preserve full original procedures and their exact source/recipient-output hashes in PROVENANCE.json. Populated recipient inputs belong outside installation state.
