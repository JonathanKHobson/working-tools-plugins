## Workflow

1. Capture exact process arguments, ownership and symptom evidence.
2. Attempt normal quit/recovery first; distinguish stale owned helpers from another task’s active processes.
3. Target only verified blockers within authorization and retest launch/operation.

## Deliver and verify

Return observed process and application state; never use broad Node/Python/browser kills.

## Example boundary

Good: stop a confirmed task-owned stale helper. Bad: kill every process with a familiar executable name.

Use current host facts rather than assuming historical absolute paths apply elsewhere. Work Management owns task coordination; Master Security owns software/permission threat review. Existing authorization carries through routine reversible steps.
