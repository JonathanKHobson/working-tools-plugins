# Quick Actions

- Start local backend and preview:
  `./scripts/start-dev.sh`
- Check whether ports `3000` and `8090` are available:
  `./scripts/check-ports.sh`
- Share the local app through Cloudflare Quick Tunnel:
  `./scripts/start-tunnel.sh`
- View PocketBase logs:
  `docker compose logs -f pocketbase`
