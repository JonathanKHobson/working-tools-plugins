# Development Studio map

Purpose: a maintained software delivery and analysis integration with complete authorized imports and explicit execution-provider routes. Canonical source is this directory; it is not a Git checkout on the preparation host.

- `.codex-plugin/plugin.json`: package identity, skills, owned REA MCP declaration and the three bounded implementation hooks in `hooks/hooks.json`.
- `docs/portable-plugin-manifest.json`: complete portable manifest retained for restoration after native hook compatibility is verified. Root `plugin.json` is intentionally absent because the tested AgentPlugin loader suppresses hooks; `mcp.json` and legacy declarations retain REA.
- `skills/`: focused discovery and operative routes; MCP app skills retain their maintained full procedures.
- `libraries/superpowers-6.4.2/`: byte-identical full upstream snapshot, including helper assets. Do not edit; use method-adaptation for reviewed behavior changes.
- `libraries/alpic-1.0.1/`: unchanged licensed snapshot used by MCP app/Alpic operations.
- `libraries/local-mcp-methods/`: portable full local MCP methods/support with per-file adaptation provenance.
- `references/`: shared provider map, method adaptation and navigation decision support.
- `references/efficient-implementation.md`, `quality-review.md`, `efficient-operations.md` and `implementation-evaluation.md`: complete efficient implementation, review/audit, mode/map/debt/help and evidence-comparison methods through existing heads. `runtime/efficient-implementation/` contains the scoped standard-library runtime; `tests/test_efficient_runtime.py` verifies its behavior and security boundaries.
- `libraries/efficient-implementation-v5/`: all historical worked examples and exact MIT notice. `docs/efficient-source-inventory.json` accounts for every pinned source file; `docs/efficient-implementation-adoption.md` records adaptations and limits.
- `docs/imports.json`, `provider-inventory.json`, `local-mcp-provenance.json`, and `docs/standalone-imports.json`: reviewed source identities, hashes and dispositions. The ten added standalone skill heads live under `skills/`; full licensed code-intelligence and local-app-pipeline support lives under `libraries/`. Go source chunks and the populated corpus index stay external behind `GOLANG_EFFECTIVE_INDEX`. Host-specific paths remain outside the distribution.
- `tests/` and `scripts/validate_package.py`: structural routing, reference closure, hashes and portability checks. No external services start.

Flow: request -> focused skill -> full chosen method and needed support -> actual existing provider/runtime -> implementation -> evidence -> requested handoff state. Useful next edits belong in the relevant skill/reference; upstream refreshes replace reviewed snapshots with a new per-file inventory. Installation/retirement is serialized by the parent ecosystem owner.

Run from this root: `python3 scripts/validate_package.py`. For native skill validation, resolve the host’s skill-creator quick_validate helper. Source/prepared, installed, fresh-discovered and live-verified are distinct.

- `references/module-design-review.md` and `references/reproduction-quality.md`: conditional interface comparison and difficult-reproduction evidence through existing design/debug heads; adapted MIT source links and notice. No new runtime or discovery head.

- `skills/reverse-engineer-software/`: artifact questions not answered by source; existing implementation/debug/test owners retain delivery. `libraries/rea-6.5.0/` contains the full shipped method/reference closure and technical guides. `docs/rea-imports.json` records exact source/output hashes and all source/package dispositions. `references/reverse-engineering-runtime.md` owns acquisition, private binding, invocation, update and missing-provider boundaries. The external runtime is not bundled; `.mcp.json` registers the plugin-owned server through `scripts/rea_runtime.py`. `docs/rea-tool-catalog.json` pins the 207-tool surface and required host approval policy; `tests/test_rea_runtime.py` checks launcher boundaries.
