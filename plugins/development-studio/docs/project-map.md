Purpose: a maintained personal software delivery method package with complete authorized imports and explicit execution-provider routes. Canonical source is this directory; it is not a Git checkout on the preparation host.

- `.codex-plugin/plugin.json`: new package identity and top-level skills only. No hooks or MCP declarations.
- `skills/`: focused discovery and operative routes; MCP app skills retain their maintained full procedures.
- `libraries/superpowers-6.4.2/`: byte-identical full upstream snapshot, including helper assets. Do not edit; use method-adaptation for reviewed behavior changes.
- `libraries/alpic-1.0.1/`: unchanged licensed snapshot used by MCP app/Alpic operations.
- `libraries/local-mcp-methods/`: portable full local MCP methods/support with per-file adaptation provenance.
- `references/`: shared provider map, method adaptation and navigation decision support.
- `docs/imports.json`, `provider-inventory.json`, `local-mcp-provenance.json`: reviewed source identities, hashes and dispositions. Host-specific paths remain outside the distribution.
- `tests/` and `scripts/validate_package.py`: structural routing, reference closure, hashes and portability checks. No external services start.

Flow: request -> focused skill -> full chosen method and needed support -> actual existing provider/runtime -> implementation -> evidence -> requested handoff state. Useful next edits belong in the relevant skill/reference; upstream refreshes replace reviewed snapshots with a new per-file inventory. Installation/retirement is serialized by the parent ecosystem owner.

Run from this root: `python3 scripts/validate_package.py`. For native skill validation, resolve the host’s skill-creator quick_validate helper. Source/prepared, installed, fresh-discovered and live-verified are distinct.
