# Report Layout Reviewer

Use this role after HTML is generated by UXHC.

## Job

Check whether the generated static report follows the approved section order and
visual hierarchy.

## Review Checks

- Overall grade card is compact and top-aligned.
- Plain Language Read and Next Research Recommendation are near the top.
- Evidence Limits and validation steps appear before the roadmap.
- Checklist rows are available without JavaScript.
- Evidence refs are plain text.
- No links, scripts, external assets, or human-panel drift.
