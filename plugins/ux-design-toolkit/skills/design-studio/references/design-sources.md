# Design guidance sources

Inspected and integrated 2026-09-29. The local UX method references are original synthesis. A separate, pinned and licensed Impeccable native runtime, browser assets and upstream playbooks are packaged as conditional reference/tool material under `runtime/impeccable`; their provenance and local source changes are recorded in [BUILD.md](../../../runtime/impeccable/BUILD.md).

- **Impeccable:** [official site](https://impeccable.style/) and [pbakaus/impeccable revision 114ea1d3838fca73b253af45f873b9c4f5f213c8](https://github.com/pbakaus/impeccable/tree/114ea1d3838fca73b253af45f873b9c4f5f213c8). Local UX methods incorporate route-level intent, existing visual authority, and browser-native checks. The pinned arm64 engine now supplies the native detector, local live helper, reviewed utilities, licensed command/reference playbooks and project-local advisory hook capability through the [owned adapter](native-design-runtime.md). The upstream installer/downloader/update and image API verbs are excluded from that route; the host image tool handles image generation. The runtime carries Apache-2.0, upstream NOTICE, relevant MIT/OFL texts and a [patch diff](../../../runtime/impeccable/SOURCE-PATCHES.diff). Upstream questionnaires, aesthetic bans and agent mandates do not supersede the user brief or this skill.
- **Kyle's Shareables:** local Shareables source reviewed by the author; consulted `design-system/style-sources/quality-gates.md`, `design-system/research/shareables-design-system-contrast-spacing-feedback.md`, the registry README and source/template organization. Adopted general token-pair, semantic-role and repeated-failure checks. The repository declares AGPL-3.0-only for code and CC BY-SA 4.0 for non-code, with exclusions for third-party materials and personal brand assets. No source documents, palettes, templates, assets, schemas or runtime were copied. Planning notes and rejected examples do not establish approved defaults.

Existing UX guidance already covers hierarchy, accessibility, responsive states, source fidelity and rendered acceptance. Sites remains the implementation/hosting provider; Graphic Design Studio owns static composition and export. The skill merge adds no MCP dependency on Shareables and requires no access to the old repository at runtime.

- **Make interfaces feel better:** Jakub Krehel's [pinned MIT source](https://github.com/jakubkrehel/make-interfaces-feel-better/tree/35545ea1512ad59fa463e6b1f95ca9c052981fe6), inspected 2026-10-02. Six complete method files and MIT copyright/license are preserved in `libraries/interface-craft`; [conditional adapter](interface-craft.md) resolves exact-value preferences against the task, approved system, accessibility and actual browser behavior. No installer/host agent configuration is copied.
- **SuperDesign:** [legacy IDE extension at 49e2b9d](https://github.com/superdesigndev/superdesign/tree/49e2b9dd9615c6dae936b326b1ddb85d4f1d6f19), inspected 2026-10-02. No method, prompt, asset, code, installer or provider admitted: variants/context/design-first overlap the existing UX owner; fixed-style/parallel-agent/CDN rules conflict with conditional source-led work. The source declares mixed AGPLv3/Enterprise licensing; no Enterprise markers were found outside LICENSE in the inspected snapshot. Runtime remains uninstalled/unverified, with permission bypass, proxy/key logging and unsandboxed preview concerns. README identifies it as unmaintained and points to separate products that were not inspected.
