# UI-kit method provenance

Prepared 9 October 2026. This is original reusable synthesis for UX Design Studio, informed by supplied UI-kit research and a completed local kit's audit/correction history. It does not install the research package's skill, scripts, palettes, third-party component snapshots or runtime dependencies.

## Evidence used

The supplied `ui-kit-research-handoff-2026-10-09` report, source register and selected references informed coverage, measurements, units, state axes, token roles, library selection, licenses, design/code mapping, distribution and governance. Its integrity check was evidence of preserved source bytes, not proof of all external claims. Version-specific vendor claims must be checked again at adoption.

The case kit's R4 review, finding dispositions, decisions, measurement/adoption documents, component map and evidence-model records informed specific failure modes: narrow CTA/subject collision; tooltip transit and dismissal; responsive menu transitions; gallery-dependent initialization; unused/mismatched tokens; stale or empty verification; assertions passing on absent targets; oversized delivery; missing comparison content; clipped tab focus; and historical screenshots mistaken for current acceptance.

The case also supplied successful boundaries worth retaining: original masters separate from web derivatives; human acceptance scoped to exact compositions; public expressive and calm task surfaces sharing foundations; website identity and domain-dependent SEO; and explicit limitations for untested browsers, assistive technology, services and deployment.

These are case-grounded methods, not measured guarantees for other products. The original project's colors, fonts, mascots, button dimensions, radii, breakpoints and asset count were deliberately excluded. Existing studio authority, accessibility and asset-delivery guidance was retained and linked rather than replaced.

## Primary references

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): formal requirements; inspect the applicable success criterion, level, units and exceptions.
- [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/patterns/): interaction patterns to adapt and test, not automatic conformance.
- [DTCG 2025.10 format](https://www.designtokens.org/tr/2025.10/format/): declare exact interoperability scope; not a W3C Recommendation.
- [Responsive images](https://web.dev/learn/images/responsive-images): source selection and resolution mechanics.
- [Google favicon guidance](https://developers.google.com/search/docs/appearance/favicon-in-search), [indexing control](https://developers.google.com/search/docs/crawling-indexing/block-indexing), [robots.txt](https://developers.google.com/search/docs/crawling-indexing/robots/intro): destination-specific discovery requirements and limits.
- [Open Graph](https://ogp.me/): social metadata vocabulary.

The dated handoff's audit/source register records local source paths and hashes, the actual plugin changes and installation evidence. It is a release record; this directory is the maintained method owner. No current product or provider availability is established merely by this source list.
