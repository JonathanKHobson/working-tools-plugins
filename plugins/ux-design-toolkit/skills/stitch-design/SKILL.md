# Stitch design

When orientation helps, briefly name this skill’s outcome, needed input and expected result, then proceed. Broader help uses the [plugin introduction](../../README.md); skip maintainer notes unless needed.


Keep one concrete output and the user's existing Stitch work intact. This skill owns the manual Stitch workflow within UX Design Studio. It does not supply a Stitch MCP, API key, browser launcher, automatic tab access, or permission to submit a draft. Read [workbench](references/workbench.md) only when the task actually requires Stitch browser operation; inspect the current UI and browser tool documentation before any action. A text-only design discussion can use the relevant method below without opening Stitch.

Read only the reference matching the requested output:

| Output | Conditional method |
|---|---|
| Explore or refine one direction | [Design partner](references/design-partner.md) |
| Keep screens and shared components coherent | [Design system](references/design-system.md) |
| Make a component or visual asset family | [Component assets](references/component-assets.md) |
| Connect screens and recovery states | [Flow prototyping](references/flow-prototyping.md) |
| Export, transfer, integrate, or hand off | [Export handoff](references/export-handoff.md) |
| Recover historical work and verify provenance | [Library evidence](references/library-evidence.md) |
| Evaluate a Stitch design or its implementation | [Design review](references/design-review.md) |

For a scattered brief, use the [compact templates](references/brief-and-handoff.md). The [dated UI observations](references/current-ui.md) are discovery hints, not current feature guarantees; [source research](references/research.md) explains the browser-first adoption boundary. Verify current capabilities at use. Preserve unsent drafts and attachments, track temporary screen selection/context chips, and restore only temporary changes. An exported file, generated canvas, implemented page, deployed site, and verified live journey are distinct states.

UX Design Studio retains design judgment and rendered verification. Figma Studio and its Figma-to-Stitch adapter retain Figma operation and cross-app handoff; read their current provider skill when that transfer is actually requested. Survey Studio remains the owner of survey instruments, even when a survey's interface is designed here. Use the current browser/computer provider for observed UI interaction; no provider is made callable by this skill text alone.

The original [Stitch Studio README](UPSTREAM-README.src.md) retains example requests, scope and limitations, and its [project map](UPSTREAM-PROJECT-MAP.src.md) records the prior package layout. They are historical source context; the references above are the active routes.
