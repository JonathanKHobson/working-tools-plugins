# Stitch Design Studio

Eight focused Codex skills for working with Google Stitch through its existing browser interface: design direction, shared systems, components/assets, flows, exports, historical evidence, and QA, with one routing skill.

Use an available browser/computer tool and your existing Stitch account. No Stitch MCP, SDK, API key, server, or extra billing is required by this package. Account access and current product limits still apply.

## Example requests

- “Use Stitch to explore two directions for this onboarding screen, then refine one.”
- “Make these subpages share a consistent header without losing their personality.”
- “Export this component and integrate it into the current app, preserving my draft.”
- “Find my older Stitch work for this case study and distinguish originals from new proposals.”
- “Audit the implemented mobile flow against the selected Stitch design.”

## Install and discovery

This package is registered in the local personal marketplace. Install with `codex plugin add stitch-design-studio@personal --json` when that marketplace entry is available. A fresh Codex task is needed to discover newly installed skills. Browser/computer tools are provided separately by the host.

The optional personal `kyle-mac-design-partners` skill adds local Claude/Desktop workflow preferences. It is intentionally outside this shareable package. This plugin works without it and does not assume a particular Mac, username, account, browser profile, or private project.
