# Project map

Stitch Design Studio is a skills-only Codex plugin for operating the existing Stitch browser interface. It has no server, runtime, API key, billing integration, or browser launcher.

- `.codex-plugin/plugin.json`: plugin metadata and skill discovery.
- `skills/stitch-workbench/`: routing, session preservation, shared brief/handoff templates, dated UI observations and research.
- `skills/stitch-design-partner/`: idea generation and controlled iteration.
- `skills/stitch-design-system/`: tokens and continuity across screens.
- `skills/stitch-component-assets/`: components and asset production.
- `skills/stitch-flow-prototyping/`: journeys and interactive states.
- `skills/stitch-export-handoff/`: verified export and implementation.
- `skills/stitch-library-evidence/`: historical library recovery and provenance.
- `skills/stitch-design-review/`: visual and functional evaluation.
- `README.md`: installation, scope, example requests, and limitations.

Personal app preferences and private project references belong outside this shareable plugin, in the optional local `kyle-mac-design-partners` skill. Do not bundle account identifiers, private prompts, screenshots, credentials, downloads, or consultation transcripts here.
