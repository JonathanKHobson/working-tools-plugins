# Compact working templates

Use only fields needed by the task. These belong in the user's project, not in the installed plugin. Do not require a new document when a short working note is enough.

## Design consultation brief

- Decision/output: one question and concrete deliverable.
- Audience and task: who needs to do what.
- Current source: actual design/file and state; approved decisions.
- Facts: verified content, role, outcomes; unknowns marked.
- Visual anchors: 3–8 references when reviewing an existing visual.
- Constraints: viewports, stack, identity, source assets, format/icon rules, accessibility, plan/time budget.
- Scope: critique only, selected mockup, or implementation; permitted destination/workspace.
- Response: prioritized advice or a selected design with rationale; assumptions and unresolved issues.

## Visual anchor map

| ID | Source and viewport | Region/coordinates | Selector/component | Observed fact | Intended action | Recheck |
|---|---|---|---|---|---|---|
| A1 | Rendered page, exact CSS viewport | Approximate x/y in 0–1 range | Actual element hint | What is visibly true | Concrete change | Verified / unresolved, with evidence |

Never populate an anchor from an imagined screenshot. Distinguish measurements from estimates.

## Design-to-code handoff

- Source project/screen/version; accepted direction.
- Actual export path/format and receiving workspace.
- Token source, shared components, and justified exceptions.
- Asset map: origin/status, intended slot, dimensions, filename, crop, alt intent.
- Interaction/state map; simulated vs implemented behavior.
- Accepted changes and rejected suggestions with short reasons.
- Build/test/render results; anchor comparison; material gaps.
- Publication/delivery status: exact evidence, not inferred from earlier stages.

## Case-study evidence record

- Stable evidence ID and private source location/link.
- Project, visible date or unknown, authorship support, role support.
- Artifact stage: historical original / historical iteration / new reconstruction / new proposal / presentation artwork / implemented result.
- Claim directly supported; adjacent support; missing information.
- Original file plus derivative/crop/redaction history.
- Public caption, audience relevance, confidentiality/release basis.
- Relationship to comparison artifact and verified chronology.
- Disposition: source lead / reviewed candidate / active evidence.

## Temporary material

Mark contact sheets, screenshots captured for QA, audit notes, unused exports, and consultation transcripts as private review material. Record cleanup eligibility after the applicable user review/cleanup approval. Preserve original source evidence and accepted deliverables. Never delete originals merely because a review is complete.
