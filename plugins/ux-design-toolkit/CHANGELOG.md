## 0.3.9

UX Design Studio 0.3.9 fixes MCP discovery and startup for the included UX Heuristics Compass bridge. Portable hosts now receive the root MCP declaration, and Claude resolves the launcher from the installed plugin rather than the recipient workspace.

The package includes 12 skills with their reviewed supporting methods, runtime adapter, provenance, and license notices. Automatic review hooks resolve either host plugin path and Claude loads the shared hook once. The optional Impeccable 4.0.0 runtime assets are unchanged from 0.3.8.

Verification covered package validation, exact native cache parity, and one successful synthetic bridge call in fresh Codex and Claude sessions. The Codex fixture used a unique server name and recipient-owned synthetic binding to keep the check attributable. These checks do not establish access to a recipient's real Compass backend or connected design applications.

Install and configuration instructions are in the package README. A recipient-owned Compass binding is required for live Compass calls. The optional executable asset targets macOS arm64; source and notices are included for the bundled runtime.

Source commit: `edf54184675d77339b8c1ac6b0092f6f6f31d874`.

## 0.3.8

UX Design Studio brings twelve interface-design and review workflows together: visual critique, responsive layouts, interaction states, design systems, product language and formal UX Heuristics Compass audits.

This release includes complete first-party and licensed methods, restored Impeccable fallback references, portable adapters, synthetic examples, source provenance and scoped notices. The pinned macOS arm64 engine is a separate runtime ZIP below; extract it into the plugin root and follow docs/design-runtime.md. Its matching upstream source archive and patches are supplied. Other platforms need a reviewed native build.

Native Codex and Claude recipient installations matched the source package. Source-only installs reported the missing engine; both verified successfully after the runtime overlay. Seventeen adapter tests, a native doctor, a scoped synthetic scan and a disposable localhost live/stop cleanup check passed. Real recipient provider connections, automatic host hook trust/event execution and browser-overlay workflows were not verified. Optional publisher branches and external services require their own installation and access.

Download the plugin ZIP plus the runtime ZIP only if you need native macOS arm64 tools. SHA256SUMS covers the exact assets.
