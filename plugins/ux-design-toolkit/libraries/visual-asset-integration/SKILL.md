# Visual assets: conditional design reference

Use for work where image purpose, provenance, placement or responsive crop materially affects the outcome. This is part of Design Studio, not another entrypoint or a second mandatory review.

Identify each asset as evidence, identity, interface, environment, editorial explanation or atmosphere. Prefer supplied source artifacts for claims about actual work or results; generated art can illustrate or establish mood, not prove an event. Distinguish historical originals, reconstructions and new proposals. Keep source/version and approved originals; public labels should explain material provenance without exposing prompts or production scaffolding.

Choose reuse, crop, edit, generation, replacement, removal or deferral according to purpose. Use the current image-generation/editing skill and its supported persistence/output rules. A chat preview is not necessarily a reusable source file. For precise icons/cutouts use individually recoverable assets; verify transparency and edges at actual use size. Do not introduce an installer or image runtime just to plan placement.

When product imagery needs a chosen generation method or an editable prompt, use the separately installed Graphic Design Studio's guided image workflows with the `ux` domain. Keep UI state, evidence accuracy, placement and responsive QA here; use the official `imagegen` skill for the actual image. Rebuild interaction or motion concepts in code under the UX owner.

Integrate with explicit dimensions, aspect ratio, loading behavior, alt text and mobile crop. Keep hero media within the intended reading area. Give text a quiet reading field using crop/position or the smallest local treatment that works. Preserve proof details inside screenshots. Repetition needs a reason; do not repeat one artifact to imply more evidence.

For multi-asset production use the existing visual-production-workflow. For posters and print use Graphic Design Studio. For deeper source distinctions read references/evidence-and-source-status.md; for web bytes, responsive selection and native resolution read references/responsive-image-qa.md. Load other local references only for a concrete placement question. Historical REFERENCE-WORKFLOW.md documents the former broad skill; this reference and current provider instructions govern.

Inspect the rendered result at affected sizes, recheck changed visual anchors, open the actual exported file and verify the authorized delivery state. Fix misleading evidence, unreadable overlays, broken mobile crops or unresolved placeholders before claiming completion. Report untested behavior plainly.
