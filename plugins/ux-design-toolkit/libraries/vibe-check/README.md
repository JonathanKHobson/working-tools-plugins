# Vibe Check method library

This is a conditional, non-discoverable source library for UX Design Toolkit's
`design-studio` beginner app-planning reference. It preserves the [full original
skill procedure](UPSTREAM-SKILL.src.md), [source README](UPSTREAM-README.src.md),
[changelog](UPSTREAM-CHANGELOG.src.md), version, twelve upstream reference files,
fourteen static diagram files, four examples, and the MIT license from
`TexasBedouin/vibe-check` v2.0.0 at commit `f675bbe`. The source skill includes a
pre-retirement local installation note; its remaining text matches that pinned
revision. These source files retain their original detail and relative paths.
The current user request and UX Design Toolkit entrypoints govern use. The
original files' blanket phase order, mandatory questions/approval pauses,
version checks, promotional footer, fixed estimates, tool/stack prescriptions,
and legal/payment assertions are historical source guidance, not operating
instructions. Read a reference only when its specific method helps the task.

The design-studio adaptation is
[`../../skills/design-studio/references/beginner-app-planning.md`](../../skills/design-studio/references/beginner-app-planning.md).
Use `DISCOVERY-DEEP-DIVE`, `MULTI-SIDED`, `COLD-START`, and `GROWTH-LOOPS`
for depth with Research, Work Management, and Marketing ownership respected.
`EXPERIENCE-BLUEPRINT`, `DIAGRAM-SYSTEM`, and `HTML-BLUEPRINT` describe optional
visual artifacts. `CODE-CHECKUP`, `KEEPING-CODE-NAVIGABLE`,
`GITHUB-AND-DEPLOYMENT`, and `MANAGING-YOUR-AI` belong with the owning
platform/build workflow when that problem actually arises.
`WHAT-A-SKILL-ACTUALLY-IS` applies only when the proposed product is itself
an AI skill or agent. No reference is a standalone skill or runtime.

The included HTML diagram templates may request Google Fonts. The blueprint
examples use Tailwind CDN and jsDelivr Mermaid; they are not offline bundles.
Their renderers and visual quality have not been verified in this merge. Use
the current design/visual tools and inspect rendered output before delivery.
Do not execute release/update scripts from the retired standalone source.
