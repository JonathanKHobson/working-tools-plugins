The complete three-dimension field vocabulary and descriptive examples are preserved in `schema.md`. Changes make unobserved values explicit, distinguish rendered effects from implementation, allow a task-sized partial profile and remove the dependency on upstream measurement scripts. The owning extraction/application procedure is an original local adapter. No scripts, dependencies, forced complete-field generation, default HTML generator, remote asset fetching, unpinned CDN loaders, palette scores or effects are imported.
