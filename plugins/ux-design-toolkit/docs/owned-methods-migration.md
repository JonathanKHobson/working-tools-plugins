## Provider-free acceptance fixtures

These checks validate method usability and reference closure, not native-app or participant execution. No provider package is read during evaluation.

1. Monthly capacity workbook: capacity 120, commitments 75 gives 45 remaining; blank is incomplete, negative invalid, overbooked 135 gives 15 over. Add/sort/filter/reopen/trace tasks are specified; runtime execution is not claimed from documentation.
2. Screenshot booking prototype: source anchors, content/state contract, mobile stacking, select/pending/confirmation/failure/retry, duplicate action prevention, preview and simulated service disclosure all have operative instructions.
3. Commerce flow: total cost/variant/stock/cart/payment recovery and confirmed order are explicit; causal uplift requires a separate valid experiment.
4. IA and participant study: neutral findability task, participant/context coverage, consent, version/evidence record, alternative explanations and limits are defined. No participant evidence is invented.
5. Missing method packs: ordinary entrypoints reach internal complete methods. A missing Figma/hosting/native-sheet tool affects its requested operation, not method access. Portable artifacts are delivered only when they match the requested end state.

Run `python3 scripts/check_owned_method_routes.py` from the package root. The [maintainer checker](../scripts/check_owned_method_routes.py) validates local file/heading references, required workflow elements and all historical redirect headings. Its passing result means the bundled instructions and paths are coherent. Actual workbook, browser, Figma, native-device, server and participant checks belong to later tasks using those runtimes and artifacts.
