# UX Design Studio: choose a workflow

For capabilities, first requests and setup, read [Start here](../README.md). For a known task use the matching skill directly. Read its complete procedure and only the conditional support it calls for. A listed MCP or provider still needs current runtime verification.

| Skill | Outcome and selection trigger |
| --- | --- |
| [dashboard-design](../skills/dashboard-design/SKILL.md) | Design or review a dashboard's information hierarchy, coordinated views, chart meaning, color, customization and delivery contract. Use for dashboard UX and visualization judgment; keep data analysis and rendering with their existing specialists. |
| [design-reference-lookup](../skills/design-reference-lookup/SKILL.md) | Browse local Site templates, public design galleries and transition references, or search offline palettes, typography and patterns when a visual decision is unresolved. |
| [design-review](../skills/design-review/SKILL.md) | Critique, audit or polish a visible interface using observed design, accessibility and performance evidence. |
| [design-studio](../skills/design-studio/SKILL.md) | Explain UX Design Studio capabilities and getting started, or review a visible interface or coordinate UX/UI and web design, critique, and source-to-rendered verification. Use for quick visual audits or work spanning design methods. Route Figma, Stitch, visualization, graphic production and hosting to their specialists; use narrow copy or planning skills directly. |
| [design-systems](../skills/design-systems/SKILL.md) | Inventory, document, extract or evolve reusable UI tokens and components while preserving a coherent design system. |
| [interaction-resilience](../skills/interaction-resilience/SKILL.md) | Design first-use flows and robust interface states for empty data, errors, recovery, retries and interrupted actions. |
| [motion-and-performance](../skills/motion-and-performance/SKILL.md) | Design and review UI motion across state changes, feedback, interruption, focus and reduced-motion behavior; diagnose rendering performance when needed. Use for interactive product surfaces, not video production. |
| [responsive-design](../skills/responsive-design/SKILL.md) | Adapt an interface across viewports, input modes, orientation, locale and native device constraints. |
| [spreadsheet-usability](../skills/spreadsheet-usability/SKILL.md) | Design or review the human interaction layer of a workbook, tracker, model or spreadsheet decision tool. |
| [stitch-design](../skills/stitch-design/SKILL.md) | Use when the user explicitly asks to work in Google Stitch through its current UI, export or integrate a selected Stitch result, review a Stitch design, or recover existing Stitch projects. Route a bounded Stitch screen, component, flow, system, export, or evidence task; do not invoke for generic UX work merely because Stitch is available. |
| [ux-heuristic-compass](../skills/ux-heuristic-compass/SKILL.md) | Run formal UX Heuristics Compass audits with the 14-heuristic rubric, evidence limits, audience-calibrated severity and structured reports. Use for scored heuristic evaluation or UXHC requests; quick polish and ordinary UI fixes belong to design-studio. |
| [ux-writer](../skills/ux-writer/SKILL.md) | Write or review product-interface words, including buttons, navigation, errors, onboarding, empty states, helper text and confirmations. Use directly for copy-only work; engineering specifications belong to product-definition and general prose to natural-prose-editor. |
