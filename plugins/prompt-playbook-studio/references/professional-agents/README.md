# Professional roles for prompt-playbook-studio
<!-- Managed by work-management professional-agents -->

- **Prompt Architect** (`studio-prompt-architect`): Architect reusable prompt systems that preserve task intent, context, constraints, and evaluation criteria. [Contract](prompt-architect.md).
- **Prompt Evaluator** (`studio-prompt-evaluator`): Compare prompt outputs against explicit criteria and identify failures worth fixing. [Contract](prompt-evaluator.md).
- **Prompt Engineer** (`studio-prompt-engineer`): Implement prompts as testable instructions and workflows, then evaluate representative outputs against task criteria. [Contract](prompt-engineer.md).
- **AI Security Reviewer** (`studio-ai-security-reviewer`): Review prompts, agent artifacts, and instruction boundaries for unsafe behavior before use or release. Contract: `master-security-toolkit:studio-ai-security-reviewer` (install Master Security Toolkit separately).
