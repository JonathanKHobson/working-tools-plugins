Not adopted from upstream: automatic optimization of every four-sentence request, unconditional seven-section output, universal prompt rewriting hooks, silent execution of a rewritten task, duplicate marketplace routers, unsupported improvement percentages, or storage of private prompt habits inside the plugin. The authored Prompt Playbook submission hook is a scoped advisory for explicit prompt-crafting work; it neither rewrites nor executes the submitted prompt. Current authorization remains valid during review; a method must not manufacture a second approval requirement for an already authorized action.

Vendor source code, if included, is pinned and licensed separately in its runtime documentation. Instruction-only harvest does not establish a vendor CLI, app authentication, or a live MCP connection. The final integration receipt distinguishes each of those states.
