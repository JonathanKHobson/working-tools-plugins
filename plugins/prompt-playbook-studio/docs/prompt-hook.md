# Prompt Playbook request advisory

`scripts/prompt_submit_advisory.py` emits a short, fixed approach reminder for every valid `UserPromptSubmit` event, including requests without text. It asks the agent to interpret the message in conversation context, strengthen methods and evidence where useful, preserve the requested deliverable and authority, and handle straightforward requests directly. The agent decides the appropriate depth; the hook does not classify ambition or optimize a prompt itself. The maintained method is [ambition within scope](../skills/prompt-refinement/references/ambition-within-scope.md).

An existing supplemental clarity hint may follow for explicit prompt-crafting requests that lack a target or success check. Only that supplement uses keyword matching. General approach guidance does not depend on keywords or task length. The original user message is never rewritten, replaced or stored. A request to execute remains an execution request; a rewrite-only request remains rewrite-only. No extra confirmation is required for already-authorized work. Explicit user choices, including requests to keep the task simple, take precedence.

The handler reads bounded stdin JSON and emits one `hookSpecificOutput.additionalContext` message. It makes no network, model, tool or file calls, does not read transcripts, and persists no prompt data. `SessionStart` is unregistered and silent to avoid duplicate reminders. Unsupported events, malformed data and input above the limit are also silent. Legacy payloads lacking an event name are accepted only when recognizable nonempty prompt text exists.

Both hosts use `hooks/hooks.json`. Codex registers it in `.codex-plugin/plugin.json`; Claude loads that default path automatically. The shared command resolves `${PLUGIN_ROOT:-$CLAUDE_PLUGIN_ROOT}`. Claude’s manifest omits an extra hook declaration because it would load alongside the default. Verify installation, enabled state, hook trust and event dispatch in each host; matching source files alone do not establish activation. Disable this event in the host's hook controls or disable the plugin to stop the reminder. Keep one registration per event in each host.

Run `python3 -B -m unittest discover -s tests -v` from the plugin root. Checks cover broad requests, image-only events, legacy input, unchanged crafting hints, SessionStart suppression, malformed/oversized input and no prompt echo. These tests exercise the handler, not model effectiveness or native event dispatch. Confirm a subsequent ordinary user turn in the target host to verify dispatch. The reminder adds context each turn; it does not launch a separate model call or guarantee better results.

This hook remains separate from Work Management's artifact-quality, goal, delegation and idea-review guidance. Those owners retain their existing responsibilities.

For unclear problems, proposed causes or method gaps, the same fixed advisory now reaches [problem framing and method selection](../skills/prompt-refinement/references/problem-framing-and-method-selection.md). The agent chooses whether to load that depth, use actual discovery/retrieval, research or delegate. Clear routine tasks still execute directly. The helper itself does none of that work and adds no SessionStart registration, classifier or new process. Model agreement does not establish factual support, and a supported first answer need not be replaced.
