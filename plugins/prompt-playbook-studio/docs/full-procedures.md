# Prompt procedure selection

Read the complete task-matching bundled method and its applicable support. This table selects the method; it does not replace it. All ordinary prompt design, repair, routing, safety and evaluation work is Studio-native.

| Task | Full procedure |
| --- | --- |
| Reuse personal prompt patterns or choose a route | [Prompt Playbook](../skills/prompt-playbook/SKILL.md), [original method](../libraries/prompt-playbook-original/SKILL.md), then relevant [patterns](../libraries/prompt-playbook-original/references/patterns.md) and [templates](../libraries/prompt-playbook-original/references/templates.md) |
| Build a new prompt | [Prompt design](../skills/prompt-design/SKILL.md), with the original patterns/templates and [current build checks](../skills/prompt-playbook/references/patterns-and-templates.md) when useful |
| Repair a draft or observed failure | [Prompt refinement](../skills/prompt-refinement/SKILL.md), including requirements comparison and affected behavioral checks |
| Review sources, privacy, authorization or persuasion | [Prompt safety](../skills/prompt-safety/SKILL.md), [pattern-specific checks](../skills/prompt-playbook/references/patterns-and-templates.md) and [private-profile boundaries](../skills/prompt-playbook/references/private-profile.md) when relevant |
| Compare behavior on fixed cases | [Prompt evaluation](../skills/prompt-evaluation/SKILL.md): criteria, fixtures, objective checks, judge limits and actual run evidence |
| Explicit complex-request compilation | [Full optimizer](../libraries/prompt-optimizer/skills/prompt-optimizer/SKILL.md), [schema](../libraries/prompt-optimizer/brief.schema.json), [worked example](../libraries/prompt-optimizer/examples/optimized-brief.json) and [source request](../libraries/prompt-optimizer/examples/long-request.txt) |

The optimizer's historical length trigger does not automatically rewrite user requests. Use it for a requested prompt-crafting/compilation task; resolve library-relative commands from their owner or use the [reviewed compiler wrapper](prompt-compiler.md). The MIT source retains its terms. Existing hooks, Atlas and optional local tools keep their own verified capability boundaries. Historical marketplace bodies stay excluded and are not required at runtime.
