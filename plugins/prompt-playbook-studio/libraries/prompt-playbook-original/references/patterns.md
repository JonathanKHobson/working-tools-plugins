# Pattern Reference

## Prompt Refinement First

Use when a rough prompt already exists and meaning should be preserved while structure improves.

## Intent Dump + Constraint Sweep

Use when the user gives a large natural-language brief that needs sorting into objective, constraints, and exclusions.

## Role Framing as Shortcut

Use when the user wants expertise or judgment loaded quickly through a coach, strategist, analyst, or similar role.

## Trait-Stack Output Control

Use when the user is steering for qualities like clear, concise, structured, deep, or emotionally attuned. Rank the top three traits.

## Multi-Axis Organizing Prompt

Use when outputs need to be sorted or grouped across two or more explicit axes.

## Research/Profile Deep-Dive Prompt

Use when the user wants a broad synthesis, self-analysis, or psychologically rich profile. Force one output artifact unless told otherwise.

## Iterative Clarification Through Follow-Up

Use when a prior answer is close but needs correction, compression, or better preservation of original intent.
