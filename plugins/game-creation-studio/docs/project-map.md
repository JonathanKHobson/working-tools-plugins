# Project map

This source package owns Game Creation Studio methods, not a game runtime. `.codex-plugin/plugin.json` and `skills/game-creation-studio/SKILL.md` are entrypoints. `skills/` contains five original creation methods and four byte-identical third-party technical methods. Each technical skill carries its original support files. `vendor/game-development-studio-1.0.2/` is the complete unmodified source snapshot and legal/support record. `provenance/coverage.json` maps every source file to its disposition. `docs/routes.json` is the machine-readable selection and official Game Studio handoff map. `tests/` holds static route cases.

Flow: user intent selects one focused skill, which reads its conditional support and hands browser execution to the already installed OpenAI Game Studio when relevant. Technical asset and capture commands use `game-dev` only if independently available and authorized. Check source integrity, links, route cases, and skill scan with `python3 tests/validate.py`; it executes no target helper or provider command. Add new design guidance to the focused skill; update `docs/routes.json` and route cases when routing changes. Keep third-party updates separate from original methods until provenance and admission are repeated.
