# Installation and capability boundary

Install this package directory with the current Codex or Claude native plugin manager. Root `plugin.json`, `.codex-plugin/plugin.json` and `.claude-plugin/plugin.json` preserve its identity and local `skills/` discovery. Host installation/discovery was not exercised by these static package checks. Read the [Working Tools installation guide](https://github.com/JonathanKHobson/working-tools-plugins/blob/main/docs/install.md) for collection-level setup.

No account, credential, MCP server, browser, service or dependency binary is bundled. Verify actual installed provider/tool access before invoking commands. Core instruction methods are readable independently. Current user authorization governs local writes, external requests and spending.
