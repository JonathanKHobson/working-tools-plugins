# Security procedure selection

Read the complete native task method and its matching support before reviewing. The Toolkit includes its instruction, indirect-content, tool-authority and regression methods; no external injection-method plugin is needed. Retained upstream methods retain their original grants and notices.

| Review question | Bundled procedure |
| --- | --- |
| Data promoted into instruction authority, reachable impact and finding evidence | [Instruction security review](../skills/instruction-security-review/SKILL.md), [injection patterns](../skills/instruction-security-review/references/injection-review-patterns.md) and [calibration](../skills/instruction-security-review/references/tool-authority-and-calibration.md) |
| Retrieved documents, tool output, encoded or multi-turn source content | [Indirect review](../skills/indirect-injection-review/SKILL.md) and the matching shared path/test patterns |
| Agent tools, arguments, user/resource authority, retries and output sensitivity | [Tool authority](../skills/instruction-security-review/references/tool-authority-and-calibration.md); use [MCP review](../skills/mcp-security-review/SKILL.md) or [permissions](../skills/permission-and-data-review/SKILL.md) for their configuration scope |
| Findings to controls, malicious/benign fixtures and exercised outcomes | [Regression tests](../skills/security-regression-tests/SKILL.md) |

External scanning tools, runtime targets and optional Atlas retrieval need actual scoped access. Report those evidence/access limits; do not substitute a source inventory or written fixture for a tested control. Historical publisher exclusions and hashes remain in provenance, outside the normal task route.
