# Source and method map

`creative-writing-studio` is the maintained package ID. Its public display name is Creative Toolkit. The canonical local source is the complete first-party owner; the public package exports the same distributable methods, references, templates, role contracts and three optional MCP launchers.

The nine principal skill families are `creative-project-router`, `creative-project-context`, `story-book-router`, `story-architecture`, `show-vs-tell-craft`, `horror-story-crafter`, `story-atlas-prep`, `originality-rights-and-provenance`, and `publishing-router`. Their complete supporting files remain beside each skill. Additional skill heads in `skills/` retain their own direct routes; no head is replaced by a catalog description.

The complete local GM direction, pacing, routing, adapter and style methods remain under `library/source-procedures/local/`. The Novelist adaptation is retained under `libraries/novelist/` under its original MIT grant. The GM Apprentice clue-audit adaptation and attribution remain under `libraries/gm-apprentice-clue-audit/` under CC BY-SA 4.0. The separately maintained `aihumanizer:creative-writing` method is a receiver-installed provider dependency, not redistributed source.

Atlas content, drawing state and TTRPG Compass data are recipient-owned runtime inputs. See `README.md` and `references/` for exact setup boundaries. A missing optional backend is a capability-access gap, not a reason to remove the launcher or first-party workflow.
