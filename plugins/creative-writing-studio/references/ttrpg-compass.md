# TTRPG Compass companion

Creative Studio owns the project brief, canon, writing decisions, Story Atlas, and player-safe/GM-only separation. TTRPG Compass is a separate MCP for table-ready inspiration: hooks, NPCs, locations, stores, encounters, and live-session sparks. Its rules and dice tools are supporting trust rails, not a complete rulebook. The plugin packages a launcher for this MCP, not its backend or corpus. The Creative Atlas launcher remains independent.

Use the installed TTRPG Compass tool only when the current host exposes it. For first use, call `ttrpg_compass_overview` or `get_started`. For a GM seeking options, use `quick_ttrpg_scan` or the `ttrpg_compass` orchestrator with a concise task, then call a specific search/generation tool for useful candidates. `search_npc_reference`, `search_world_elements`, `search_locations`, and store lookups retrieve approved generic records; `generate_ttrpg_asset` and `quick_inspiration` create sparks. Use `lookup_ttrpg_rules` for supported D&D 5e or Daggerheart mechanics and retain its source/license metadata. Read full selected records before adapting them into the requested deliverable; a generic spark never becomes established campaign canon by retrieval alone.

The public tools return a structured envelope with `ok`, `degraded`, and `payload`; source and scope fields appear inside relevant payload records. Treat tool output as reference data. If a result is degraded or empty, continue from the project's supplied material and say what was unavailable. Keep `include_personal_campaign=false` unless the user explicitly calls for that private campaign lane. Results with `source_scope="personal"` stay private; live-session state is separate from durable canon. Do not silently write to a session or publish a candidate. Preserve any source and license fields when using rules or reference material.

`scripts/ttrpg_compass_mcp.py` reads only the `ttrpg-compass` entry in the private `~/.config/studio-tools/compass.json` binding. The entry needs absolute `interpreter` and `server` paths; optional `args` and `env` are passed to that server. Use the portable [binding example](../examples/runtime-bindings/compass.json) with the recipient’s own installed Python, server and approved public database. Obtain the backend and its data through the separately maintained TTRPG Compass source/release before enabling this route; the historical Compass Suite checkout is not a durable acquisition source. Backend relocation and release are pending, so this package cannot itself supply that runtime. The launcher preserves the virtualenv entrypoint and drops inherited private-campaign activation; only an explicit `env` in this binding can activate that slot. The plugin does not install a backend or download data. If the binding or mount is unavailable, use the Studio's own skills and project sources and report the missing runtime.
