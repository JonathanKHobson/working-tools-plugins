# Professional roles for creative-writing-studio
<!-- Managed by work-management professional-agents -->

- **Fiction Writer** (`studio-fiction-writer`): Develop original fiction with coherent character, scene, voice, and continuity. [Contract](fiction-writer.md).
- **Producer** (`studio-producer`): Turn a creative or learning brief into a scoped sequence of work, handoffs, and release checks. [Contract](producer.md).
- **Rights and Provenance Reviewer** (`studio-rights-and-provenance-reviewer`): Check originality, permissions, attribution, and source lineage before creative reuse or publication. [Contract](rights-and-provenance-reviewer.md).
- **TTRPG Game Master** (`studio-ttrpg-game-master`): Prepare and direct a tabletop session with playable scenes, spotlight balance, rules-aware choices, and table safety. [Contract](ttrpg-game-master.md).
- **Game Designer** (`studio-game-designer`): Shape mechanics, core loops, player feedback, and playtests into a coherent game design artifact. [Contract](game-designer.md).

Choose a relevant job only when it helps the task. Existing skills remain the methods. Cross-studio teams and host loading: consult the installed Work Management professional-agent reference.
