# ArtCraft app interfaces

These are documented upstream interfaces, checked October 11, 2026. Commands and flags may change; check the matching installed CLI's `--help` before use. All ten official repositories are under [`storytold`](https://github.com/storytold), with a universal macOS DMG and **separate** universal macOS CLI ZIP in each release. The [ArtCraft app pages](https://getartcraft.com/apps) have shown older versions than GitHub releases. Match desktop and CLI versions, verify release checksums, and inspect signing on the actual downloaded artifacts.

The plugin registers one `artcraft-toolkit` gateway. That gateway starts the selected native stdio server only for an open session. Confirm a real native tool call and its output before treating the integration as working. Live control should be stopped after the task. The app pages market broad capabilities; the commands above are the narrower documented routes and still require installed-binary and rendered-behavior checks.

## Direct native MCP entries, if needed outside this plugin

The toolkit gateway handles ordinary on-demand use. If another client must connect directly to an app, use **one selected entry** for a task, with that host's verified absolute CLI path in `command`. This is a template for clients that accept `mcpServers`; it is not an installed configuration or a recommendation to enable all ten. For live mode, launch the matching desktop app with its control setting first and close the listener when finished.

```json
{"mcpServers":{"selected-artcraft-app":{"command":"/verified/absolute/path/to/selected-cli","args":["mcp"]}}}
```

| App | Headless `args` | Live `args` |
|---|---|---|
| PhotoCraft | `["mcp", "--automation-read-root", "/project/input", "--automation-write-root", "/project/output"]` | `["mcp", "--bridge", "127.0.0.1:7878", "--control-token-file", "/private/token"]` |
| VectorCraft | `["mcp", "--headless"]` | `["mcp", "--connect", "127.0.0.1:7979"]` |
| FilmCraft | `["mcp", "--project", "/project/edit.fcproj"]` | `["mcp", "--bridge", "127.0.0.1:9876"]` |
| LightCraft | `["mcp", "--library", "/external/library"]` | `["mcp", "--connect", "127.0.0.1:7980"]` |
| PdfCraft | `["mcp", "--root", "/project/pdfs", "--compact"]` | Use the separate `pdfcraft-cli ui --control FILE` interface, not a live MCP mode. |
| EffectCraft | `["mcp", "--autosave"]` | `["mcp", "--bridge", "9877"]` |
| DesignCraft | `["mcp"]` | `["mcp", "--connect", "7979"]` |
| WordCraft | `["mcp"]` or `["mcp", "--author", "Agent name"]` | `["mcp", "--connect", "127.0.0.1:7981"]` |
| SoundCraft | `["mcp"]` or `["mcp", "--demo"]` | `["mcp", "--connect", "7801"]` |
| CADCraft | `["mcp"]` | `["mcp", "--connect", "127.0.0.1:7979"]` |

The PhotoCraft read and write directories must exist before starting headless automation. In its live mode, set the read/write roots on the desktop process. Use a private token file, never a token copied into a shared command line.

## Installation and launch lookup

All ten CLIs use `<ARTCRAFT_HOME>/cli/<lowercase-app>/<lowercase-app>-cli`. On macOS the desktop bundles are `<ARTCRAFT_HOME>/SoundCraft.app`, `CADCraft.app`, and `WordCraft.app` for the new apps; `PdfCraft.app` is the PDF bundle. Use the host installation report to resolve Applications shortcuts and support-directory redirects. Launch the verified bundle through its Applications shortcut or Computer Use binding. CLI binaries come from the separate release ZIP, not from the DMG. The gateway does not require PATH aliases.

The new apps were checked against v0.5.0 CLI help. CADCraft prints help with exit status 1; use `--version`, command discovery, and a real MCP response to distinguish this from a failed executable. `mcp --help` is not supported consistently across these apps.
