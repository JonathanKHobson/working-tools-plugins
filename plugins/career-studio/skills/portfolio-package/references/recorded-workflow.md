# Reusable portfolio lessons

Resolve the actual source project before designing. Use existing approved presentations, case shells and original evidence; do not replace them with invented stories or reconstruct screenshots as proof. An independent tool project and work performed for an organization are distinct claims even when their names overlap.

Use one evidence map across site, resume and deck. Adapt emphasis to the hiring question while keeping roles, dates, ownership and outcomes consistent. Finish every requested variant; a first-set checkpoint is not completion of the whole request.

Verify the actual hosted or exported result. A generated build, commit, local preview or HTTP success alone cannot establish the requested visible content and interactions. Preserve source originals; keep temporary review materials and personal provenance outside the plugin.
