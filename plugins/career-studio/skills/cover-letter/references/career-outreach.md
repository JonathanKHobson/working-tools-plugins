# Career outreach and responses

Load when the user requests a referral ask, recruiter note, no-open-role interest letter, post-application follow-up, interview thank-you, status check, withdrawal, or offer response. First establish the relationship, actual application/interview state, recipient, channel, and one concrete ask. Use a real shared context or verified conversation detail when present. Keep a referral request easy to decline and do not imply endorsement the person has not offered.

| Message | Core content |
| --- | --- |
| Referral ask or recruiter note | Exact role or work interest, one relevant proof link or sentence, and a low-pressure request. |
| No-open-role interest | Target team/problem and supported contribution, without asserting a vacancy. |
| Application follow-up | Exact role/requisition, actual submitted state and date if known, one new relevant fact or concise question. |
| Interview thank-you | A specific discussion point, how the candidate could contribute, and thanks; do not fabricate rapport or decisions. |
| Status check, withdrawal, offer response | State the observed stage and requested action clearly; use actual offer terms and deadline rather than guessed ones. |

Timing varies with employer instructions, role, and prior contact; verify current context rather than imposing a universal day count. Drafting does not authorize sending. If sending is requested, use the authorized channel and verify the sent item; a sent message is not an employer reply.

For freelance platform proposals, name the client's stated problem, one comparable real sample, a bounded approach and timing, and one useful question. Follow the platform's current rules. Quote a price only from user-approved terms or current researched options presented for choice; never invent availability, testimonials, or client results.
