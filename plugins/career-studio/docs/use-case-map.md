# Independent use cases

Select the smallest task owner and read its complete required procedures, examples and templates. The plugin is a package; do not load every skill.

| Skill | Trigger |
| --- | --- |
| [application-statements](../skills/application-statements/SKILL.md) | Draft or audit truthful job screening answers, personal statements, motivation letters, and scholarship or program application essays from the applicant's real evidence and the exact prompt. |
| [campaign](../skills/campaign/SKILL.md) | Run or resume a tailored job-application campaign, tracking roles, evidence-backed materials, blockers, submission attempts, and employer receipts. Use for campaign preparation, application execution, or status reconciliation across roles; a standalone resume rewrite does not require this campaign workflow. |
| [career-interviews](../skills/career-interviews/SKILL.md) | Prepare evidence-backed interview answers, portfolio walkthroughs or design-challenge practice for a named role and stage. |
| [career-outreach](../skills/career-outreach/SKILL.md) | Draft referral requests, recruiter follow-ups, thank-you notes or freelance proposals from verified professional evidence. |
| [cover-letter](../skills/cover-letter/SKILL.md) | Build and audit truthful employment cover letters, including faculty, career-change, internal, short-form, localized, and referral contexts; handle related career outreach. |
| [portfolio](../skills/portfolio/SKILL.md) | Build, edit, target, audit, and sharpen portfolio case studies, contractor-facing case cards, competency evidence maps, service proof inventories, artifact captions, confidentiality checks, reviewer simulations, visitor-journey audits, portfolio playtest plans, and reader-aware proof structures. |
| [portfolio-package](../skills/portfolio-package/SKILL.md) | Assemble or refresh coordinated portfolio websites, resumes, and slide decks from local work samples, with shared evidence and consistent UX Design and UX Research variants. Use for a portfolio package or cross-format assembly request; use the format-specific skill for an isolated resume rewrite or case-study edit. |
| [resume](../skills/resume/SKILL.md) | Build and audit evidence-backed resumes, recruiter-readable bullets, ATS-safe structure, and matching LinkedIn profile proof. |
| [submissions](../skills/submissions/SKILL.md) | Complete or resume job applications using prepared role-specific packets, verify uploads and form answers, capture submission receipts, and update the existing private campaign dashboard and tracker. Use for submission execution or reconciliation, not job sourcing or portfolio rebuilding. |
