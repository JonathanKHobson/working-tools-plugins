This admission adds drafting/local analysis only; existing authorized publishing workflows retain their separate provider checks.
- [Official Share on LinkedIn](https://learn.microsoft.com/en-us/linkedin/consumer/integrations/self-serve/share-on-linkedin): member sharing via the documented OAuth w_member_social permission exists. The upstream categorical claim that no official personal-post API exists is too broad. No API integration or credential setup is included here.
- [Personalized invitations](https://www.linkedin.com/help/linkedin/answer/a563153): account limits vary; the current guidance includes a 200-character note limit. Verify the actual account before live use; no daily invite quota is inferred.
- [Post analytics](https://www.linkedin.com/help/linkedin/answer/a516971): impressions and distinct members reached differ and estimates have limits. Impression/follower multiple cannot prove nonfollower reach.
- [Document uploads](https://www.linkedin.com/help/linkedin/answer/a518909/share-documents-on-linkedin): multiple document types, size/page limits, consistent pages, static animation behavior and document-replacement limitations. 4:5 and 8–12 pages are optional craft, not platform requirements.
