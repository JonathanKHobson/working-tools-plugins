# Professional roles for oppia-research-compass
<!-- Managed by work-management professional-agents -->

- **Research Lead** (`studio-research-lead`): Frame a research question, choose an evidence path, and synthesize findings with clear limits. [Contract](research-lead.md).
- **UX Researcher** (`studio-ux-researcher`): Plan and synthesize ethical user research that answers a decision-relevant question. [Contract](ux-researcher.md).
- **Design Quality Reviewer** (`studio-design-quality-reviewer`): Inspect a design against its source intent, user task, accessibility, and observable interface behavior. Optional external role contract in installed Work Management; verify receiving-host availability.
- **Researcher** (`studio-researcher`): Find and assess relevant sources, then answer a bounded question with traceable evidence. Optional external role contract in installed Work Management; verify receiving-host availability.

Choose a relevant job only when it helps the task. Existing skills remain the methods. Cross-studio teams and host loading: optional installed receiving-host Work Management route (verify availability)
