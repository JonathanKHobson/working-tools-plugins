# Social Content Studio

Canonical source is this `social-content-studio` tree. The public package is an exact distribution copy of the same maintained implementation; installed caches are generated.
`skills/` contains eight independent owners, indexed by `docs/use-case-map.md`.
Drafting/adaptation owns source-faithful content, calendar owns dates/history,
preview owns visual mockups and publishing owns native platform actions/readback.

`references/social-methods/publishing-ecosystem.md` owns the conditional connected
course/video/article flow. `account-learning.md` owns measured feedback and attended
relationship review. Substack and YouTube UI/receipt guidance belongs under
`skills/social-publishing/references/`. Source provenance stays under `library/`.
Recipient-owned accounts, voice samples, policy, contacts, assets and platform receipts stay
in their projects, never this plugin. No file watcher or comment bot is installed.

The Substack publishing reference also owns optional source-grounded visual/video companion selection and the article handoff. Graphic, Video and Data Visualization retain asset production; Work Management retains editable-source/export handoff. The existing article record holds source/claim lineage, accessibility, companion state and native receipts; no extra queue is created.

Validate changed skill folders with system skill-creator's quick_validate.py and the
existing skill-validation Python; check referenced files and actual native UI separately.
Install through the host plugin manager, then verify skill discovery and package hashes. The included social prose revision method is at `references/social-methods/provider-social-prose.md`; its historical filename is a local compatibility anchor, not an installation requirement.

Recipient projects provide source facts, voice samples and platform authorization; the package creates no account or user-specific config. Writing-template mechanics are shared through `writing-quality-studio:voice-and-style`; this Studio retains its domain decisions. Entry points link the shared catalog by skill identity rather than copying it or hardcoding another plugin’s cache path.

Conditional LinkedIn methods under references/social-methods/ own writing and 21 hook forms, comments/replies, weekly planning, documents/repurposing and performance. Existing social-content, channel-adaptation, content-calendar and review heads select only the applicable method. content-calendar/scripts/linkedin_metrics.py performs local descriptive arithmetic. libraries/linkedin-agent/ preserves exact selected MIT sources. Career owns profile/career-message methods; Writing Quality owns safe text diagnostics. No new publishing provider or automatic engagement.

The same social-methods folder includes linkedin-trend-research.md, platform-coverage.md and platform-content-cycles.md: dated primary-source trend intake plus distinct LinkedIn/YouTube/Substack/TikTok lifecycle decisions. TikTok production and attended native future scheduling belongs to
`skills/social-publishing/references/tiktok-manual-publishing.md`. Short-form and
connected-publishing routes assess each new Short; Video owns media. Capability
values, account policy, backlog, receipts and metrics remain dated project data.
Immediate/Now TikTok posting is prohibited; at most one video per account calendar
day. Direct exports/custom edits and authorized owned-account reuse keep distinct
variant IDs/receipts. Separately authorized pin changes use native readback.
Shared-source public availability, live
queue/horizon and date/time/timezone schedule receipts govern; eventual public release
is verified separately. No posting API, external scheduler service, bot or unattended
UI loop is installed.

Motion-designed originals route from `short-form-video` to Video’s `create-motion-graphics` / code-authored motion storytelling method and Graphic’s `motion-design`. Original platform-only work retains an explicit authorized release basis; cadence, queue and actual publication stay in the project and Social Publishing. The motion method adds no schedule or platform mutation.
