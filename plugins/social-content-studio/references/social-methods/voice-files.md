## Voice Files

When voice matters, look for these local files in the project:

- `about-me.md`
- `voice.md`
- `voice-guide.md`
- `newsletter-voice.md`
- `outreach-profile.md`

If they are missing, either create a compact voice profile from supplied
samples or state that voice matching is limited.

For a linked career/social workflow, reuse the project's existing voice source or the optional external Career workspace binding (`voice_profile`, `linkedin_context`). Do not create a second voice file under a tool-specific home. Writing Quality's voice-and-style method owns authentic sample selection and a provisional brief when authorship is unverified.
