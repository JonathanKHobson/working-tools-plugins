## Voice Files

When voice matters, look for these local files in the project:

- `about-me.md`
- `voice.md`
- `voice-guide.md`
- `newsletter-voice.md`
- `outreach-profile.md`

If they are missing, either create a compact voice profile from supplied
samples or state that voice matching is limited.

For a linked career/social workflow, reuse the project's existing voice source or the optional external Career workspace binding (`voice_profile`, `linkedin_context`). Do not create a second voice file under a tool-specific home. Writing Quality's voice-and-style method owns authentic sample selection and a provisional brief when authorship is unverified.

## Spoken/social voice fields

For substantial Reels or a recurring Instagram workflow, map the useful fields below into the existing project voice record, rather than creating another profile. For a single post, use only the supplied facts needed to draft it. Authentic examples outrank generic style labels; distinguish inferred preference from a stated one.

| Field | Evidence and use |
| --- | --- |
| Identity, audience and purpose | Accurate role, intended viewer, offer or noncommercial purpose; no invented expertise |
| Authentic examples | Source URLs/files and dates for the author's own scripts, captions and speech; third-party inspiration remains separate |
| Spoken delivery | Face-to-camera, voiceover, demonstration or mixed mode; actual measured pace if available, pauses and pronunciation needs |
| Language and diction | Languages, contractions, swearing/emoji preferences, characteristic phrases and words to avoid; preserve meaningful Unicode |
| Point of view | Actual positions and opinions with source, not inferred contrarian beliefs |
| Public evidence | Reusable verified proof and allowed claims; proposal/shipped/measured distinctions |
| Off-limits material | Confidential, private, employer/client, health or unsupported outcome claims and rights restrictions |
| Reader action | Relevant destination/resource and optional keyword already supplied; no default engagement gate |

Capture missing fields only when they materially change the output. A draft or automatic style analysis cannot authenticate the author's voice. Do not populate public plugin templates with private samples or account data.
