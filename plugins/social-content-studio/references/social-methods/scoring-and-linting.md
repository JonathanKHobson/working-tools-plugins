## Scoring And Linting

Assess the following dimensions qualitatively against available evidence. If a user explicitly requests numbers, label them subjective editorial judgments with criteria, never predicted performance:

- hook strength
- voice match
- value density
- structure and channel fit
- publish readiness
- proof-to-claim alignment
- platform norm fit
- human-review status

Use supplied comparable performance data only for descriptive results. If absent or stale, state the gap and give an editorial assessment. Do not substitute heuristic scores for missing analytics. Use content-calendar's LinkedIn performance method for dates, denominators and comparison limits.

Use a brand-voice lint pass for em dashes, buzzword clusters, hedge language,
vague superlatives, repetitive or generic phrasing, unsupported claims, and CTA vagueness.
Report-only by default; edit only when asked.
