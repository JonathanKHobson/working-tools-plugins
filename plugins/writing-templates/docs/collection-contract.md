# External Writing collection contract

Set `WRITING_TEMPLATES_DATA_ROOT` to an authorized real directory outside the installed package. The runtime reads `records/catalog.json`, `records/briefs.md`, and `approved-sources.json` from that root. It preserves the original V01-V24/P25-P53 ID and resource-type contracts, actual base/module routes, exact guide and marked specimen paths, source-edition bundle files, four-axis profiles and six generated references per routed resource, draft QA manifest/runtime files/profiles and prose companions.

The approved manifest pins `catalogSha256`, optional `sourceEditionSha256`, `axesSha256`, `validationManifestSha256`, and the `files` mapping. Every handoff verifies the selected and base/module guides/examples, source-edition references, four-axis references and the complete registered QA closure. It rejects traversal, symlinks, catalog/source mutations and incompatible modifier routes. Pinning a file is a integrity check, not copyright clearance or evidence of style quality. Set `WRITING_TEMPLATES_PUBLIC_BASE` only for your collection's real published catalog if it has one; no public source URL is invented for the synthetic fixture.

The complete original offline engine under `library/voice-library/` is included with the pinned MIT Marked 17.0.5 parser. Real collection-specific profiles, readings, editorial/Humanizer companions and style guides must be separately authorized external files. The public fixture creator copies the licensed engine into an external empty directory and authors four small clearly synthetic records, two bases and two modules, fixtures for source-edition/four-axis/QA contracts and a neutral editorial test companion. It does not export original prose or replace the original collection. The default empty collection can browse without a data binding.

Optional private feedback uses the complete bundled first-party search-miss helper. Set `WRITING_LIBRARY_FEEDBACK_DB` to an external SQLite path to expose its two additional tools. Without it, core retrieval and handoff work, and no miss is recorded. Feedback tools write only when explicitly invoked. A legacy external Atlas binding may supply a database path; arbitrary external Python is never loaded.
