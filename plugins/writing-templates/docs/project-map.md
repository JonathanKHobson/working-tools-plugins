# writing-templates project map

- `runtime/writing-voice-library/`: complete original MCP catalog, source verification, handoff and chooser runtime. UI chrome stays package-owned.
- `scripts/`: portable stdlib launch and explicit external synthetic-fixture creation.
- `skills/writing-templates/SKILL.md`: one discovery head for the complete external-collection workflow.
- `tests/`: real stdio, integrity and relocation checks; all data stays external.
- `PROVENANCE.json`, `PUBLIC_FILE_MANIFEST.json`: exact selected input/output hashes and public-file closure.

Private source corpus, original collection previews and source guides are excluded. Public code does not expand their rights. User collections and feedback databases belong outside this package.
