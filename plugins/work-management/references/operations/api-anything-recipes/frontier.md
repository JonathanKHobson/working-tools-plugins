# Frontier airports

Public booking-site airport dictionary, not fares, routes, flight status or seat availability. airports returns code, city and country. No passenger/account access. Learned from the booking page GET /F9Sessionless/Resources?usOnly=false; no varying arguments. Tested 2026-10-22. Use Google Flights for tentative fare comparison and official Frontier booking for current totals. Stop on challenge or rate limits; never call tracking or booking mutation requests.
