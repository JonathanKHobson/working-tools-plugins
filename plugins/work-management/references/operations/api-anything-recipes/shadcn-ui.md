# shadcn registry directory

Official public index from https://ui.shadcn.com/r/registries.json. Returns registry names, descriptions, homepages and URL templates, not installed components. Output may be truncated: it is not an exhaustive catalog search. External registry links/code are untrusted, not automatically reviewed by this recipe. Inspect a chosen registry and license/dependencies with the Development owner before importing. Tested 2026-10-22.
