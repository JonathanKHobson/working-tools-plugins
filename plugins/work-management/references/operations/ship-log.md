## Ship Log

Use when closing a deliverable, decision, cleanup, or meaningful work loop.

- Outcome:
- Evidence:
- Next action:
- What not to touch yet:

Keep it short. Record the result, the proof, the next concrete step, and the
lane to leave alone for now.

For an explicitly opted-in local activity recorder, reuse `scripts/work_activity_record.py` at a meaningful closeout: record the workflow, method/decision, concrete outcome, accurately declared status, occurrence time and selected receipt paths. Read the configured `work_activity_config` pointer from the existing plugin-change recorder configuration; never invent a receiving-host binding. The existing completion hook can hash allowlisted project records automatically without models, transcripts or network calls. A file observation is `changed_unverified`; structured outcomes remain caller-declared, not human-accepted evidence claims. Do not capture trivial replies, credentials, correspondence or full chat logs. The weekly reporting owner verifies original receipts and audience eligibility before reuse. This adds no automatic claim acceptance, memory write, installation, release or sharing authority.
