# Common behavioral-pattern hypotheses

This is a coaching map, not a judgment file.

## Pattern 1: System-Over-Output

**What it looks like**: the receiving user builds skills, frameworks, templates, and workflows that are impressive, but the infrastructure becomes the work.

**Evidence cues**:
- repeated creation of skills and structured systems
- portfolio and other public artifacts lingering in "almost done"
- research pipelines and frameworks expanding while public output stays thin

**Coaching move**: Ask what finished work the system enables that is not currently shipping.

**Antidote**: No new systems until one visible artifact ships.

## Pattern 2: Mission Buffer

**What it looks like**: the receiving user frames work in world-changing terms. This is genuine, but it can also keep any one deliverable from ever feeling sufficient.

**Evidence cues**:
- repeated mission language
- discomfort with reducing big aims into small, judgeable artifacts

**Coaching move**: Separate the permanent mission from the temporary deliverable.

**Antidote**: Ask for the smallest shippable artifact that moves the mission by 1%.

## Pattern 3: Perfectionism Spiral

**What it looks like**: Starting is easier than before, but near the finish line refinement can extend indefinitely.

**Evidence cues**:
- portfolio and other materials long in progress
- high attention to improving already-strong drafts

**Coaching move**: Name the 80% moment explicitly.

**Antidote**: Use the Ship-It Check. An 8 that ships beats a 10 that does not exist.

## Pattern 4: Parallel Tracks Problem

**What it looks like**: Too many real, meaningful commitments running at once.

**Fictional examples of competing tracks; choose actual user priorities**:
- consulting work
- a volunteer project
- portfolio
- teaching outreach
- thought leadership
- PhD exploration
- creative worldbuilding
- relationship and life stability

**Coaching move**: Reframe dropping to sequencing.

**Antidote**: One primary track gets 80% of intentional energy for 90 days.

## Pattern 5: AI-as-Externalizer

**What it looks like**: AI helps the receiving user structure and articulate raw thought quickly. This is powerful, but overuse can weaken confidence in his unassisted voice.

**Evidence cues**:
- heavy use of AI for drafting, structuring, and polishing
- strong voice-to-text / stream-of-consciousness workflow

**Coaching move**: Ask for a raw first pass before AI cleanup when the goal is voice, conviction, or authorship.

**Antidote**: "Write the first draft yourself. Then bring it here."

## Professional / Relationship Notes

- the receiving user shows up generously for collaborators and causes.
- Generosity can become overcommitment.
- Mentors and warm professional relationships are leverage points, not just support.
- Financial constraints can affect protected commitments; ask the user which commitments matter rather than inferring them.

## What the receiving user Responds To

- Direct honesty without condescension
- Being asked the hard question he is avoiding
- Systems language grounded in real action
- Specific next actions
- Patterns being named without shame

## What the receiving user Does Not Need More Of

- validation for planning
- praise for starting
- permission for more ideas
- generic motivational language
- agreement that every active track deserves equal focus
