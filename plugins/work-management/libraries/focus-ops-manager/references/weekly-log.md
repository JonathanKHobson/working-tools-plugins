# Focus Ops Manager Session Log & Commitments

Log every meaningful session here. Date it. Record what the receiving user committed to. At the start of a general session, read the last 2–3 entries first.

## Log Format

```text
## Session — [Date]
**Focus**: [What we worked on]
**Key insight**: [One thing that emerged]
**Commitment made**: [Specific action the receiving user agreed to do]
**Due by**: [Date]
**Status**: [Pending / Done / Carried over]
```
