# Recipient living goal registry template

The original private commitments are excluded. Date each authorized entry. Use SMART where useful: Specific, Measurable, Achievable, Relevant, Time-bound. A template does not create a goal or authorize a write.

## Secondary goals

Use the same fields for active work outside the selected priority.

## Horizon goals

Plant a bounded next step; do not treat every future interest as daily work.

## Completed goals

Record completion date and actual outcome evidence after verification.

## GOAL REVIEW PROTOCOL

Every 30 days, ask:

1. Which goals moved? Which stalled?
2. What should be promoted, demoted, or dropped?
3. Did anything new emerge that should be added?
4. What got finished?
