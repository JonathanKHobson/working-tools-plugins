# From Compass Suite to Working Tools

Compass Suite was the earlier public storefront for several task-specific AI tools. Working Tools is the maintained entrance for current packages, resources and those continuing Compass products.

This transition does not retire every Compass implementation. Existing Prompt, Critical and UX Heuristic Compass releases and URLs retain their own support and compatibility boundaries. The compass-suite repository continues to own shared compatibility assets and the public catalog source, so it remains unarchived.

Start new plugin installations from this repository's tested packages. Keep an existing installation until the replacement supports the behavior you need. The public package collection excludes private data bindings and provider-owned implementations, and does not claim parity with every locally maintained Studio. Historical downloads remain at their original addresses and are not overwritten by new releases.

[Open Working Tools](https://working-tools.jkylehobson.chatgpt.site/) or [read installation instructions](install.md).
