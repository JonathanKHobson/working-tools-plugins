# From Compass Suite to Working Tools

Working Tools replaces the Compass Suite storefront with the current plugin ecosystem. Start with a plugin for the work you want to do. Familiar Compass capabilities now live inside those plugins.

## Find the current plugin

| Earlier tool | Current home |
| --- | --- |
| Critical Compass | [Reasoning Toolkit](../plugins/reasoning-studio/), which owns the critical reasoning and research-audit capability. Writing Quality Studio links to it. |
| Prompt Compass | [Prompt Playbook Studio](../plugins/prompt-playbook-studio/) |
| UX Heuristics Compass | [UX Design Studio](../plugins/ux-design-toolkit/) |
| Job Application Compass | [Career Studio](../plugins/career-studio/) |
| Humanizer writing workflows | [Writing Quality Studio](../plugins/writing-quality-studio/) |
| Marketing & Social Studio | Two separate plugins: [Marketing Strategy Studio](../plugins/marketing-strategy-studio/) and [Social Content Studio](../plugins/social-content-studio/). |

Each package page explains its skills, installation, dependencies and examples. The [compatibility record](compatibility.md) distinguishes verified installation and sample tasks from integrations that need your own configuration or account access.

## Keep access to an earlier edition

The [Legacy Library](https://working-tools.jkylehobson.chatgpt.site/legacy/) preserves original Compass releases, standalone guides and earlier skill collections. They are labeled as historical editions because their format and capabilities can differ from the current plugins. Existing download addresses are preserved; a new plugin release does not overwrite an earlier download.

For a new installation, [choose a current plugin](https://working-tools.jkylehobson.chatgpt.site/#library) and follow the [installation guide](install.md). Before replacing a working installation, try the new package on a small task and check any required integration setup. Private records, account credentials and recipient-specific configuration stay outside public packages.
