# Accessibility

Documentation uses text-first installation paths, descriptive links and source-readable examples. Screenshots never replace an essential command or instruction. Video workflows include caption and quality checks, but using the package does not establish WCAG conformance or accessible finished media.

Report a barrier through Issues with the page/package, assistive tool when relevant, expected task and observed obstacle. Avoid private content. Support is best effort. The Working Tools Site receives separate desktop/mobile and keyboard review when its interface changes.
